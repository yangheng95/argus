ชุดโครงการชุมชนที่สร้างขึ้นบน OpenCorvus

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ OpenCorvus ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-opencorvus](https://github.com/awesome-opencorvus/awesome-opencorvus) และ [opencorvus.cafe](https://opencorvus.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
