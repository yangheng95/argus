## Causal chain

1. The branch fast-forwarded from `02b404762` to `430a74153` with 18 remote commits and no tracked local conflict.
2. The GUI matrix resolved `0.0.7-beta` for installer naming, but constructed its child environment before projecting that resolved value.
3. In continuous integration the workflow masked the omission by supplying `OPENCORVUS_VERSION`; a direct local matrix run did not, so the embedded sidecar used a timestamped branch snapshot while the Tauri app and installer used `0.0.7-beta`.
4. The root fix is to project the already-resolved version through the matrix's single child-build environment, matching the native CLI and Linux bundle owners.
5. GUI construction clears `packages/opencorvus/dist` while rebuilding its embedded sidecar, so the final build order must be GUI first and CLI second to leave both deliverable sets present.

4. Build the GUI matrix, inspect the embedded sidecar version, then build the CLI matrix so both final artifact sets remain present.
5. Verify hashes, architecture, Tauri plist version, DMG integrity, git diff, commit, and push the source repair to `legacy-remote/v0.0.7beta`.
