Argus → OpenCode Plugin — TypeScript 重写方案

 Context

 Argus 从零构建了完整的 LLM ReAct
 agent（session/tools/permissions/streaming）、任务管  
 理、通信层等基础设施，与 OpenCode
 高度重叠（~60%）。用户决定放弃从零构建，转而将 Argus  
 的独有能力（Eyes 截屏感知、Hands OS
 控制、感知循环、通信桥接）移植为 OpenCode 插件，复用  
 OpenCode 的 LLM 推理引擎、工具系统、会话管理。        

 架构定位：代码结构上是 OpenCode plugin
 package，架构上是最上层——Argus 作为"自主守护者"驱动   
 OpenCode 工作。

 为什么需要 Sidecar？
 OpenCode 插件是被动的（hook 响应事件），而 Argus      
 的感知循环是主动的（持续截屏→分析→触发）。Sidecar     
 通过 OpenCode SDK HTTP
 API（client.session.prompt_async()）将感知结果注入    
 Agent 会话。

 关键组件设计

 1. Plugin 入口 (src/index.ts)

 import type { Plugin } from "@opencode-ai/plugin"     
 import { createTools } from "./plugin/tools"
 import { createHooks } from "./plugin/hooks"
 import { createSkills } from "./plugin/skills"        

 const argus: Plugin = async (input) => {
   const { client, project, directory, $ } = input     

   return {
     // Tools: 8 个 Argus 独有工具
     tool: createTools(),

     // Skills: 观察者相关 SKILL.md 内容
     skill: createSkills(),

     // Hooks
     event: createHooks(client).event,
     "permission.ask":
 createHooks(client).permissionAsk,
     "experimental.chat.system.transform":
 createHooks(client).systemTransform,
     "tool.execute.after":
 createHooks(client).toolExecuteAfter,
   }
 }

 export default argus

 2. 工具定义 (src/plugin/tools.ts)

 import { tool } from "@opencode-ai/plugin"
 import { Eyes } from "../eyes/capture"
 import { Hands } from "../hands/window"

 export function createTools() {
   return {
     argus_observe_screen: tool({
       description: "Capture a screenshot and analyze  
 the current screen state",
       args: { analyze:
 tool.schema.boolean().default(true).describe("Run OCR 
  analysis") },
       async execute(args, ctx) {
         const screenshot = await Eyes.capture()       
         if (!args.analyze) return `Screenshot saved:  
 ${screenshot.path}`
         const text = await Eyes.ocr(screenshot)       
         return `Screen content:\n${text}`
       },
     }),

     argus_find_window: tool({
       description: "Find windows matching a pattern", 
       args: { pattern:
 tool.schema.string().describe("Window title pattern") 
  },
       async execute(args, ctx) {
         const windows = await
 Hands.findWindows(args.pattern)
         return JSON.stringify(windows)
       },
     }),

     argus_activate_window: tool({
       description: "Bring a window to the
 foreground",
       args: { title:
 tool.schema.string().describe("Window title or        
 handle") },
       async execute(args, ctx) {
         await Hands.activateWindow(args.title)        
         return `Activated: ${args.title}`
       },
     }),

     argus_type_text: tool({
       description: "Type text into the active
 window",
       args: { text: tool.schema.string(), method:     
 tool.schema.enum(["keystrokes", "clipboard",
 "console"]).default("clipboard") },
       async execute(args, ctx) {
         await Hands.typeText(args.text, args.method)  
         return `Typed ${args.text.length} chars via   
 ${args.method}`
       },
     }),

     argus_press_keys: tool({
       description: "Press keyboard shortcut",
       args: { keys:
 tool.schema.string().describe("e.g. 'ctrl+shift+p'")  
 },
       async execute(args, ctx) {
         await Hands.pressKeys(args.keys)
         return `Pressed: ${args.keys}`
       },
     }),

     argus_click_at: tool({
       description: "Click at screen coordinates",     
       args: { x: tool.schema.number(), y:
 tool.schema.number(), button:
 tool.schema.enum(["left", "right"]).default("left")   
 },
       async execute(args, ctx) {
         await Hands.click(args.x, args.y,
 args.button)
         return `Clicked ${args.button} at (${args.x}, 
  ${args.y})`
       },
     }),

     argus_notify_developer: tool({
       description: "Send notification to developer    
 via Slack/Telegram",
       args: { message: tool.schema.string(),
 priority: tool.schema.enum(["low", "medium", "high",  
 "critical"]).default("medium") },
       async execute(args, ctx) {
         // 通过 sidecar IPC 或直接调用 comm bridge    
         return `Notified developer: ${args.message}`  
       },
     }),

     argus_ask_developer: tool({
       description: "Ask developer a question and wait 
  for response",
       args: { question: tool.schema.string(),
 timeout_seconds: tool.schema.number().default(300) }, 
       async execute(args, ctx) {
         // 通过 comm bridge 发送问题并等待回复        
         return `Asked: ${args.question}`
       },
     }),
   }
 }

 3. Sidecar 感知循环 (src/sidecar.ts)

 import { createOpencodeClient } from
 "@opencode-ai/sdk"
 import { PerceptionLoop } from "./perception/loop"    
 import { SlackBridge } from "./comm/slack"
 import { loadConfig } from "./config"

 const config = loadConfig()
 const client = createOpencodeClient({ baseUrl:        
 config.opencodeUrl })

 // 启动感知循环
 const perception = new PerceptionLoop(client, config) 
 await perception.start()

 // 启动通信桥接
 if (config.slackBotToken) {
   const slack = new SlackBridge(client, config)       
   await slack.start()
 }

 // Sidecar 保持运行
 process.on("SIGTERM", async () => {
   await perception.stop()
   process.exit(0)
 })

 3-tier 文本注入策略保留：
 1. Clipboard (快速，默认) — clipboardy 读写 + Ctrl+V  
 2. Keystrokes (兼容) — @nut-tree/nut-js 逐键输入      
 3. Console injection (精确) — koffi 调用 Win32        
 WriteConsoleInput

 6. 感知循环 (src/perception/loop.ts)

 每 CAPTURE_INTERVAL (5s):
   1. Eyes.capture() → screenshot
   2. Eyes.diff(prev, curr) → changeRatio
   3. if changeRatio < THRESHOLD → skip (无变化)       
   4. Eyes.ocr(screenshot) → text
   5. Analyzer.analyze(text) → Trigger | null
      - 本地启发式优先 (idle → wait, Y/n →
 auto-confirm)
      - LLM 兜底 (通过 PluginInput.llm 或
 client.session.prompt)
   6. TriggerRouter.route(trigger)
      - cooldown/rate-limit 检查
      - client.session.prompt_async(sessionId,
 trigger.message)

 7. 通信桥接 (src/comm/slack.ts)

 直接参考 packages/slack/src/index.ts 的模式，但增加   
 Argus 特色：
 - 开发者命令解析：status pause resume approve deny    
 - 优先级路由：CRITICAL→所有频道, HIGH→Slack+Telegram, 
  MEDIUM→Slack
 - 双向：Slack 消息 → OpenCode session prompt,
 OpenCode 事件 → Slack 通知
