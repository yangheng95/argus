# AimeCode M4-1 · 用户认证系统

> **自包含文档**：一个 AI 模型只读这一个文件，就能实现完整的用户注册/登录/JWT 认证系统。
> **前置条件**：M1-1（API 框架）+ M1-2（Drizzle + SQLite）已完成。
> **包含**：用户表 schema、注册/登录 API、JWT 签发与验证、Token 刷新、密码哈希、登录页 UI。
> **不包含**：RBAC 权限（M4-2）、OAuth/SSO（阶段 3+）、MFA。

---

## 1. 目标与验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 注册 | `POST /api/auth/register` | 201，返回 user 对象（不含密码） |
| V2 | 登录 | `POST /api/auth/login` | 200，返回 `{ accessToken, refreshToken, expiresIn }` |
| V3 | 密码错误 | 错误密码登录 | 401，`"Invalid credentials"` |
| V4 | Token 验证 | 带 Bearer token 请求 `/api/sessions` | 200，正常返回 |
| V5 | Token 过期 | 使用过期 token | 401，`"Token expired"` |
| V6 | Token 刷新 | `POST /api/auth/refresh` 带 refreshToken | 200，新 accessToken |
| V7 | 密码哈希 | 查看数据库 users 表 | password 字段为 bcrypt hash，不可逆 |
| V8 | 登录页 UI | 访问 `/login` | 显示登录表单，支持注册切换 |
| V9 | 登出 | `POST /api/auth/logout` | refreshToken 失效 |

export const users = sqliteTable('users', {
  id:        text('id').primaryKey(),
  email:     text('email').notNull().unique(),
  name:      text('name').notNull(),
  password:  text('password').notNull(),           // bcrypt hash
  role:      text('role', { enum: ['admin', 'user', 'viewer'] }).notNull().default('user'),
  createdAt: text('created_at').notNull(),
  updatedAt: text('updated_at').notNull(),
  lastLoginAt: text('last_login_at'),
})

export const refreshTokens = sqliteTable('refresh_tokens', {
  id:        text('id').primaryKey(),
  userId:    text('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  token:     text('token').notNull().unique(),
  expiresAt: text('expires_at').notNull(),
  createdAt: text('created_at').notNull(),
})

## 3. 认证服务

```typescript
// server/services/auth.ts

const JWT_SECRET = process.env.JWT_SECRET || 'aimecode-dev-secret-change-in-prod'
const ACCESS_TOKEN_EXPIRY = '1h'
const REFRESH_TOKEN_EXPIRY_DAYS = 7

export class AuthService {
  async register(email: string, name: string, password: string) {
    // 检查邮箱唯一
    const existing = db.select().from(users).where(eq(users.email, email)).get()
    if (existing) throw AppError.conflict('Email already registered')

    const hashedPassword = await Bun.password.hash(password, { algorithm: 'bcrypt', cost: 12 })
    const id = crypto.randomUUID()
    const now = new Date().toISOString()

    db.insert(users).values({ id, email, name, password: hashedPassword, createdAt: now, updatedAt: now }).run()

    return { id, email, name, role: 'user', createdAt: now }
  }

  async login(email: string, password: string) {
    const user = db.select().from(users).where(eq(users.email, email)).get()
    if (!user) throw AppError.unauthorized('Invalid credentials')

    const valid = await Bun.password.verify(password, user.password)
    if (!valid) throw AppError.unauthorized('Invalid credentials')

    // 签发 JWT
    const payload = { sub: user.id, email: user.email, role: user.role }
    const accessToken = await signJWT(payload, JWT_SECRET, ACCESS_TOKEN_EXPIRY)
    const refreshToken = crypto.randomUUID()

    // 存储 refresh token
    const expiresAt = new Date(Date.now() + REFRESH_TOKEN_EXPIRY_DAYS * 86400000).toISOString()
    db.insert(refreshTokens).values({
      id: crypto.randomUUID(),
      userId: user.id,
      token: refreshToken,
      expiresAt,
      createdAt: new Date().toISOString(),
    }).run()

    // 更新最后登录时间
    db.update(users).set({ lastLoginAt: new Date().toISOString() }).where(eq(users.id, user.id)).run()

    return { accessToken, refreshToken, expiresIn: 3600 }
  }

  async refresh(refreshTokenValue: string) {
    const record = db.select().from(refreshTokens).where(eq(refreshTokens.token, refreshTokenValue)).get()
    if (!record || new Date(record.expiresAt) < new Date()) {
      throw AppError.unauthorized('Invalid or expired refresh token')
    }

    const user = db.select().from(users).where(eq(users.id, record.userId)).get()
    if (!user) throw AppError.unauthorized('User not found')

    // 轮转 refresh token（旧的删除，签发新的）
    db.delete(refreshTokens).where(eq(refreshTokens.id, record.id)).run()

    const payload = { sub: user.id, email: user.email, role: user.role }
    const accessToken = await signJWT(payload, JWT_SECRET, ACCESS_TOKEN_EXPIRY)
    const newRefreshToken = crypto.randomUUID()

    const expiresAt = new Date(Date.now() + REFRESH_TOKEN_EXPIRY_DAYS * 86400000).toISOString()
    db.insert(refreshTokens).values({
      id: crypto.randomUUID(), userId: user.id, token: newRefreshToken, expiresAt, createdAt: new Date().toISOString(),
    }).run()

    return { accessToken, refreshToken: newRefreshToken, expiresIn: 3600 }
  }

  async logout(refreshTokenValue: string) {
    db.delete(refreshTokens).where(eq(refreshTokens.token, refreshTokenValue)).run()
  }
}
```

## 4. JWT 工具

```typescript
// server/utils/jwt.ts
// 使用 Bun 内置 crypto 实现 HS256 JWT

export async function signJWT(payload: Record<string, any>, secret: string, expiresIn: string): Promise<string> {
  const header = btoa(JSON.stringify({ alg: 'HS256', typ: 'JWT' }))
  const exp = Math.floor(Date.now() / 1000) + parseExpiry(expiresIn)
  const body = btoa(JSON.stringify({ ...payload, iat: Math.floor(Date.now() / 1000), exp }))
  const signature = await hmacSHA256(`${header}.${body}`, secret)
  return `${header}.${body}.${signature}`
}

export async function verifyJWT(token: string, secret: string): Promise<Record<string, any>> {
  const [header, body, signature] = token.split('.')
  const expectedSig = await hmacSHA256(`${header}.${body}`, secret)
  if (signature !== expectedSig) throw new Error('Invalid signature')

  const payload = JSON.parse(atob(body))
  if (payload.exp && payload.exp < Math.floor(Date.now() / 1000)) {
    throw new Error('Token expired')
  }
  return payload
}

function parseExpiry(s: string): number {
  const match = s.match(/^(\d+)(s|m|h|d)$/)
  if (!match) return 3600
  const [, n, unit] = match
  const multipliers: Record<string, number> = { s: 1, m: 60, h: 3600, d: 86400 }
  return parseInt(n) * (multipliers[unit] || 3600)
}

async function hmacSHA256(data: string, key: string): Promise<string> {
  const encoder = new TextEncoder()
  const cryptoKey = await crypto.subtle.importKey('raw', encoder.encode(key), { name: 'HMAC', hash: 'SHA-256' }, false, ['sign'])
  const sig = await crypto.subtle.sign('HMAC', cryptoKey, encoder.encode(data))
  return btoa(String.fromCharCode(...new Uint8Array(sig))).replace(/\+/g, '-').replace(/\//g, '_').replace(/=/g, '')
}
```

## 5. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | JWT_SECRET 硬编码 | 生产环境必须通过环境变量设置 |
| T2 | bcrypt 在 Bun 中性能 | `Bun.password.hash/verify` 原生支持 bcrypt |
| T3 | Refresh token 泄露 | 每次刷新轮转旧 token，且存储 hash 而非明文（简化版用明文） |
| T4 | 前端 token 存储 | 存 localStorage（XSS 风险），M4-2 升级为 httpOnly cookie |
