**优先级**：P0 · 阶段 0
**依赖**：M01（会话上下文）
**负责范围**：`useEntityParser` · `tool_definitions.ts` · `detectScenario` · `ToolCallBadge`

> **阶段 0 必须交付**：三类意图的分类识别（依赖 Claude Tool Use，无需独立分类器）、常用 50+ 公司名 → 股票代码的精确映射（`companies.ts`）、基础时间表述解析（最近 N 年/季度/交易日）、工具调用触发的 ToolCallBadge 显示。
> **阶段 1 可推迟**：模糊公司名匹配（拼音首字母、历史简称）、意图可解释性文字输出的措辞优化。

---

## 1. 模块目标

将用户的自然语言输入解析为结构化的执行计划：
识别意图类型（代码 / 数据查询 / 混合），解析金融实体（公司名 → 股票代码、日期表述 → 区间），
并将工具定义注入 LLM 调用，让 Claude 自主决定何时调用哪个工具。

---

## 2. 用户故事

- **US-01**：我说"帮我看茅台最近三年财报"，工具能自动识别「茅台 = 600519.SH」和「最近三年 = 2021-01-01 ~ 今天」，不追问。
- **US-02**：我说"帮我写一个计算夏普比率的函数"，工具识别为纯代码意图，不触发任何金融数据查询。
- **US-03**：工具在调用金融数据源时，界面上显示一个气泡告诉我「正在查询 tushare…」，让我知道在等什么。

---

## 3. 功能规格

### 3.1 意图分类

三类意图，由 Claude Tool Use 机制自动判断（不需要独立分类器）：

| 意图类型 | 特征 | 工具调用 |
|---|---|---|
| 纯代码意图 | "写一个函数"、"帮我优化这段代码" | 无工具调用，直接 code_block |
| 纯数据意图 | "茅台最新 PE 是多少" | 1次工具调用，返回数据文本 |
| 混合意图 | "画一下茅台 ROE 趋势" | 工具调用 → 代码生成 → 图表渲染 |

### 3.2 金融实体解析（`useEntityParser`）

在将用户消息传给 LLM 之前，预处理以下实体：

**股票代码解析**：
- 输入：公司名称 / 简称 / 拼音首字母 / 6位代码
- 输出：标准代码（`600519.SH` / `300750.SZ` 格式）
- 规则：精确匹配优先，模糊匹配兜底，无法解析时原文透传给 LLM

**时间表述解析**：
- "最近三年" → `{ start: 3年前的今天, end: 今天 }`
- "过去12个季度" → 推算12个季度的起止日期
- "2023年" → `{ start: 2023-01-01, end: 2023-12-31 }`
- "最新一期" → 最近已发布的财报期（从 Mock 数据元信息中读取）

**指数代码解析**：
- "沪深300" / "hs300" → `000300.SH`
- "创业板指" → `399006.SZ`
- "上证50" → `000016.SH`

### 3.4 工具调用 UI（`ToolCallBadge`）

每次 Claude 发起工具调用时，对话流中插入一个状态气泡：

**进行中状态**：
```
[🔍 查询中] tushare · get_financial_report · 600519.SH · quarterly
```

**完成状态**：
```
[✓ 已获取] tushare · 财报数据 · 2021Q1–2024Q3 · 12条
```

**失败状态**：
```
[✗ 查询失败] tushare 连接超时，已切换备用数据
```

气泡样式：小尺寸、边框、muted 文字色，不占用主要阅读区域。

## 5. Mock 设计

### 场景匹配（`src/mocks/scenarios/index.ts`）

```typescript
// 关键词权重匹配，返回最匹配的预制场景
const SCENE_RULES = [
  { weight: ['roe','财报','茅台','盈利','净利润'],     scene: s01RoeChart },
  { weight: ['因子','ic','动量','阿尔法','回测'],      scene: s02FactorDebug },
  { weight: ['换手率','封装','函数','可复用'],          scene: s03WrapQuery },
  { weight: ['压力测试','回撤','股灾','2015','风险'],   scene: s04StressTest },
  { weight: ['对比','比较','宁德','比亚迪','亿纬'],     scene: s05Comparison },
]

// 匹配算法：统计命中关键词数量，取最高分；并列时取第一个
export function detectScenario(input: string): Scenario {
  const lower = input.toLowerCase()
  let best = { score: 0, scene: defaultScenario }
  for (const { weight, scene } of SCENE_RULES) {
    const score = weight.filter(k => lower.includes(k)).length
    if (score > best.score) best = { score, scene }
  }
  return best.scene
}
```

## 7. 错误处理

| 场景 | 处理 |
|---|---|
| 公司名无法解析 | 原文透传给 LLM，由 LLM 自行理解（不中断流程）|
| 日期表述无法解析 | 不注入日期参数，LLM 自行决定范围 |
| 工具调用失败 | ToolCallBadge 显示 error 状态，LLM 获得 `tool_error` 事件，自行决定如何回应 |
| 无匹配场景（Mock 模式）| 使用 `defaultScenario`（通用回复：解释工具能力）|
