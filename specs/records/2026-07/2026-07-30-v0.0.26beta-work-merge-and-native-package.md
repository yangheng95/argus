1. Initial Task hydrate publishes a valid short tail.
2. `task.messages.changed` schedules a larger latest-tail refresh.
3. The refresh prepares a replacement snapshot but replays it into the prior
   writer. Its truncated boundary groups an overlapping message under a
   different card, so strict part ownership rejects the second owner.
4. Rollback clears Board, Agent, and card-tree stores, but the long-lived
   Virtua instance retains the previous virtual rows.
5. Later source selection succeeds at the transport and source layers, while
   the stale virtual generation continues rendering old rows. New Chat exposes
   the same stale rows beside the now-correct empty launcher.
