# AimeCode M3-2 · 上下文记忆引擎

> **自包含文档**：一个 AI 模型只读这一个文件，就能实现多轮对话的上下文保持和长会话压缩。
> **前置条件**：M1-1（API 框架）+ M1-2（数据库）+ M2-1（真实 LLM 接入）已完成。
> **包含**：对话上下文窗口管理、长会话摘要压缩、实体跨轮次指代消解、上下文注入策略。
> **不包含**：知识库 RAG（M3-3）、用户级长期记忆、多会话关联。

---

## 1. 目标与验收标准

### 1.1 里程碑目标

使 AimeCode 在多轮对话中保持上下文连贯性：用户第一轮问茅台，第二轮说"它的毛利率"时，系统自动理解"它"指茅台。长会话（>20 轮）自动压缩历史，不超过 Claude 的上下文窗口。

### 1.2 验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 基础指代消解 | 第一轮"茅台ROE"，第二轮"它的毛利率" | 第二轮自动调用 `get_financial_report(ticker='600519.SH', fields=['gross_margin'])` |
| V2 | 多实体跟踪 | 轮次 1"茅台ROE"，轮次 2"五粮液呢"，轮次 3"对比这两家" | 轮次 3 调用两个 ticker 的工具 |
| V3 | 长会话压缩 | 发送 25 轮消息 | 发送给 Claude 的 messages 不超过 120K tokens（约 15 轮原文 + 摘要） |
| V4 | 摘要质量 | 在第 20 轮引用第 3 轮的具体数据 | 摘要中保留了关键数据点 |
| V5 | 压缩透明 | 压缩发生时 | 控制台日志 `[Context] Compressed: 25 messages → 15 messages + summary` |
| V6 | Token 计数准确 | 检查发送给 Claude 的 messages 总 token | 误差 < 10%（使用 tiktoken 估算） |
| V7 | 上下文保持准确率 | 20 组多轮对话测试 | ≥ 90% 的指代消解正确 |

## 2. 架构

```
用户消息 → ContextManager → 构建 messages 数组 → Claude API

ContextManager 职责：
1. 维护完整消息历史（持久化在 DB）
2. 维护实体跟踪表（当前会话的 ticker/公司名/指标）
3. 在发送前决定哪些消息原文保留、哪些压缩为摘要
4. 注入实体解析结果到 system prompt
```

## 3. 上下文窗口策略

### 3.1 窗口结构

```
[System Prompt]                        ~2K tokens (固定)
[Entity Context]                       ~200 tokens (动态)
[Summary of messages 1..N-K]           ~500-2K tokens (压缩)
[Recent K messages (原文)]             ~10-80K tokens (保留)
[Current user message]                 ~100-500 tokens
─────────────────────────────────────
Total ≤ 100K tokens (留余量给输出)
```

### 3.2 策略参数

```typescript
const CONTEXT_CONFIG = {
  maxInputTokens: 100_000,          // Claude 输入上限（留 28K 给输出）
  systemPromptTokens: 2_000,        // 固定系统提示
  entityContextTokens: 200,         // 实体上下文
  recentMessagesMin: 6,             // 至少保留最近 6 条消息（3 轮）
  recentMessagesMax: 30,            // 最多保留最近 30 条消息
  summaryMaxTokens: 2_000,          // 摘要最大长度
  compressionThreshold: 20,         // 超过 20 条消息时触发压缩
  summaryModel: 'claude-haiku-4-5-20251001',  // 摘要用便宜模型
}
```

## 4. 实体跟踪器

文件路径：`server/services/context/entity-tracker.ts`

```typescript
/**
 * 跟踪当前会话中提及的金融实体，用于指代消解。
 */
export interface TrackedEntity {
  type: 'company' | 'index' | 'indicator'
  name: string              // 用户使用的名称（如"茅台"）
  code?: string             // 标准代码（如"600519.SH"）
  mentionedAt: number       // 最后提及的消息序号
}

export class EntityTracker {
  private entities: TrackedEntity[] = []
  private messageSeq = 0

  /**
   * 从用户消息和工具调用中提取并更新实体。
   */
  updateFromMessage(content: string, toolCalls?: Array<{ tool: string; params?: Record<string, unknown> }>) {
    this.messageSeq++

    // 从工具调用中提取 ticker
    if (toolCalls) {
      for (const call of toolCalls) {
        const ticker = call.params?.ticker as string | undefined
        if (ticker) {
          this.upsertEntity({
            type: 'company',
            name: ticker,
            code: ticker,
            mentionedAt: this.messageSeq,
          })
        }
      }
    }
  }

  /**
   * 获取最近的实体列表（用于注入 system prompt）。
   */
  getRecentEntities(limit = 5): TrackedEntity[] {
    return [...this.entities]
      .sort((a, b) => b.mentionedAt - a.mentionedAt)
      .slice(0, limit)
  }

  /**
   * 生成实体上下文字符串，附加到 system prompt 末尾。
   */
  toContextString(): string {
    const recent = this.getRecentEntities()
    if (recent.length === 0) return ''

    const lines = recent.map(e => {
      if (e.type === 'company' && e.code) {
        return `- ${e.name} (${e.code})`
      }
      return `- ${e.name}`
    })

    return `\n\n## 当前对话涉及的实体\n用户近期讨论了以下标的，当用户说"它"、"这只股票"、"上面那个"时，优先指代最近提及的实体：\n${lines.join('\n')}`
  }

  private upsertEntity(entity: TrackedEntity) {
    const existing = this.entities.find(
      e => e.code === entity.code || e.name === entity.name
    )
    if (existing) {
      existing.mentionedAt = entity.mentionedAt
      if (entity.code) existing.code = entity.code
    } else {
      this.entities.push(entity)
    }
  }
}
```

## 5. 上下文管理器

文件路径：`server/services/context/context-manager.ts`

```typescript
import type { Message } from '@shared/types'
import { EntityTracker } from './entity-tracker'
import { generateSummary } from './summarizer'
import { estimateTokens } from './token-counter'

const CONFIG = {
  maxInputTokens: 100_000,
  systemPromptTokens: 2_000,
  recentMessagesMin: 6,
  recentMessagesMax: 30,
  summaryMaxTokens: 2_000,
  compressionThreshold: 20,
}

interface ContextWindow {
  systemPrompt: string
  messages: Array<{ role: 'user' | 'assistant'; content: string }>
  totalTokens: number
  compressed: boolean
  summaryIncluded: boolean
}

export class ContextManager {
  private entityTracker = new EntityTracker()
  private summary: string | null = null
  private summaryCoversUpTo = 0  // summary 覆盖到第几条消息

  /**
   * 构建发送给 Claude 的 messages 数组。
   * 
   * @param allMessages 完整消息历史（从 DB 读取）
   * @param baseSystemPrompt 基础 system prompt
   * @returns 构建好的上下文窗口
   */
  async buildContext(
    allMessages: Message[],
    baseSystemPrompt: string,
  ): Promise<ContextWindow> {
    // 更新实体跟踪
    const lastMsg = allMessages[allMessages.length - 1]
    if (lastMsg) {
      this.entityTracker.updateFromMessage(lastMsg.content, lastMsg.toolCalls)
    }

    // 注入实体上下文到 system prompt
    const entityContext = this.entityTracker.toContextString()
    const systemPrompt = baseSystemPrompt + entityContext

    const systemTokens = estimateTokens(systemPrompt)
    const budget = CONFIG.maxInputTokens - systemTokens

    // 不需要压缩的情况
    if (allMessages.length <= CONFIG.compressionThreshold) {
      const messages = allMessages.map(m => ({
        role: m.role,
        content: m.content,
      }))
      const totalTokens = messages.reduce((sum, m) => sum + estimateTokens(m.content), 0) + systemTokens

      return {
        systemPrompt,
        messages,
        totalTokens,
        compressed: false,
        summaryIncluded: false,
      }
    }

    // 需要压缩
    console.log(`[Context] ${allMessages.length} messages, triggering compression`)

    // 计算保留多少条最近消息
    let recentCount = CONFIG.recentMessagesMin
    let recentTokens = 0

    for (let i = allMessages.length - 1; i >= 0 && recentCount <= CONFIG.recentMessagesMax; i--) {
      const tokens = estimateTokens(allMessages[i].content)
      if (recentTokens + tokens > budget - CONFIG.summaryMaxTokens) break
      recentTokens += tokens
      if (i < allMessages.length - recentCount) recentCount++
    }

    const recentStart = allMessages.length - recentCount
    const oldMessages = allMessages.slice(0, recentStart)
    const recentMessages = allMessages.slice(recentStart)

    // 生成摘要（如果旧消息范围变化）
    if (recentStart > this.summaryCoversUpTo) {
      this.summary = await generateSummary(oldMessages)
      this.summaryCoversUpTo = recentStart
      console.log(`[Context] Summary generated covering messages 0..${recentStart - 1}`)
    }

    // 构建消息数组
    const messages: Array<{ role: 'user' | 'assistant'; content: string }> = []

    // 摘要作为第一条 assistant 消息
    if (this.summary) {
      messages.push({
        role: 'assistant',
        content: `[以下是之前对话的摘要]\n${this.summary}\n[摘要结束，以下是近期对话]`,
      })
    }

    // 近期消息原文
    for (const msg of recentMessages) {
      messages.push({ role: msg.role, content: msg.content })
    }

    const totalTokens = systemTokens + messages.reduce((sum, m) => sum + estimateTokens(m.content), 0)

    console.log(`[Context] Compressed: ${allMessages.length} messages → ${messages.length} messages + summary (${totalTokens} tokens)`)

    return {
      systemPrompt,
      messages,
      totalTokens,
      compressed: true,
      summaryIncluded: !!this.summary,
    }
  }
}
```

## 6. 摘要生成

文件路径：`server/services/context/summarizer.ts`

```typescript
import Anthropic from '@anthropic-ai/sdk'
import type { Message } from '@shared/types'

const SUMMARY_MODEL = 'claude-haiku-4-5-20251001'
const SUMMARY_MAX_TOKENS = 1024

const SUMMARY_PROMPT = `你是一个对话摘要助手。请将以下金融分析对话压缩为一段简洁的摘要。

要求：
1. 保留所有提及的公司名称和股票代码
2. 保留关键数据点（如 ROE 33.2%、PE 22.1x）
3. 保留用户的分析目标和结论
4. 省略寒暄、重复内容和过程细节
5. 使用中文，简洁专业
6. 摘要不超过 500 字`

export async function generateSummary(
  messages: Message[],
): Promise<string> {
  // 构建对话文本
  const conversationText = messages.map(m =>
    `${m.role === 'user' ? '用户' : 'AI'}: ${m.content.slice(0, 500)}`
  ).join('\n\n')

  const client = new Anthropic({
    apiKey: process.env.ANTHROPIC_API_KEY || '',
  })

  const response = await client.messages.create({
    model: SUMMARY_MODEL,
    max_tokens: SUMMARY_MAX_TOKENS,
    system: SUMMARY_PROMPT,
    messages: [{ role: 'user', content: conversationText }],
  })

  const text = response.content
    .filter((block): block is Anthropic.TextBlock => block.type === 'text')
    .map(block => block.text)
    .join('')

  return text
}
```

## 7. Token 计数

文件路径：`server/services/context/token-counter.ts`

```typescript
/**
 * 估算文本的 token 数。
 * 使用简单的字符计数估算（中文 1 字 ≈ 2 tokens，英文 1 word ≈ 1.3 tokens）。
 * 精度足够用于窗口管理，不需要引入 tiktoken。
 */
export function estimateTokens(text: string): number {
  if (!text) return 0

  let tokens = 0
  for (const char of text) {
    if (char.charCodeAt(0) > 0x4e00) {
      tokens += 2  // CJK 字符
    } else if (/\s/.test(char)) {
      tokens += 0.25
    } else {
      tokens += 0.5
    }
  }

  return Math.ceil(tokens * 1.1)  // 10% 安全余量
}
```

## 8. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | 摘要丢失关键数据点 | summary prompt 强调保留公司代码和数值 |
| T2 | 摘要本身消耗 API 调用 | 用 Haiku（便宜快速），且只在消息数超过阈值时触发 |
| T3 | 实体跟踪器漏掉口语化名称 | 从 tool_call 结果中提取 ticker（比从用户输入提取更准） |
| T4 | 压缩后模型对旧消息的理解降低 | 保留最近 6 条原文（3 轮），确保当前话题的上下文完整 |
| T5 | token 估算不准导致超窗口 | 10% 安全余量 + maxInputTokens 设为 100K（Claude 上限 200K） |
| T6 | 摘要与原文不一致 | 摘要标记为 `[摘要]` 让模型知道这是压缩内容 |
