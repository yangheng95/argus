# AimeCode M1-4 · 行情数据服务

> **自包含文档**：一个 AI 模型只读这一个文件，就能实现 TushareService 的行情查询功能。
> **前置条件**：M0-1（OHLCVBar 类型定义）+ M1-1（API 框架）+ M1-3（TushareService 基础调用已就绪）。
> **包含**：OHLCV 日线/周线/月线查询、指数成分股查询、行情缓存（4 小时）、数据清洗、合约测试。
> **不包含**：技术指标计算（M3-4）、分钟线数据（阶段 2+）、财报查询（M1-3）。

---

## 1. 目标与验收标准

### 1.1 里程碑目标

实现 `IFinanceService.getOHLCV()` 和 `getIndexComponents()`，从 Tushare Pro API 获取 A 股/指数的历史行情数据，附带 4 小时磁盘缓存。

### 1.2 验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 日线查询 | `getOHLCV({ ticker: '600519.SH', startDate: '2024-01-02', endDate: '2024-03-29', freq: 'D' })` | 返回 OHLCVBar[]，约 60 条，每条含 date/open/high/low/close/volume |
| V2 | 周线查询 | `freq: 'W'` | 返回约 13 条周线数据 |
| V3 | 月线查询 | `freq: 'M'` | 返回 3 条月线数据 |
| V4 | 数值合理 | 茅台 2024 年日线 | close 在 1400-1900 区间，volume > 0 |
| V5 | 指数行情 | `getOHLCV({ ticker: '000300.SH', ... })` | 返回沪深300指数行情 |
| V6 | 指数成分 | `getIndexComponents({ indexCode: '000300.SH' })` | 返回 300 条，每条含 ticker/name/weight |
| V7 | 缓存命中 | 相同参数连续查询两次 | 第二次 < 10ms |
| V8 | 缓存 TTL | 行情缓存 4h 后失效 | 4h 后重新请求 |
| V9 | 日期校验 | `startDate > endDate` | 返回空数组，不抛错 |
| V10 | 合约测试 | `bun test server/services/__tests__/tushare-market.test.ts` | 全部通过 |

## 2. Tushare Pro 行情 API

### 2.1 日线行情（pro_bar / daily）

```json
{
  "api_name": "daily",
  "token": "<token>",
  "params": {
    "ts_code": "600519.SH",
    "start_date": "20240102",
    "end_date": "20240329"
  },
  "fields": "ts_code,trade_date,open,high,low,close,vol,amount,pct_chg,turnover_rate"
}
```

响应 items 中每行：
```
["600519.SH", "20240329", 1628.01, 1650.00, 1620.00, 1645.50, 25831.00, 423561.78, 1.23, 0.21]
```

注意：`vol` 单位是**手**（100 股），`amount` 单位是**千元**。

### 2.2 周线/月线

```json
{
  "api_name": "weekly",
  "params": { "ts_code": "600519.SH", "start_date": "20240102", "end_date": "20240329" }
}
```

月线用 `api_name: "monthly"`。

### 2.3 指数成分

```json
{
  "api_name": "index_weight",
  "params": { "index_code": "399300.SZ", "start_date": "20240301", "end_date": "20240331" }
}
```

注意：沪深 300 在 Tushare 中的代码是 `399300.SZ`（深交所版），非 `000300.SH`。需要做代码映射。

### 2.4 指数代码映射

| AimeCode 格式 | Tushare index_weight 格式 | 说明 |
|---|---|---|
| `000300.SH` | `399300.SZ` | 沪深 300 |
| `000905.SH` | `399905.SZ` | 中证 500 |
| `000852.SH` | `399852.SZ` | 中证 1000 |
| `000016.SH` | `000016.SH` | 上证 50（不变） |

## 3. 完整实现

文件路径：`server/services/tushare-market.ts`

```typescript
import type { OHLCVBar } from '@shared/types'

interface TushareResponse {
  code: number
  msg: string | null
  data: {
    fields: string[]
    items: (string | number | null)[][]
  } | null
}

// ── 指数代码映射 ─────────────────────────────────────────────
const INDEX_CODE_MAP: Record<string, string> = {
  '000300.SH': '399300.SZ',
  '000905.SH': '399905.SZ',
  '000852.SH': '399852.SZ',
}

function mapIndexCode(code: string): string {
  return INDEX_CODE_MAP[code] || code
}

// ── 日期工具 ─────────────────────────────────────────────────
function toTushareDate(isoDate: string): string {
  return isoDate.replace(/-/g, '')
}

function toISODate(td: string): string {
  return `${td.slice(0, 4)}-${td.slice(4, 6)}-${td.slice(6, 8)}`
}

// ── 缓存 ─────────────────────────────────────────────────────
interface CacheEntry<T> {
  data: T
  expiresAt: number
}

const cache = new Map<string, CacheEntry<any>>()
const OHLCV_CACHE_TTL_MS = 4 * 60 * 60 * 1000   // 4 小时
const INDEX_CACHE_TTL_MS = 24 * 60 * 60 * 1000   // 24 小时（成分股变动低频）

// ── freq → Tushare API ──────────────────────────────────────
const FREQ_API_MAP: Record<string, string> = {
  D: 'daily',
  W: 'weekly',
  M: 'monthly',
}

// ── TushareMarketService ────────────────────────────────────
export class TushareMarketService {
  private token: string
  private baseUrl = 'https://api.tushare.pro'

  constructor(token: string) {
    if (!token || token.trim() === '') {
      throw new Error('Invalid Tushare token: token cannot be empty')
    }
    this.token = token
  }

  /**
   * 获取 OHLCV 行情数据。
   */
  async getOHLCV(params: {
    ticker: string
    startDate: string
    endDate: string
    freq?: 'D' | 'W' | 'M'
  }): Promise<OHLCVBar[]> {
    const freq = params.freq || 'D'

    // 日期校验
    if (params.startDate > params.endDate) return []

    // 缓存检查
    const cacheKey = `ohlcv:${params.ticker}:${params.startDate}:${params.endDate}:${freq}`
    const cached = cache.get(cacheKey)
    if (cached && Date.now() < cached.expiresAt) {
      console.log(`  [Cache] HIT ${cacheKey}`)
      return cached.data
    }

    // 请求 Tushare
    const apiName = FREQ_API_MAP[freq] || 'daily'
    const response = await this.callTushare(apiName, {
      ts_code: params.ticker,
      start_date: toTushareDate(params.startDate),
      end_date: toTushareDate(params.endDate),
    }, 'ts_code,trade_date,open,high,low,close,vol,amount,pct_chg,turnover_rate')

    if (!response.data?.items) return []

    const { fields, items } = response.data
    const bars: OHLCVBar[] = []

    for (const row of items) {
      const rowData: Record<string, any> = {}
      for (let i = 0; i < fields.length; i++) {
        rowData[fields[i]] = row[i]
      }

      // 数据清洗
      const open = Number(rowData.open)
      const high = Number(rowData.high)
      const low = Number(rowData.low)
      const close = Number(rowData.close)
      const vol = Number(rowData.vol)

      // 跳过无效数据
      if (isNaN(close) || close <= 0) continue

      bars.push({
        date: toISODate(rowData.trade_date),
        open,
        high,
        low,
        close,
        // vol 单位：手 → 股（× 100）
        volume: vol * 100,
        // amount 单位：千元 → 元（× 1000）
        amount: rowData.amount ? Number(rowData.amount) * 1000 : undefined,
        turnover: rowData.turnover_rate ? Number(rowData.turnover_rate) : undefined,
        change_pct: rowData.pct_chg ? Number(rowData.pct_chg) : undefined,
      })
    }

    // 按日期升序排列
    bars.sort((a, b) => a.date.localeCompare(b.date))

    // 写缓存
    cache.set(cacheKey, { data: bars, expiresAt: Date.now() + OHLCV_CACHE_TTL_MS })
    console.log(`  [Cache] SET ${cacheKey} (${bars.length} bars, TTL 4h)`)

    return bars
  }

  /**
   * 获取指数成分股。
   */
  async getIndexComponents(params: {
    indexCode: string
    date?: string
  }): Promise<Array<{ ticker: string; name: string; weight: number }>> {
    const cacheKey = `index:${params.indexCode}:${params.date || 'latest'}`
    const cached = cache.get(cacheKey)
    if (cached && Date.now() < cached.expiresAt) {
      console.log(`  [Cache] HIT ${cacheKey}`)
      return cached.data
    }

    // 映射指数代码
    const tushareIndexCode = mapIndexCode(params.indexCode)

    // 获取最近日期的成分股
    const queryParams: Record<string, string> = {
      index_code: tushareIndexCode,
    }

    if (params.date) {
      queryParams.start_date = toTushareDate(params.date)
      queryParams.end_date = toTushareDate(params.date)
    } else {
      // 取最近一个月
      const now = new Date()
      const oneMonthAgo = new Date(now.getTime() - 30 * 24 * 60 * 60 * 1000)
      queryParams.start_date = toTushareDate(oneMonthAgo.toISOString().slice(0, 10))
      queryParams.end_date = toTushareDate(now.toISOString().slice(0, 10))
    }

    const response = await this.callTushare(
      'index_weight',
      queryParams,
      'index_code,con_code,con_name,weight,trade_date',
    )

    if (!response.data?.items) return []

    const { fields, items } = response.data

    // 每个成分股可能有多条（不同日期），取最新日期的
    const latestByTicker = new Map<string, { ticker: string; name: string; weight: number }>()

    for (const row of items) {
      const rowData: Record<string, any> = {}
      for (let i = 0; i < fields.length; i++) {
        rowData[fields[i]] = row[i]
      }

      const ticker = rowData.con_code as string
      const existing = latestByTicker.get(ticker)
      if (!existing || (rowData.trade_date > (existing as any)._tradeDate)) {
        latestByTicker.set(ticker, {
          ticker,
          name: rowData.con_name || ticker,
          weight: Number(rowData.weight) || 0,
        })
      }
    }

    const result = Array.from(latestByTicker.values())
      .sort((a, b) => b.weight - a.weight)

    cache.set(cacheKey, { data: result, expiresAt: Date.now() + INDEX_CACHE_TTL_MS })
    console.log(`  [Cache] SET ${cacheKey} (${result.length} components, TTL 24h)`)

    return result
  }

  private async callTushare(
    apiName: string,
    params: Record<string, string | number>,
    requestFields: string,
  ): Promise<TushareResponse> {
    console.log(`  [Tushare] POST ${apiName} ts_code=${params.ts_code || params.index_code}`)

    const response = await fetch(this.baseUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        api_name: apiName,
        token: this.token,
        params,
        fields: requestFields,
      }),
    })

    if (!response.ok) {
      throw new Error(`Tushare API HTTP error: ${response.status}`)
    }

    const json = await response.json() as TushareResponse

    if (json.code !== 0) {
      if (json.msg?.includes('token') || json.msg?.includes('权限')) {
        throw new Error(`Invalid Tushare token: ${json.msg}`)
      }
      throw new Error(`Tushare API error (code ${json.code}): ${json.msg}`)
    }

    return json
  }
}
```

## 4. 合约测试

文件路径：`server/services/__tests__/tushare-market.test.ts`

```typescript
import { describe, it, expect, beforeAll } from 'bun:test'
import { TushareMarketService } from '../tushare-market'

const TUSHARE_TOKEN = process.env.TUSHARE_TOKEN || ''
const SKIP_REAL = !TUSHARE_TOKEN

describe('TushareMarketService', () => {
  describe.skipIf(SKIP_REAL)('Real API', () => {
    let service: TushareMarketService

    beforeAll(() => {
      service = new TushareMarketService(TUSHARE_TOKEN)
    })

    it('should return daily OHLCV for 600519.SH', async () => {
      const bars = await service.getOHLCV({
        ticker: '600519.SH',
        startDate: '2024-01-02',
        endDate: '2024-03-29',
        freq: 'D',
      })

      expect(bars.length).toBeGreaterThanOrEqual(50)
      for (const bar of bars) {
        expect(bar.date).toMatch(/^\d{4}-\d{2}-\d{2}$/)
        expect(bar.open).toBeGreaterThan(0)
        expect(bar.high).toBeGreaterThanOrEqual(bar.low)
        expect(bar.close).toBeGreaterThan(0)
        expect(bar.volume).toBeGreaterThan(0)
      }
    })

    it('should return bars sorted by date ascending', async () => {
      const bars = await service.getOHLCV({
        ticker: '600519.SH',
        startDate: '2024-01-02',
        endDate: '2024-03-29',
      })

      for (let i = 1; i < bars.length; i++) {
        expect(bars[i].date >= bars[i - 1].date).toBe(true)
      }
    })

    it('should return weekly bars', async () => {
      const bars = await service.getOHLCV({
        ticker: '600519.SH',
        startDate: '2024-01-02',
        endDate: '2024-03-29',
        freq: 'W',
      })

      expect(bars.length).toBeLessThan(20)
      expect(bars.length).toBeGreaterThanOrEqual(10)
    })

    it('should return empty for invalid date range', async () => {
      const bars = await service.getOHLCV({
        ticker: '600519.SH',
        startDate: '2024-12-31',
        endDate: '2024-01-01',
      })
      expect(bars).toEqual([])
    })

    it('should return HS300 index components', async () => {
      const components = await service.getIndexComponents({
        indexCode: '000300.SH',
      })

      expect(components.length).toBeGreaterThanOrEqual(290)
      expect(components[0].ticker).toBeDefined()
      expect(components[0].weight).toBeGreaterThan(0)
    })

    it('should cache OHLCV results', async () => {
      const params = { ticker: '000001.SH', startDate: '2024-01-02', endDate: '2024-01-31' } as const
      await service.getOHLCV(params)

      const t = performance.now()
      await service.getOHLCV(params)
      expect(performance.now() - t).toBeLessThan(10)
    })
  })
})
```

## 5. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | Tushare `vol` 单位是手（100 股），`amount` 是千元 | 转换：`volume = vol * 100`，`amount = amount * 1000` |
| T2 | 沪深 300 在 `index_weight` API 中代码是 `399300.SZ` 而非 `000300.SH` | `INDEX_CODE_MAP` 映射，对用户透明 |
| T3 | 行情数据按日期降序返回 | 查询后 `sort((a, b) => a.date.localeCompare(b.date))` 升序 |
| T4 | 停牌日无数据、vol=0 | 不过滤停牌日（保留 vol=0 的记录），用户可能需要知道停牌 |
| T5 | 指数成分股在不同日期变化（调入/调出） | `getIndexComponents` 取最新日期的快照 |
| T6 | Tushare 限频 + 批量查询多标的 | 串行查询，每次请求间自动有网络延迟 |
| T7 | 涨跌幅 `pct_chg` 可能为 null（新股首日） | 用可选字段 `change_pct?: number` |
| T8 | 缓存 4h vs 24h | OHLCV 用 4h（盘中数据变化），指数成分用 24h（低频变动） |
