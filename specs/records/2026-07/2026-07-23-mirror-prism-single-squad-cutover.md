## Design

- Generic delivery is one Mission stage: squad `prism`, workflow `mirror-prism-generic`.
- AInvest delivery is one Mission stage: squad `prism`, workflow `mirror-prism-ainvest`.
- The manifest owns exact node dependencies. Mission owns bootstrap, one delivery Task, recovery Task sequencing, and final evidence.
- The PRD general researcher materializes one canonical system-project contract. Its accepted route set exactly matches every independently useful, evidence-qualified route in the acquired materials inside the authorized boundary. It neither invents routes to meet a minimum nor omits them to meet a maximum; material insufficiency, not route count, blocks delivery.
- Task-scoped Requirements/Architect nodes decompose that contract into route-disjoint local Goals; goal-scoped workers implement and independently review those Goals; task-scoped integrators enumerate every expected Goal ID and always assemble the shared shell, navigation, shared data/state, global states, and cross-route journeys before closing a phase.
- Reuse the existing Author, Page Designer, Implementer, and Reviewer agents under distinct mandatory manifest node IDs for convergence and recheck. A no-change convergence still emits real verification evidence; there are no optional nodes or automatic retry edges.
- Add one writable Design integration implementer and one writable Code integration implementer between each read-only task review and its terminal recheck; the final package therefore projects 31 agents.
- Restore two Code passes: initial production implementation, then explicit interaction/state/navigation/accessibility expansion before visual review. Visual findings then receive one mandatory correction and recheck before task-scoped integrity.
- Review & Debug and MirrorTest remain separate recovery/retest owners to preserve independent product-fix and audit responsibility.
