## Causal correction

The current package incorrectly uses input identity to choose output identity:
a non-AInvest reference selects `mirror-prism-generic`, which omits the mapper
and commands downstream workers not to use AInvest authority. Prism's real
contract fixes the output identity to AInvest; the reference identity only
changes the observed product evidence. The repair deletes that false choice.

The sole workflow remains named `mirror-prism-ainvest` because its product and
design destination is AInvest. Its first node observes arbitrary operator-
named reference products, the general researcher turns those observations into
the canonical system contract, and the mapper projects the relevant AInvest
Wiki closure onto every accepted route before planning.
