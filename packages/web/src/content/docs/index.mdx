## What it is

Coding agents write code. Their raw output is **unreliable**: no spec, no acceptance criteria, no retries, no durable state.

OpenCorvus wraps one-shot code generation into a **repeatable, evidence-driven, self-healing development workflow**. You hand it a task; the orchestrator chooses between a direct build or the pipeline workflow: optional research/design, intent analysis, requirements, architecture, per-goal build, and integrity review.

## Core capabilities

| Capability | Summary |
|---|---|
| **Requirements capture** | A Requirements agent turns vague requests into testable requirements and foundational decisions |
| **Architecture decomposition** | The Architect agent turns requirements into independently buildable goals with acceptance specs and dependency contracts |
| **Multi-executor dispatch** | Built-in OpenCorvus; auto-discovers and dispatches to Codex / Claude Code |
| **Integrity-driven review** | Build evidence, specialist checks, visual/runtime evidence, and LLM review are consolidated by the integrity stage |
| **Multi-channel reach** | Local TUI, HTTP API, Overlay desktop app, 14 IM channels (Slack/Telegram/Feishu/Discord/…) |
| **Durable state** | Tasks, requirements, plans, goals, runs, artifacts, interactions, acceptance rows, and evaluations persist to SQLite |
| **Human-in-the-loop** | `ask/allow/deny` permissions, follow-up messages, manual feedback, all embeddable in unattended pipelines |

## Three-layer architecture

```
┌─ Channel layer ──────────────────────────────────────────┐
│  Local TUI / Overlay UI / HTTP API / 14 IM channels      │
├─ Orchestrator layer ─────────────────────────────────────┤
│  Orchestrator → workflow tools → per-goal build → review │
│  (SQLite persistence + permissions + budgets + artifacts)│
├─ Executor layer ─────────────────────────────────────────┤
│  OpenCorvus kernel / Codex / Claude Code                 │
└──────────────────────────────────────────────────────────┘
```

## Quick start

```bash
curl -fsSL https://github.com/yangheng95/argus/releases/latest/download/install.sh | bash
cd /path/to/your/repo
opencorvus serve
# open http://127.0.0.1:7878/ui/
```
