按类别整理的全量环境变量清单。来源：`packages/opencorvus/src/flag/flag.ts`、`script/benchmark/env.ts`、`packages/channel-runtime/.env.example`。

## 核心

| 变量 | 用途 | 默认值 |
|---|---|---|
| `OPENCORVUS_HOME` | 本地数据目录 | `~/.opencorvus` |
| `OPENCORVUS_CONFIG_DIR` | 配置文件目录 | 系统 managed |
| `OPENCORVUS_CONFIG_CONTENT` | 运行时注入的 JSON 配置 | 无 |
| `OPENCORVUS_PROJECT_DIR` | 默认项目工作目录 | `cwd()` |
| `OPENCORVUS_CHANNEL` | 运行通道 | `local` \| `slack` \| …  |
| `OPENCORVUS_DEFAULT_MODEL` | 默认 LLM 模型 | 自动探测 |

## 服务端

| 变量 | 用途 | 默认值 |
|---|---|---|
| `OPENCORVUS_SERVER_PASSWORD` | HTTP Basic Auth 密码（对外必设） | 无 |
| `OPENCORVUS_SERVER_URL` | 客户端默认连接地址 | `http://127.0.0.1:7878` |

## Executor / Timeout

| 变量 | 用途 | 默认值 |
|---|---|---|
| `OPENCORVUS_AUTO_DISCOVER_EXECUTORS` | 自动发现 codex / claude-code | `0` |
| `OPENCORVUS_EXECUTOR_CLAUDE_PERMISSION_MODE` | Claude executor 权限模式 | `ask` |
| `OPENCORVUS_EXECUTOR_CODEX_PERMISSION_MODE` | Codex executor 权限模式 | `ask` |
| `OPENCORVUS_TOOL_TIMEOUT_MS` | 单工具调用无活动超时 | 无全局默认（按工具类型单独控制） |
| `OPENCORVUS_GOAL_RUN_TIMEOUT_MS` | Goal 运行上限 | 无限 |
| `OPENCORVUS_DECISION_INACTIVITY_MS` | Orchestrator 决策无活动超时 | 600000 |
| `OPENCORVUS_INTERACTION_TIMEOUT_MS` | 交互请求超时 | 30000（`src/orchestrator/runtime.ts:76`） |

## 权限

| 变量 | 用途 | 默认值 |
|---|---|---|
| `OPENCORVUS_PERMISSION_TIMEOUT_MS` | 未回复权限 ask 的拒绝超时 | 300000 |
| `OPENCORVUS_CHANNEL_PERMISSION_PROFILE` | Channel 权限模板 | `standard` |

`OPENCORVUS_CHANNEL_PERMISSION_PROFILE` 合法值：`restricted / standard / permissive / passthrough`。

## Plugin / Skills

| 变量 | 用途 |
|---|---|
| `OPENCORVUS_DISABLE_EXTERNAL_SKILLS=1` | 跳过 `.claude/` 与 `.agents/` 目录的 skill 发现 |
| `OPENCORVUS_DISABLE_CLAUDE_CODE_SKILLS=1` | 同上，仅针对 `.claude/skills/` |

## Overlay

| 变量 | 用途 |
|---|---|
| `OPENCORVUS_OVERLAY_BIN` | overlay 二进制路径覆盖 |
| `OPENCORVUS_OVERLAY_DISABLED=1` | 禁用 overlay |
| `OPENCORVUS_OVERLAY_SINGLETON_MODE` | `kill-old-start-new` \| `reuse` |
| `OPENCORVUS_OVERLAY_RETRY_BASE_MS` | 重试退避起点 |
| `OPENCORVUS_OVERLAY_CIRCUIT_*` | 熔断器调优 |

## LLM Provider（按平台）

### 通用

| 变量 | 说明 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic |
| `OPENAI_API_KEY` | OpenAI |
| `GOOGLE_GENERATIVE_AI_API_KEY` | Google AI |
| `DEEPSEEK_API_KEY` | DeepSeek |
| `OPENROUTER_API_KEY` | OpenRouter |

### DashScope (阿里云)

| 变量 | 说明 |
|---|---|
| `DASHSCOPE_API_KEY` | 标准 intl endpoint（`sk-` 前缀） |
| `CODING_DASHSCOPE_API_KEY` | Coding Plan 专线（`sk-sp-` 前缀） |
| `DASHSCOPE_CODING_BASE_URL` | Coding 接入地址 |
| `DASHSCOPE_INTL_BASE_URL` | 标准接入地址 |
| `ALIBABA_CODING_PLAN_API_KEY` | Coding Plan 专用 Key（与上同值或独立） |

### Model override

| 变量 | 说明 |
|---|---|
| `OPENCORVUS_MODEL_ALIBABA` | Alibaba 交互默认模型 |
| `OPENCORVUS_MODEL_ANTHROPIC` | Anthropic 交互默认模型 |
| `OPENCORVUS_MODEL_OPENAI` | OpenAI 交互默认模型 |
| `OPENCORVUS_MODEL_GOOGLE` | Google 交互默认模型 |
| `OPENCORVUS_MODEL_DEEPSEEK` | DeepSeek 交互默认模型 |
| `OPENCORVUS_MODEL_OPENROUTER` | OpenRouter 交互默认模型 |
| `OPENCORVUS_VISION_MODEL` | Vision / 截图理解模型 |
| `OPENCORVUS_BENCHMARK_MODEL` | Benchmark 指定模型（不被 Gateway 读取，需写 cfg.model） |

## STT（语音识别）

| 变量 | 说明 |
|---|---|
| `STT_PROVIDERS` | 优先顺序（`groq,openai-whisper,deepgram,google-gemini,local-cli`） |
| `STT_LANGUAGE` | 识别语言（`zh` / `en` / …） |
| `GROQ_API_KEY` / `STT_GROQ_MODEL` / `STT_GROQ_BASE_URL` | Groq |
| `STT_OPENAI_MODEL` / `STT_OPENAI_BASE_URL` | OpenAI Whisper |
| `DEEPGRAM_API_KEY` / `STT_DEEPGRAM_*` | Deepgram |
| `GOOGLE_API_KEY` / `STT_GOOGLE_*` | Google Gemini |
| `STT_LOCAL_COMMAND` | 本地 CLI 命令（如 whisper） |

## Channels

每个 channel 的 env 见对应 [channels/*](../channels/overview.md) 页。

## Benchmark / Testing

| 变量 | 说明 |
|---|---|
| `TEST_PROMPT` | 启动后自动注入的测试 prompt |
| `SLACK_CHANNEL_ID` | 配合 `TEST_PROMPT` 使用 |
| `SSL_CERT_FILE` | 额外 CA 证书（企业内网） |

## Shared Session / Overlay 集成

| 变量 | 说明 |
|---|---|
| `OPENCORVUS_CHANNEL_SERVER_URL` | channel-runtime 连接的后端地址（通常由 overlay 注入） |
| `OPENCORVUS_SHARED_SESSION_MODE=1` | 共享会话模式 |
| `OPENCORVUS_SHARED_SESSION_FILE` | 共享 session 文件路径 |
| `OPENCORVUS_MIRROR_STDOUT=1` | 镜像 stdout 到外层 |

## 内部变量（勿手动设置）

`OPENCORVUS_OVERLAY_MODE`、`OPENCORVUS_OVERLAY_STDIN_EXIT`、`OPENCORVUS_EMBEDDED_OVERLAY_B64`、`OPENCORVUS_EMBEDDED_OVERLAY_HASH` —— 由父进程注入。
