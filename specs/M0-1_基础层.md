# AimeCode M0-1 · 基础层

> **自包含文档**：一个 AI 模型只读这一个文件，就能从零实现整个基础层。
> **不包含**：React UI 组件（M0-2）、Hooks（M0-2）、路由、页面布局。
> **包含**：项目脚手架、类型定义、常量、服务接口、Mock 数据、Mock 场景（S01-S05）、Mock 服务实现、状态管理、服务注册表、最小启动入口。

## 3. 类型定义（types.ts）

文件路径：`src/services/types.ts`

这是全项目的类型中心。所有其他文件从这里 import 类型。不 import 任何项目内文件。

```typescript
// ── StreamEvent（discriminated union）──────────────────────────
// 使用 discriminated union 而非可选字段 interface。
// 好处：TypeScript 在 switch(event.type) 分支中自动收窄类型，
// 消费端无需 null check，编译器保证每个分支的字段一定存在。

export type StreamEvent =
  | { type: 'thinking';    content: string }
  | { type: 'tool_start';  tool: string; source: string; params?: Record<string, unknown> }
  | { type: 'tool_end';    tool: string; source: string; summary?: string }
  | { type: 'tool_error';  tool: string; source: string; error: string }
  | { type: 'text_delta';  delta: string }
  | { type: 'code_block';  language: string; code: string }
  | { type: 'chart_data';  chartSpec: object }
  | { type: 'table_data';  columns: string[]; rows: unknown[][] }
  | { type: 'disclaimer' }
  | { type: 'done';        messageId: string }
  | { type: 'error';       content: string }
  | { type: 'usage';       inputTokens: number; outputTokens: number }
  // usage 事件由 AnthropicLLMService 在 done 之前 emit，用于 Token 预算统计（M0.5 引入）

export type StreamEventType = StreamEvent['type']

// ── ContentBlock（渲染用）──────────────────────────────────────
export type ContentBlock =
  | { type: 'text';       content: string }
  | { type: 'code';       language: string; code: string }
  | { type: 'chart';      spec: object }
  | { type: 'table';      columns: string[]; rows: unknown[][] }
  | { type: 'disclaimer'; content: string }

// ── 工具调用记录 ─────────────────────────────────────────────
// 从流式状态持久化到 Message，用于历史消息恢复 ToolCallBadge。
export interface ToolCallRecord {
  tool: string
  source: string
  status: 'pending' | 'done' | 'error'
  params?: Record<string, unknown>
  summary?: string
  errorMessage?: string
}

// ── 消息 ──────────────────────────────────────────────────────
export type MessageRole = 'user' | 'assistant'

export interface Message {
  id: string
  role: MessageRole
  content: string
  contentBlocks?: ContentBlock[]
  toolCalls?: ToolCallRecord[]   // 工具调用历史（持久化，历史消息恢复 ToolCallBadge 用）
  thinkingText?: string           // 思考过程文本（持久化）
  createdAt: Date
}

// ── 工具定义（Anthropic Tool Use 格式）────────────────────────
export interface ToolDefinition {
  name: string
  description: string
  input_schema: {
    type: 'object'
    properties: Record<string, unknown>
    required?: string[]
  }
}

export interface ChatOptions {
  tools?: ToolDefinition[]
  systemPrompt?: string
  maxTokens?: number
}

// ── 金融数据 ──────────────────────────────────────────────────
export interface FinancialReport {
  ticker: string
  period: string          // 格式统一为 'YYYY-QN'（如 '2024-Q3'）或 'YYYY'（年报）
  reportDate: string
  fields: Record<string, number | null>
}

export interface OHLCVBar {
  date: string
  open: number
  high: number
  low: number
  close: number
  volume: number
  amount?: number
  turnover?: number
  change_pct?: number
}

// ── 代码执行结果 ──────────────────────────────────────────────
export interface ExecutionResult {
  status: 'ok' | 'error' | 'timeout'
  stdout: string
  stderr: string
  charts: Array<{ id: string; spec: object; imageDataUrl?: string }>
  durationMs: number
}
```

### 5.4 LLM System Prompt

文件路径：`src/services/llm/system-prompt.ts`

```typescript
export const BASE_SYSTEM_PROMPT = `你是 AimeCode，一个面向金融从业者的 AI 分析助手。你的核心能力是将用户的自然语言请求转化为"数据查询 + 代码生成 + 结果呈现"的完整链路。

## 身份与边界

- 你是金融数据分析工具，不是投资顾问。
- 你可以呈现数据、计算指标、生成代码、绘制图表。
- 你绝不提供买卖建议、持仓推荐或市场预测性结论。
- 你生成的所有分析内容仅供参考。

## 工具调用规则

你可以使用以下工具查询金融数据：
- get_financial_report：查询上市公司财报数据（ROE、营收、净利润、毛利率、PE、PB 等）
- get_market_data：查询股票/指数历史行情（OHLCV 日线数据）
- get_index_components：查询指数成分股和权重

调用规则：
1. 用户请求涉及具体公司数据时，必须先调用工具获取真实数据，不可编造或使用训练数据中的记忆。
2. 股票代码格式：xxxxxx.SH（上交所）或 xxxxxx.SZ（深交所）。如果用户说公司名，你需要使用正确的股票代码。系统可能在 system prompt 末尾附加实体预解析结果供你参考。
3. 时间范围：用户未指定时，默认使用最近 1 年。"最近三年"指从今天往前推 3 年。
4. 多标的查询时，对每个标的分别调用工具（最多 5 个并行）。
5. 纯代码请求（"写一个函数"、"帮我优化这段代码"）不要调用任何金融工具。

## 代码生成规则

当需要生成代码时，必须遵守以下规则：

**R1 · 内联数据**：代码中必须使用工具返回的真实数据，以 dict / list 形式硬编码。禁止使用 fetch_data()、YOUR_TICKER、TODO 等任何占位符。

**R2 · 关键步骤注释**：每个逻辑段落前有一行中文注释，说明该步骤目的。

**R3 · 标准库优先**：按优先级使用 pandas / numpy / matplotlib / plotly。不引入未预装的包。

**R4 · 图表自包含**：若代码生成图表，末尾必须调用 fig.show() 或 plt.show()。图表标题使用中文，包含标的名称和时间范围。

代码输出格式：使用 code_block 类型输出，language 字段设为 "python"。

## 输出结构

你的回复应按以下结构组织（根据实际需要选择）：

1. **工具调用**（如需要）：先调用工具获取数据
2. **文字分析**：简要说明数据含义、趋势解读（2-4 句话，不啰嗦）
3. **图表/表格**：如用户要求可视化，输出 Plotly JSON spec（chart_data 类型）或表格数据（table_data 类型）
4. **代码块**：如用户需要可复现的代码，输出完整可运行的 Python 代码（code_block 类型）
5. **免责声明**（如适用）：见下方规则

## 表格输出规则

当输出结构化对比数据时，使用 table_data 类型：
- columns：列名数组，第一列通常是标的名称或时间
- rows：二维数组，数值保持原始精度（不格式化），由客户端负责格式化展示
- 百分比类字段传小数（如 0.921 表示 92.1%），金额类字段传元为单位的原始值

## Plotly 图表输出规则

当输出图表时，使用 chart_data 类型，chartSpec 字段为完整的 Plotly JSON：
- data：trace 数组
- layout：布局配置
- K 线图使用 candlestick trace 类型，MA 线叠加在同一 y 轴
- 振荡指标（MACD/RSI）放在下方 subplot
- 中文标题和轴标签
- Y 轴放在右侧（金融图表惯例）

## 免责声明规则

当你的回复满足以下任一条件时，你必须在流的最末尾 emit 一个 { type: "disclaimer" } 事件：
- 使用了金融工具返回的市场数据、财务数据或行情数据
- 对市场走势、公司基本面、股价表现做出分析或评价
- 包含量化回测或风险计算的结果

纯代码编写、纯算法解释、与金融数据无关的通用回复，不需要 emit disclaimer。

## 对话风格

- 简洁专业，不寒暄
- 使用金融术语但给出必要的解释
- 数据引用要注明来源和截止期
- 一次只做用户要求的事，不主动扩展分析范围
- 如果用户的请求模糊，推断最可能的意图执行，不追问（除非完全无法判断）
```

```typescript
// ── 确定性伪随机数生成器（mulberry32）──────────────────────────
// 不依赖 Math.random()，保证每次运行结果一致
function mulberry32(seed: number) {
  return function(): number {
    seed |= 0; seed = seed + 0x6D2B79F5 | 0
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed)
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t
    return ((t ^ t >>> 14) >>> 0) / 4294967296
  }
}

function isTradingDay(dateStr: string): boolean {
  if (HOLIDAYS_2022_2024.has(dateStr)) return false
  const d = new Date(dateStr)
  const day = d.getUTCDay()
  return day !== 0 && day !== 6 // 排除周末

function getTradingDays(startDate: string, count: number): string[] {
  const days: string[] = []
  const d = new Date(startDate)
  while (days.length < count) {
    const ds = d.toISOString().slice(0, 10)
    if (isTradingDay(ds)) days.push(ds)
    d.setDate(d.getDate() + 1)
  }
  return days
}

// ── GBM 行情数据生成器 ────────────────────────────────────────
interface OHLCVSeed {
  ticker: string
  startDate: string
  startClose: number
  annualVolatility: number
  annualDrift: number
  avgVolume: number
  avgTurnover: number
  seed: number            // mulberry32 种子
}

function generateOHLCV(config: OHLCVSeed, tradingDays: number): OHLCVBar[] {
  const rng = mulberry32(config.seed)
  const days = getTradingDays(config.startDate, tradingDays)
  const bars: OHLCVBar[] = []
  let prevClose = config.startClose

  for (const date of days) {
    // 日收益率：drift/252 + volatility/sqrt(252) * N(0,1)
    // Box-Muller 变换生成正态分布
    const u1 = rng()
    const u2 = rng()
    const z = Math.sqrt(-2 * Math.log(Math.max(u1, 1e-10))) * Math.cos(2 * Math.PI * u2)
    const dailyReturn = config.annualDrift / 252 + (config.annualVolatility / Math.sqrt(252)) * z

    const close = Math.round(prevClose * Math.exp(dailyReturn) * 100) / 100
    const open = Math.round(prevClose * (1 + (rng() - 0.5) * 0.01) * 100) / 100
    const high = Math.round(Math.max(open, close) * (1 + rng() * 0.015) * 100) / 100
    const low = Math.round(Math.min(open, close) * (1 - rng() * 0.015) * 100) / 100
    const volume = Math.round(config.avgVolume * (0.7 + rng() * 0.8))
    const amount = Math.round(volume * (open + close) / 2)
    const turnover = Math.round(config.avgTurnover * (0.7 + rng() * 0.8) * 10000) / 10000
    const change_pct = Math.round((close / prevClose - 1) * 10000) / 10000

    bars.push({ date, open, high, low, close, volume, amount, turnover, change_pct })
    prevClose = close
  }

  return bars
}
```

```typescript
/**
 * 匹配算法：统计命中关键词数量，取最高分；并列时取第一个。
 * 无匹配时抛错——Mock 模式必须覆盖全部测试输入，
 * 未覆盖的输入说明测试用例设计不完整，不能用 defaultScenario 掩盖。
 */
export function detectScenario(input: string): Scenario {
  const lower = input.toLowerCase()
  let best: { score: number; scene: Scenario } | null = null
  for (const { weight, scene } of SCENE_RULES) {
    const score = weight.filter(k => lower.includes(k)).length
    if (score > 0 && (!best || score > best.score)) {
      best = { score, scene }
    }
  }
  if (!best) {
    throw new Error(
      `[MockLLM] 无匹配场景，输入: "${input.slice(0, 50)}"。` +
      `请在 SCENE_RULES 中添加对应场景或检查测试输入。`
    )
  }
  return best.scene
}
```

### 9.2 Session Store

文件路径：`src/stores/session.store.ts`

```typescript
import { create } from 'zustand'
import { persist, createJSONStorage } from 'zustand/middleware'
import type { Message, ContentBlock, StreamEvent, ToolCallRecord } from '../services/types'
import { DISCLAIMER_TEXT } from '../constants/disclaimer'

// 自定义 storage：处理 Date 对象的 JSON hydration。
// Zustand persist 默认 JSON.stringify/parse 会将 Date 序列化为字符串，
// 恢复后类型变为 string，必须在 reviver 中转回 Date。
const dateReviver = (_key: string, value: unknown) =>
  typeof value === 'string' && /^\d{4}-\d{2}-\d{2}T/.test(value)
    ? new Date(value)
    : value

const hydratedStorage = createJSONStorage(() => localStorage, {
  reviver: dateReviver,
})

interface ChatSession {
  id: string
  title: string
  messages: Message[]
  createdAt: Date
}

interface SessionState {
  sessionsById: Record<string, ChatSession>
  sessionOrder: string[]
  currentSessionId: string | null
  isStreaming: boolean
  streamingBlocks: ContentBlock[]
  streamingToolCalls: ToolCallRecord[]  // 当前流式工具调用状态列表
  streamingThinking: string              // 当前流式思考文本

  createSession: () => string
  selectSession: (id: string) => void
  deleteSession: (id: string) => void
  renameSession: (id: string, title: string) => void
  addUserMessage: (content: string) => void
  appendStreamEvent: (event: StreamEvent) => void
  finalizeAssistantMessage: (messageId: string) => void
  setStreaming: (v: boolean) => void
  clearStreamingBlocks: () => void
}

export const useSessionStore = create<SessionState>()(
  persist(
    (set, get) => ({
      sessionsById: {},
      sessionOrder: [],
      currentSessionId: null,
      isStreaming: false,
      streamingBlocks: [],
      streamingToolCalls: [],
      streamingThinking: '',

      createSession: () => {
        const id = crypto.randomUUID()
        const session: ChatSession = {
          id, title: '新对话', messages: [], createdAt: new Date(),
        }
        set(s => ({
          sessionsById: { ...s.sessionsById, [id]: session },
          sessionOrder: [id, ...s.sessionOrder],
          currentSessionId: id,
        }))
        return id
      },

      selectSession: (id) => set({ currentSessionId: id }),

      deleteSession: (id) => set(state => {
        const newById = { ...state.sessionsById }
        delete newById[id]
        const newOrder = state.sessionOrder.filter(s => s !== id)
        const newCurrentId = id === state.currentSessionId
          ? (newOrder[0] ?? null)
          : state.currentSessionId
        return { sessionsById: newById, sessionOrder: newOrder, currentSessionId: newCurrentId }
      }),

      renameSession: (id, title) => set(state => {
        const session = state.sessionsById[id]
        if (!session) return {}
        return {
          sessionsById: { ...state.sessionsById, [id]: { ...session, title } },
        }
      }),

      addUserMessage: (content) => {
        const { currentSessionId, sessionsById } = get()
        if (!currentSessionId) return
        const session = sessionsById[currentSessionId]
        if (!session) return
        const msg: Message = {
          id: crypto.randomUUID(),
          role: 'user', content,
          createdAt: new Date(),
        }
        set({
          sessionsById: {
            ...sessionsById,
            [currentSessionId]: {
              ...session,
              messages: [...session.messages, msg],
              title: session.messages.length === 0 ? content.slice(0, 30) : session.title,
            },
          },
        })
      },

      appendStreamEvent: (event) => {
        set(s => {
          switch (event.type) {
            // ── 思考过程 ──────────────────────────────────────
            case 'thinking':
              return { streamingThinking: event.content }

            // ── 工具调用状态流转 ──────────────────────────────
            case 'tool_start':
              return {
                streamingToolCalls: [
                  ...s.streamingToolCalls,
                  { tool: event.tool, source: event.source, status: 'pending' as const, params: event.params },
                ],
              }
            case 'tool_end': {
              const updated = s.streamingToolCalls.map(tc =>
                tc.tool === event.tool && tc.status === 'pending'
                  ? { ...tc, status: 'done' as const, summary: event.summary }
                  : tc
              )
              return { streamingToolCalls: updated }
            }
            case 'tool_error': {
              const updated = s.streamingToolCalls.map(tc =>
                tc.tool === event.tool && tc.status === 'pending'
                  ? { ...tc, status: 'error' as const, errorMessage: event.error }
                  : tc
              )
              return { streamingToolCalls: updated }
            }

            // ── 内容块追加 ────────────────────────────────────
            case 'text_delta': {
              const blocks = [...s.streamingBlocks]
              const last = blocks.at(-1)
              if (last?.type === 'text') {
                blocks[blocks.length - 1] = { type: 'text', content: last.content + event.delta }
              } else {
                blocks.push({ type: 'text', content: event.delta })
              }
              return { streamingBlocks: blocks }
            }
            case 'code_block':
              return { streamingBlocks: [...s.streamingBlocks, { type: 'code', language: event.language, code: event.code }] }
            case 'chart_data':
              return { streamingBlocks: [...s.streamingBlocks, { type: 'chart', spec: event.chartSpec }] }
            case 'table_data':
              return { streamingBlocks: [...s.streamingBlocks, { type: 'table', columns: event.columns, rows: event.rows }] }
            case 'disclaimer':
              return { streamingBlocks: [...s.streamingBlocks, { type: 'disclaimer', content: DISCLAIMER_TEXT }] }

            // ── 其余事件（done/error/usage）不修改 blocks ─────
            default:
              return {}
          }
        })
      },

      finalizeAssistantMessage: (messageId) => {
        const { currentSessionId, sessionsById, streamingBlocks, streamingToolCalls, streamingThinking } = get()
        if (!currentSessionId) return
        const session = sessionsById[currentSessionId]
        if (!session) return
        const fullText = streamingBlocks
          .filter((b): b is { type: 'text'; content: string } => b.type === 'text')
          .map(b => b.content)
          .join('')
        const msg: Message = {
          id: messageId,
          role: 'assistant',
          content: fullText,
          contentBlocks: streamingBlocks,
          ...(streamingToolCalls.length > 0 && { toolCalls: streamingToolCalls }),
          ...(streamingThinking && { thinkingText: streamingThinking }),
          createdAt: new Date(),
        }
        set({
          sessionsById: {
            ...sessionsById,
            [currentSessionId]: { ...session, messages: [...session.messages, msg] },
          },
          streamingBlocks: [],
          streamingToolCalls: [],
          streamingThinking: '',
          isStreaming: false,
        })
      },

      setStreaming: (v) => set({ isStreaming: v }),
      clearStreamingBlocks: () => set({ streamingBlocks: [], streamingToolCalls: [], streamingThinking: '' }),
    }),
    { name: 'aimecode-sessions', storage: hydratedStorage }
  )
)
```

## 12. 集成陷阱

实现时必须注意的常见错误。

### 陷阱 1：Zustand persist 的 Date hydration

```typescript
// 错误：直接 persist（Date 变成 string，后续 .getTime() 报错）
persist((set) => ({ ... }), { name: 'aimecode-sessions' })

// 正确：自定义 storage 处理 Date 反序列化
import { createJSONStorage } from 'zustand/middleware'
const dateReviver = (_key: string, value: unknown) =>
  typeof value === 'string' && /^\d{4}-\d{2}-\d{2}T/.test(value)
    ? new Date(value)
    : value
const storage = createJSONStorage(() => localStorage, { reviver: dateReviver })
persist((set) => ({ ... }), { name: 'aimecode-sessions', storage })
```

### 陷阱 2：crypto.randomUUID() 在场景文件中

```typescript
// 错误：在模块顶层调用（模块加载时执行，每次 import 生成同一个 ID）
export const s01 = {
  events: [
    { type: 'done', messageId: crypto.randomUUID() },  // 模块加载时执行！
  ]
}

// 正确：在运行时生成
export const s01 = {
  events: [
    { type: 'done', messageId: '' },  // 占位
  ]
}
// MockLLMService.chat() 中覆盖：
// if (event.type === 'done') yield { ...event, messageId: crypto.randomUUID() }
```

### 陷阱 3：StreamEvent discriminated union 的消费

```typescript
// 错误：用 if + 可选链（绕过类型收窄）
if (event.type === 'text_delta') {
  yield { type: 'text_delta', delta: event.delta ?? '' }  // delta 不可能是 undefined！
}

// 正确：switch + 直接访问（TypeScript 自动收窄）
switch (event.type) {
  case 'text_delta':
    yield { type: 'text_delta', delta: event.delta }  // event.delta: string（保证存在）
    break
}
```

### 陷阱 4：Anthropic SDK 浏览器端使用

```typescript
// 错误：默认配置（会报 CORS 错误或安全警告）
const client = new Anthropic({ apiKey })

// 正确：显式允许浏览器端使用
const client = new Anthropic({ apiKey, dangerouslyAllowBrowser: true })
```

### 陷阱 5：Plotly.js 包导入（M0-2 阶段使用，此处预告）

```typescript
// 错误：导入完整包（8MB，首屏 10 秒）
import Plotly from 'plotly.js'

// 正确：导入最小化包
import createPlotlyComponent from 'react-plotly.js/factory'
import Plotly from 'plotly.js-dist-min'
const Plot = createPlotlyComponent(Plotly)
```
