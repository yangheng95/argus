> **自包含文档**：一个 AI 模型只读这一个文件，就能将前端从 Mock 模式切换为请求真实后端 API。
> **前置条件**：M0-2（前端 UI 完整）+ M0-4（API Client 骨架）+ M1-1（API 框架）+ M1-2（数据库）+ M1-3/M1-4（真实数据服务）已完成。

> **不包含**：设置 UI（M2-2）、HTCR 评测（M2-3）、后端实现细节。

## 2. 架构变更

### 2.1 切换前后对比

```
切换前（Mock 模式）:
  React UI → useChat Hook → MockLLMService (浏览器内)
                           → MockFinanceService (浏览器内)

切换后（Real 模式）:
  React UI → useChat Hook → ApiChatService → HTTP/SSE → Bun API Server
                                                          ├→ LLM Service
                                                          ├→ Finance Service
                                                          └→ Executor Service
```

### 2.2 关键原则

- **useChat Hook 接口不变**：组件层完全不感知 Mock/Real 切换
- **切换粒度**：一个布尔值 `useServerApi` 切换整个数据层
- **渐进式**：可以只切 LLM 为 Real（用真实 Claude），数据仍用 Mock

## 4. SSE 流解析器

文件路径：`src/services/api/sse-parser.ts`

```typescript
import type { StreamEvent } from '../types'

/**
 * 从 fetch Response 中解析 SSE 流，yield StreamEvent。
 *
 * SSE 格式：
 *   event: <type>\n
 *   data: <json>\n
 *   \n
 *
 * 注意事项：
 * - 浏览器的 EventSource 只支持 GET，我们用 POST + fetch + ReadableStream
 * - data 字段可能跨多行（Hono streamSSE 会自动处理）
 * - ping 事件需要跳过
 */
export async function* parseSSEStream(
  response: Response,
  signal?: AbortSignal,
): AsyncGenerator<StreamEvent, void, unknown> {
  const reader = response.body!.getReader()
  const decoder = new TextDecoder()
  let buffer = ''

  try {
    while (true) {
      if (signal?.aborted) break

      const { done, value } = await reader.read()
      if (done) break

      buffer += decoder.decode(value, { stream: true })

      // 按双换行分割事件
      const parts = buffer.split('\n\n')
      buffer = parts.pop() || ''

      for (const part of parts) {
        if (!part.trim()) continue

        let eventType = ''
        let data = ''

        for (const line of part.split('\n')) {
          if (line.startsWith('event: ')) {
            eventType = line.slice(7).trim()
          } else if (line.startsWith('data: ')) {
            data += line.slice(6)
          } else if (line.startsWith('data:')) {
            data += line.slice(5)
          }
        }

        // 跳过心跳
        if (eventType === 'ping') continue

        if (data) {
          try {
            const parsed = JSON.parse(data) as StreamEvent
            yield parsed
          } catch {
            console.warn('[SSE] Failed to parse event data:', data.slice(0, 100))
          }
        }
      }
    }
  } finally {
    reader.releaseLock()
  }
}
```

## 5. API Chat Service

文件路径：`src/services/api/api-chat-service.ts`

```typescript
import type { ILLMService } from '../llm/interface'
import type { Message, StreamEvent, ChatOptions } from '../types'
import { parseSSEStream } from './sse-parser'

const API_BASE = import.meta.env.VITE_API_BASE_URL || 'http://localhost:3001'

export class ApiChatService implements ILLMService {
  private controller: AbortController | null = null
  private apiKey: string
  private tushareToken?: string

  constructor(apiKey: string, tushareToken?: string) {
    this.apiKey = apiKey
    this.tushareToken = tushareToken
  }

  async *chat(
    messages: Message[],
    options?: ChatOptions & { sessionId?: string },
  ): AsyncGenerator<StreamEvent, void, unknown> {
    this.controller = new AbortController()

    // 构建 Authorization header
    const authToken = this.tushareToken
      ? `${this.apiKey}:${this.tushareToken}`
      : this.apiKey

    const sessionId = (options as any)?.sessionId
    const lastMessage = messages[messages.length - 1]

    const response = await fetch(`${API_BASE}/api/chat`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${authToken}`,
      },
      body: JSON.stringify({
        sessionId,
        message: lastMessage.content,
        options: options ? {
          maxTokens: options.maxTokens,
          systemPromptOverride: options.systemPrompt,
        } : undefined,
      }),
      signal: this.controller.signal,
    })

    if (!response.ok) {
      const error = await response.json().catch(() => ({ error: { message: `HTTP ${response.status}` } }))
      yield {
        type: 'error',
        content: error.error?.message || `请求失败 (${response.status})`,
      }
      return
    }

    // 解析 SSE 流
    yield* parseSSEStream(response, this.controller.signal)
  }

  abort(): void {
    this.controller?.abort()
    this.controller = null
  }
}
```

## 6. API Session Service

文件路径：`src/services/api/api-session-service.ts`

```typescript
const API_BASE = import.meta.env.VITE_API_BASE_URL || 'http://localhost:3001'

export interface RemoteSession {
  id: string
  title: string
  createdAt: string
  updatedAt: string
  messageCount: number
}

export interface RemoteMessage {
  id: string
  sessionId: string
  role: 'user' | 'assistant'
  content: string
  contentBlocks?: any[]
  toolCalls?: any[]
  thinkingText?: string
  createdAt: string
}

class ApiSessionService {
  private getHeaders(): HeadersInit {
    return { 'Content-Type': 'application/json' }
  }

  async createSession(): Promise<RemoteSession> {
    const res = await fetch(`${API_BASE}/api/sessions`, {
      method: 'POST',
      headers: this.getHeaders(),
    })
    if (!res.ok) throw new Error(`Create session failed: ${res.status}`)
    return res.json()
  }

  async listSessions(): Promise<RemoteSession[]> {
    const res = await fetch(`${API_BASE}/api/sessions`, {
      headers: this.getHeaders(),
    })
    if (!res.ok) throw new Error(`List sessions failed: ${res.status}`)
    return res.json()
  }

  async getMessages(sessionId: string): Promise<RemoteMessage[]> {
    const res = await fetch(`${API_BASE}/api/sessions/${sessionId}/messages`, {
      headers: this.getHeaders(),
    })
    if (!res.ok) throw new Error(`Get messages failed: ${res.status}`)
    return res.json()
  }

  async updateTitle(sessionId: string, title: string): Promise<void> {
    const res = await fetch(`${API_BASE}/api/sessions/${sessionId}`, {
      method: 'PATCH',
      headers: this.getHeaders(),
      body: JSON.stringify({ title }),
    })
    if (!res.ok) throw new Error(`Update title failed: ${res.status}`)
  }

  async deleteSession(sessionId: string): Promise<void> {
    const res = await fetch(`${API_BASE}/api/sessions/${sessionId}`, {
      method: 'DELETE',
      headers: this.getHeaders(),
    })
    if (!res.ok) throw new Error(`Delete session failed: ${res.status}`)
  }

  async checkHealth(): Promise<{ status: string; mode: string }> {
    const res = await fetch(`${API_BASE}/api/health`)
    if (!res.ok) throw new Error('Server unreachable')
    return res.json()
  }
}

export const apiSessionService = new ApiSessionService()
```

## 8. Registry 适配

文件路径：`src/services/registry.ts`（修改）

```typescript
import { useConfigStore } from '@/stores/config.store'
import type { ILLMService } from './llm/interface'
import { MockLLMService } from '@/mocks/services/mock-llm'
import { ApiChatService } from './api/api-chat-service'

let cachedLLMService: ILLMService | null = null

export function getLLMService(): ILLMService {
  const config = useConfigStore.getState()

  if (config.useServerApi && config.anthropicApiKey) {
    // Real 模式：通过 API Server 代理
    if (!cachedLLMService || !(cachedLLMService instanceof ApiChatService)) {
      cachedLLMService = new ApiChatService(
        config.anthropicApiKey,
        config.tushareToken || undefined,
      )
    }
    return cachedLLMService
  }

  // Mock 模式：浏览器内 Mock
  if (!cachedLLMService || !(cachedLLMService instanceof MockLLMService)) {
    cachedLLMService = new MockLLMService()
  }
  return cachedLLMService
}

export function resetServiceCache(): void {
  if (cachedLLMService && 'abort' in cachedLLMService) {
    (cachedLLMService as ILLMService).abort()
  }
  cachedLLMService = null
}
```

## 9. useChat Hook 适配

文件路径：`src/hooks/useChat.ts`（关键修改）

```typescript
// useChat 的核心变更：
// 1. 在 API 模式下，不再本地管理消息——消息由后端持久化
// 2. 在 API 模式下，sessionId 必须先通过 API 创建
// 3. 错误处理增加网络错误

import { useCallback } from 'react'
import { useSessionStore } from '@/stores/session.store'
import { useConfigStore } from '@/stores/config.store'
import { getLLMService, resetServiceCache } from '@/services/registry'
import { apiSessionService } from '@/services/api/api-session-service'
import type { StreamEvent } from '@/services/types'

export function useChat() {
  const {
    currentSessionId,
    addUserMessage,
    appendStreamEvent,
    finalizeAssistantMessage,
    setStreaming,
    isStreaming,
  } = useSessionStore()

  const { useServerApi } = useConfigStore()

  const sendMessage = useCallback(async (content: string) => {
    if (!content.trim() || isStreaming) return

    let sessionId = currentSessionId

    // API 模式下确保会话存在于后端
    if (useServerApi && !sessionId) {
      try {
        const session = await apiSessionService.createSession()
        sessionId = session.id
        // 同步到本地 store
        useSessionStore.getState().createSessionWithId(session.id, session.title)
      } catch (err) {
        appendStreamEvent({ type: 'error', content: '无法连接服务器，请检查后端是否启动' })
        return
      }
    }

    if (!sessionId) {
      sessionId = useSessionStore.getState().createSession()
    }

    addUserMessage(content)
    setStreaming(true)

    try {
      const llmService = getLLMService()
      const messages = useSessionStore.getState().getCurrentMessages()

      const eventStream = llmService.chat(messages, {
        sessionId, // API 模式下传递给后端
      } as any)

      for await (const event of eventStream) {
        appendStreamEvent(event)

        if (event.type === 'done') {
          finalizeAssistantMessage(event.messageId)
        }
        if (event.type === 'error') {
          break
        }
      }
    } catch (err: any) {
      if (err.name === 'AbortError') {
        // 用户主动停止，不报错
      } else {
        const message = err.message?.includes('fetch')
          ? '网络连接失败，请检查后端服务是否运行'
          : err.message || '未知错误'
        appendStreamEvent({ type: 'error', content: message })
      }
    } finally {
      setStreaming(false)
    }
  }, [currentSessionId, isStreaming, useServerApi])

  const stopGeneration = useCallback(() => {
    const llmService = getLLMService()
    llmService.abort()
    setStreaming(false)
  }, [])

  return { sendMessage, stopGeneration, isStreaming }
}
```

## 10. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | SSE 用 POST 不能用 `EventSource` | 用 `fetch` + `ReadableStream` + 手写 SSE 解析器 |
| T2 | `fetch` abort 后 reader.read() 抛 `AbortError` | 在 `parseSSEStream` 的 finally 中 `reader.releaseLock()` |
| T3 | 浏览器缓冲 SSE 数据（不逐字到达） | 后端已设 `Cache-Control: no-cache`；前端不依赖逐字节到达 |
| T4 | Mock ↔ Real 切换时旧 service 残留 | `resetServiceCache()` 在切换时调用，abort 旧 stream |
| T5 | API 模式下会话 ID 由后端生成 | `createSessionWithId(id)` 允许前端用后端返回的 ID |
| T6 | 刷新页面后需要从 API 重新加载会话列表 | session store init 时判断 `useServerApi`，若为 true 则 `apiSessionService.listSessions()` |
| T7 | 网络错误 vs LLM 错误的区分 | `fetch` 失败 = 网络错误；SSE 中 `event: error` = LLM/业务错误 |
| T8 | CORS 的 `Authorization` header | CORS 中间件已允许 `Authorization` header |
