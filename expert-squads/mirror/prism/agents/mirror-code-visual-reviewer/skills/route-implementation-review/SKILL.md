# Route implementation review

- Launch the real assembled task-scoped subsystem, enter through canonical and supported deep links, and exercise every closure member, associated-subpage journey, shared-state continuation, forward/back transition, recovery, interaction, navigation endpoint, state, keyboard/focus path, accessibility behavior, and reduced motion.
- Compare the implementation with the approved Prism-authored design and Product Requirements evidence. Never compare it with target or competitor screenshots.
- Inspect console, runtime, asset, network, and layout diagnostics.
- Report exact Critical, Major, and Minor discrepancies without editing.
- Use current final bytes and fresh per-member/per-journey evidence to issue one terminal subsystem verdict; reject mocked targets, string screenshot references, DOM-only checks, stale screenshots, or representative-page sampling.
