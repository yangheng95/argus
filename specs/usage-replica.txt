Replicate the Claude Settings → Usage page shown in the attached reference image (usage.png).

Build a working single-page application using vanilla HTML + CSS + JavaScript (no frameworks, no external CDN dependencies). All code must be inline in src/index.html.

## Architecture

### Data Layer
All UI data must come from a single JavaScript data object at the top of the <script> block, not hardcoded into HTML:

```js
const usageData = {
  plan: {
    currentSession: { used: 14, max: 100, resetIn: "3 hr 48 min", maxMultiplier: "20x" },
  },
  weeklyLimits: {
    allModels: { used: 63, max: 100, resetIn: "19 hr 48 min" },
    sonnetOnly: { used: 15, max: 100, resetLabel: "Resets Wed 4:00 PM" },
    lastUpdated: "3 minutes ago",
  },
  extraUsage: {
    enabled: true,
    spent: 0.00,
    resetDate: "May 1",
    monthlyLimit: 20,
    balance: 200.00,
    autoReload: false,
  },
  navigation: [
    { label: "General", active: false },
    { label: "Account", active: false },
    { label: "Privacy", active: false },
    { label: "Billing", active: false },
    { label: "Usage", active: true },
    { label: "Capabilities", active: false },
    { label: "Connectors", active: false },
    { label: "Claude Code", active: false },
    { label: "Claude in Chrome", active: false, badge: "Beta" },
  ],
}
```

### Component Structure
Build these as reusable render functions that accept data and return DOM elements:

1. **Sidebar component** — renders navigation items from `usageData.navigation`
   - Left icon strip (use inline SVG placeholders for the icon column)
   - Navigation list with active state highlight (left blue border + light background)
   - "Claude in Chrome" has a "Beta" badge (small rounded gray tag)

2. **ProgressBar component** — reusable function: `renderProgressBar({ used, max, label, sublabel, rightLabel })`
   - Rounded track (light gray #e5e7eb background)
   - Filled portion (blue #3b82f6) proportional to used/max
   - Supports percentage display on the right ("14% used", "63% used", etc.)

3. **ToggleSwitch component** — functional toggle that updates state
   - Clicking the toggle flips `extraUsage.enabled` and re-renders the toggle visual
   - Blue when on, gray when off
   - Pill shape with sliding circle

4. **InfoIcon component** — small (i) circle icon rendered as inline SVG
   - Used next to "Sonnet only" and "$20" labels
   - Shows tooltip text on hover

5. **ActionButton component** — `renderButton({ text, variant, badge })`
   - "Adjust limit" — outline style, rounded border
   - "Buy extra usage" — outline with "Up to 30% off" discount badge (coral/orange tag inside button)

## Interactions
- Navigation items: clicking sets `active: true` on the clicked item and `false` on all others, re-renders sidebar
- Toggle switch: clicking toggles `extraUsage.enabled`, updates toggle visual
- Buttons: cursor pointer on hover, subtle hover background change
- Links: cursor pointer, underline on hover
- InfoIcon: shows tooltip on hover with brief explanation text
