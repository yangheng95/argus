# Taste Principles：设计品味方法论

这份文档回答一个问题：**在 design system 的约束内，如何做出有品味的设计，而不是有 AI 味的设计。**

SKILL.md 的「设计心法」是四条纲领，这里是展开的方法论。核心立场：**AI 味不是 DS 的锅，是 agent 在 DS 之外自作主张默认审美的锅。** 你的品味体现在"如何在合法 token 里做取舍"，不体现在"发明新东西"。

---

## 一、心法总纲

### 1. Earn its place（每个元素挣得存在）

页面上每个元素都要过一遍这个问题：

- **删掉它，设计会更差吗？** 不会 → 删。
- **它解决了什么真问题？** 如果答案是"让页面不那么空" → 删。
- **它有真内容支撑吗？** 编的 stats/quote/feature → 不写，留白或问用户。

空白不是缺陷。空白是节奏。用**构图**（对比、层级、留白、对齐）解决"太空"，不是用内容或装饰填满。

### 2. 品味 = 在约束内的克制

好设计师和 AI 的区别不在"会用多少花招"，而在"忍住不用多少花招"。DS 给了你渐变、阴影、圆角、图标——但**能用不代表该用**。默认最简，只在场景真的需要时才加一层。

> 当你冒出"加个 XX 会更好看"的念头——先假设那是 AI slop 的征兆，做最简版本，把"加不加"留给用户或 DS 决定。

---

## 二、层级：用对比建立，不用装饰堆砌

想让一块内容更重要？按这个优先级选手段（全部用 DS 已有 token）：

1. **字重对比** —— 重要的加粗，次要的常规/减淡
2. **字号对比** —— 拉开 title / body / caption 的层级
3. **颜色对比** —— 主色文字 vs 次级灰阶文字（用 DS 的 text-primary / text-secondary）
4. **背景对比** —— 用 DS 的 surface 分层（如 elevated 背景）
5. **留白** —— 给重要内容更多呼吸空间
6. **朴素分隔线** —— `border-t` / `divide-y` 分组，代替卡片套卡片

**不要**靠这些制造层级（都是 AI 味）：
- 加渐变让它"更显眼"
- 加彩色左边框 accent
- 加投影/发光
- 加一个 icon
- 套一层圆角卡片

层级越靠前的手段越"干净"。能用字重解决的，别动背景色；能用背景色解决的，别加边框。

---

## 三、留白与节奏

- **section 之间的呼吸** > 塞满每一寸。业务页密度可以高，但高密度 ≠ 无间距，要有清晰的分组节奏。
- **同类元素等距，不同组拉开** —— 靠间距表达"这几个是一组"，比画框更高级。
- **对齐是免费的秩序感** —— 所有元素回到统一的网格/基线，页面自然显得"设计过"。歪一点点就是廉价感的来源。
- **背景色最多 2 种**（在 DS 允许范围内）。频繁切换背景色 = 杂乱。

---

## 四、颜色克制

- 视觉表现**只来自 DS token**。不凭空发明颜色。
- accent 色**全页一致**：选定一个强调色就用到底，不要 section 5 蓝色 CTA、section 7 又冒出绿色 badge。
- **渐变**：默认不用。DS 有渐变 token 才用；实在要，只做单色系、极克制的点缀（button hover、进度条），绝不全屏彩虹/紫色 mesh。
- **毛玻璃**：默认不用。仅 DS 有 glass token 且用于 overlay/modal/浮层时可用。**禁止**给普通卡片、普通 section 加 `backdrop-filter`——这是最典型的 AI 味之一。
- **不用纯黑 `#000` / 纯白 `#fff`**：用 DS 的 off-black / off-white，纯值会杀掉层次感。
- **dark mode 不是反色**：需要重新调饱和度和对比度，DS 有 dark token 就用，没有就别硬做。

---

## 五、图标、图像、数据

- **图标**：不是每个标题/feature 都配 icon。icon 要有真信息价值。滥用 icon 让界面像玩具。用 DS 指定的图标方案，缺了用灰块 placeholder，**绝不 emoji、绝不手画 SVG icon**。
- **图像**：不用 SVG 画人物/场景/设备/插画——AI 画的一眼假。缺图就 `插画位 1200×800` 灰块 + 文字标签。
- **数据**：列表/表格数据驱动渲染（见 SKILL.md 数据契约）；不编造装饰性 stats；没真数据填 `--` 或问用户。

---

## 六、决策速查（当你犹豫时）

| 你想… | 默认答案 |
|-------|---------|
| 加个渐变背景 | 不加（除非 DS token） |
| 加个透明毛玻璃卡片 | 不加（除非 DS glass token + 浮层场景） |
| 给卡片加圆角 + 左 border accent | 不加，换字重/背景对比 |
| 加个 emoji | 不加 |
| 用 SVG 画个 hero 插画 | 不画，用 placeholder |
| 加一段 quote/一排 stats 装饰 | 先问用户有没有真内容 |
| 给这个标题配个 icon | 大概率不配 |
| 加投影/发光让它更显眼 | 不加，用层级手段（字重/间距） |
| 再加一个 section 让页面更丰富 | 先问用户，不单方面加 |

**通用原则**：「加一下会更好看」的直觉，在 AI 身上八成是错的。先做最简，把加法留给明确需求。
