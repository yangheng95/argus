ชุดโครงการชุมชนที่สร้างขึ้นบน Argus

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Argus ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-argus](https://github.com/awesome-argus/awesome-argus) และ [argus.cafe](https://argus.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
