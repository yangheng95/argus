TUI 是 OpenCorvus 的交互式终端前端，也是 `opencorvus` 不带子命令时的默认行为。

## 启动

```bash
opencorvus
```

会绑定当前目录所在项目，自动发现 `opencorvus.jsonc`、加载已配置 provider 凭证、打开交互式任务面板。

## 功能

- **Sessions** — 每次交互都是一个 session。`--continue` 续接最后一次，`--session <id>` 续指定。
- **Tasks** — 提交任务后实时观察 spec → goals → plan → run → evaluate → deliver。
- **Slash commands** — `/init`、`/share`、`/undo`，以及你在 `commands/` 或 [config](/docs/zh-cn/config/) 中定义的自定义命令。
- **权限提示** — 命中 `ask` 规则时 TUI 暂停并展示 `allow / deny`。详见 [Permissions](/docs/zh-cn/permissions/)。
- **主题** — 内置调色板及自定义主题。见 [Themes](/docs/zh-cn/themes/)。
- **Keybinds** — 完全可自定义。见 [Keybinds](/docs/zh-cn/keybinds/)。

## 继承自 OpenCorvus

OpenCorvus 的 TUI 扩展自上游 Go 实现的 OpenCorvus TUI。大部分快捷键、主题、slash command 原语沿用；OpenCorvus 在其上叠加 orchestrator 事件流（spec / goals / evaluator / acceptance）。

## Headless 替代

若希望从脚本、浏览器或编辑器驱动 OpenCorvus，运行 [`opencorvus serve`](/docs/zh-cn/cli/) 并配合 [SDK](/docs/zh-cn/sdk/) 或 [ACP](/docs/zh-cn/acp/)。
