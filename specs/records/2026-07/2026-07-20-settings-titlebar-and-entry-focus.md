## Causal chain

1. **Observable titlebar defect:** the highlighted top band reads as a dark shadow above the light Settings surface.
2. **Direct titlebar trigger:** the band is not a CSS shadow gradient. Settings uses the shared Dialog as a fullscreen non-modal page below the persistent titlebar, but the primitive still renders its normal full-window 40% scrim. That overlay sits above the titlebar and uniformly darkens it while the Settings content sits above the overlay.
3. **Deep titlebar cause:** `modal={false}` correctly disables modal interaction semantics, but it does not encode the visual surface policy. Settings did not use the shared Dialog's existing `overlayClass` extension point, so it inherited modal visual dimming despite being a page-level navigation surface.
4. **Root titlebar repair:** give Config Settings one explicit `config-dialog-overlay` class and make that shared-overlay instance transparent in the Settings surface stylesheet. Keep the ordinary Dialog scrim and the Interaction Dialog's focused-popup scrim unchanged. Also let the sole `.titlebar` rule paint the existing semantic `--rail-surface` token and retain `box-shadow: none`, closing the prior native alpha hole without adding another palette source.
5. **Observable Back-button defect:** Back to app looks hovered before the user points at it.
6. **Direct Back-button trigger:** Kobalte Dialog's default open autofocus selects the first tabbable Settings control, which is Back to app. The canonical Button deliberately renders `:focus-visible` with the same wash as hover.
7. **Deep Back-button cause:** a fullscreen non-modal Settings page inherited modal-dialog autofocus behavior even though its first control is navigation back out of the page. A CSS exception would hide valid keyboard focus and leave the ownership error intact.
8. **Root Back-button repair:** prevent Kobalte's default open autofocus at the `ConfigDialogHost` call site. Preserve all Button hover/focus styling; after entry, pointer hover and subsequent keyboard Tab still exercise the shared primitive normally.
