## Acronyms

- GUI: Graphical User Interface, the visible overlay and browser preview surfaces.

This document records Codex-led audit fixes from the GUI/benchmark quality goal. The fixes are intentionally scoped to concrete issues found by independent agents plus local code evidence.

- These fixes must not introduce fallback or compatibility aliases.
- Each changed behavior has a targeted regression test.
