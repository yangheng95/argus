基于 specs/prd.txt 的 Moment Diary PRD，交付一个商业级可运行的 MVP 全栈 Web 应用。

## 技术栈（固定，不可更改）

### 后端
- **运行时**: Bun
- **语言**: TypeScript (strict mode)
- **框架**: Hono（轻量 Web 框架）
- **数据库**: SQLite via `bun:sqlite`，数据文件 `data/moment-diary.db`
- **密码哈希**: `Bun.password.hash()` / `Bun.password.verify()`（Argon2 内置）
- **入口**: `index.ts`，同时服务 API 和前端静态资源

### 前端
- **框架**: React 19 + TypeScript
- **脚手架**: Vite（`npm create vite@latest` 的 react-ts 模板结构）
- **路由**: React Router v7
- **样式**: Tailwind CSS v4
- **图表**: Recharts（统计面板）
- **HTTP 客户端**: 原生 fetch + 自封装 api client
- **前端目录**: `web/`，构建产物 `web/dist/`，由后端 Hono 静态托管

### 项目结构

## 交付范围（MVP P0 功能）

### 后端 API

1. **认证**
   - `POST /api/auth/register` — 邮箱+密码注册，密码用 `Bun.password.hash()` 存储
   - `POST /api/auth/login` — 登录返回 Bearer token
   - 中间件：从 `Authorization: Bearer <token>` 解析用户

2. **日记 CRUD**
   - `POST /api/diaries` — 创建日记（标题、正文、心情、标签[]、是否收藏）
   - `GET /api/diaries` — 列表（支持 ?tag=&mood=&favorite=&limit=&offset= 筛选）
   - `GET /api/diaries/:id` — 详情（含标签）
   - `PATCH /api/diaries/:id` — 更新（刷新 updated_at，同步更新 tags）
   - `DELETE /api/diaries/:id` — 删除（同步清理 diary_tags）

3. **时间轴**
   - `GET /api/timeline` — 按 created_at 倒序，支持 tag/mood/limit/offset

4. **日历**
   - `GET /api/calendar?year=2026&month=3` — 返回该月每天的日记数量和心情

5. **统计**
   - `GET /api/stats` — 总篇数、连续记录天数、心情分布、高频标签 top5

### 前端页面

React SPA，6 个主要视图：

1. **登录/注册页** (`/login`, `/register`)
   - 表单验证（邮箱格式、密码长度≥6）
   - 错误提示（邮箱已存在、密码错误）
   - 登录成功自动跳转首页

2. **首页/时间轴** (`/`)
   - 日记卡片列表，按时间倒序
   - 每张卡片展示：标题、正文摘要(前100字)、心情 emoji、标签 chips、时间
   - 顶部筛选栏：心情、标签、收藏
   - 无限滚动或分页加载
   - 空状态引导："写下你的第一篇日记"

3. **新建/编辑日记** (`/write`, `/edit/:id`)
   - 标题输入
   - 正文 textarea（支持换行，不需要富文本编辑器）
   - 心情选择器：7级（😄很开心/😊开心/😌平静/😔低落/😢难过/😰焦虑/😡愤怒）
   - 标签输入：逗号或回车分隔，显示为 chips
   - 收藏开关
   - 保存/取消按钮

4. **日记详情** (`/diary/:id`)
   - 完整展示标题、正文、心情、标签、时间
   - 编辑/删除按钮
   - 删除需确认对话框

5. **日历视图** (`/calendar`)
   - 月历网格，当前月份
   - 有日记的日期显示心情色彩圆点
   - 点击有日记的日期，展示当日日记列表
   - 可切换上/下月

6. **统计面板** (`/stats`)
   - 心情分布饼图（Recharts PieChart）
   - 连续记录天数（数字+描述）
   - 高频标签 top5（柱状图或标签云）
   - 总篇数

### 全局 UI

- **导航栏**: 底部 Tab 导航（移动端）/ 顶部导航（桌面），包含：首页、写日记、日历、统计、退出
- **主题切换**: 暗色/亮色，按钮在导航栏，状态持久化到 localStorage
- **响应式**: 移动端优先，断点 sm(640px)/md(768px)/lg(1024px)
- **加载态**: 骨架屏或 spinner
- **Toast**: 操作成功/失败提示

## 视觉设计要求

- 商业级设计品质，不是 demo 风格
- 配色方案：暖色调为主（日记软件的温馨感）

## 数据表

```sql
CREATE TABLE users (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  email TEXT NOT NULL UNIQUE,
  password_hash TEXT NOT NULL,
  nickname TEXT,
  created_at INTEGER NOT NULL DEFAULT (unixepoch())
);

CREATE TABLE sessions (
  token TEXT PRIMARY KEY,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  created_at INTEGER NOT NULL DEFAULT (unixepoch())
);

CREATE TABLE diary_entries (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  title TEXT NOT NULL,
  content TEXT NOT NULL DEFAULT '',
  mood TEXT NOT NULL DEFAULT 'calm',
  is_favorite INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL DEFAULT (unixepoch()),
  updated_at INTEGER NOT NULL DEFAULT (unixepoch())
);

CREATE TABLE tags (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  name TEXT NOT NULL,
  normalized_name TEXT NOT NULL,
  UNIQUE(user_id, normalized_name)
);

CREATE TABLE diary_tags (
  diary_id INTEGER NOT NULL REFERENCES diary_entries(id) ON DELETE CASCADE,
  tag_id INTEGER NOT NULL REFERENCES tags(id) ON DELETE CASCADE,
  PRIMARY KEY (diary_id, tag_id)
);
```

mood 枚举值：`very_happy`, `happy`, `calm`, `down`, `sad`, `anxious`, `angry`

## 安全规则

- 密码用 `Bun.password.hash()` (Argon2) 存储
- 未认证请求返回 401
- 用户不能访问其他用户的日记（所有查询带 user_id 条件）
- 标签按小写去重（normalized_name = name.toLowerCase().trim()）
- Session token 使用 `crypto.randomUUID()`

## 测试要求

`tests/api.test.ts` 使用 `bun:test`，至少覆盖：

1. 注册后密码是哈希（不等于原始密码）
2. 登录返回 token
3. 带 token 创建日记（含 mood + tags），返回完整对象
4. 时间轴按 created_at 倒序
5. tag 过滤有效
6. mood 过滤有效
7. 用户隔离（用户 A 看不到用户 B 的日记）
8. 更新日记后 updated_at 刷新
9. 删除日记后 diary_tags 同步清理
