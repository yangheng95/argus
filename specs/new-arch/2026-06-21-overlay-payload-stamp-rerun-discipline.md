# Overlay Payload Stamp Rerun Discipline

## Problem

`bun run build:overlay` failed once in the Tauri custom build script after the
overlay-server artifact had been rebuilt. The visible output was dominated by
thousands of `cargo:rerun-if-changed=...browser-mcp-node/node_modules/...`
lines from `packages/overlay/src-tauri/build.rs`.

The same payload later built successfully through direct `cargo build --release`
and then through the full `bun run build:overlay` pipeline. That means the
confirmed defect is not a missing runtime file or an invalid tar archive. The
confirmed defect is that the Tauri build script still treats every embedded
payload file as a Cargo rerun input, producing noisy and fragile custom-build
output for a payload that currently contains more than 12,000 files.

## Evidence

| Evidence                                                                  | Finding                                                                                                                                                                                                              |
| ------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `specs/overlay-package-size-optimization-2026-06-05.md`                   | The accepted architecture is one gzip tar archive plus a manifest, not per-file `include_bytes!`.                                                                                                                    |
| `specs/new-arch/2026-06-02-overlay-browser-mcp-self-contained-runtime.md` | The overlay-server payload must keep `browser-mcp-node`, packaged Node, and runtime `node_modules`; removing them is not an acceptable fix.                                                                          |
| `packages/overlay/src-tauri/build.rs`                                     | `main()` recursively calls `collect_payload_files()` only to print one `cargo:rerun-if-changed` line per payload file, then `write_embed_module()` collects the same payload again.                                  |
| `packages/opencorvus/script/build.ts`                                     | The overlay-server artifact directory is generated by one script before Tauri receives it through `OPENCORVUS_EMBED_PATH`. This script can emit a single authoritative payload stamp after the artifact is complete. |
| `rg -n "stdio\\.mjs                                                       | browser\\.mjs                                                                                                                                                                                                        | browser-mcp-node" packages specs` | Current runtime, MCP, Docker, and Linux package checks use one packaged browser bundle: `browser-mcp-node/browser.mjs`. The Rust embedded payload test was the remaining stale `stdio.mjs` assertion. |
| Local measurement                                                         | `packages/opencorvus/dist/opencorvus-overlay-server-windows-x64` contained 12,071 files and about 393 MB of files; the embedded gzip archive was about 152 MB.                                                       |

## Design

The overlay-server artifact directory becomes the single source for Cargo rerun
detection by writing `.opencorvus-overlay-payload.stamp` after the artifact is
complete.

- `packages/opencorvus/script/build.ts` writes the stamp only for
  `--overlay-server` artifacts, after `package.json` and all runtime files have
  been written.
- The stamp records the payload file count, total byte size, and a SHA-256 digest
  over relative paths and file bytes, excluding the stamp file itself.
- `packages/overlay/src-tauri/build.rs` watches the payload root and that stamp
  file instead of printing one Cargo input per embedded payload file.
- `build.rs` still recursively collects the real payload files when generating
  the archive and manifest; the payload contents are not reduced and no runtime
  fallback is introduced.
- Directory payloads without the stamp fail closed with an explicit build error:
  the supported path is to rebuild the overlay-server artifact first.
- The Rust embedded payload test is aligned with the existing single packaged
  browser bundle, `browser-mcp-node/browser.mjs`, matching runtime resolver and
  packaging tests.

## Rejected Designs

| Design                                                       | Reason                                                                                         |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------- |
| Remove `browser-mcp-node/node_modules` from the payload      | Violates the self-contained browser MCP runtime design.                                        |
| Keep per-file Cargo watches and only redirect logs           | Leaves the fragile custom-build behavior in place.                                             |
| Watch only the payload directory                             | Misses nested file content changes when Cargo evaluates whether the build script should rerun. |
| Download or resolve missing runtime files at overlay startup | Fallback and external double source.                                                           |

## Acceptance

- `bun test packages/opencorvus/test/script/build-artifact.test.ts --timeout 60000`
- `cargo test --manifest-path packages/overlay/src-tauri/Cargo.toml embedded_sidecar --release`
- `bun run build:overlay`
- Manual review: `build.rs` no longer prints per-file `cargo:rerun-if-changed`
  for embedded payload files, and the overlay-server dist directory contains
  `.opencorvus-overlay-payload.stamp`.
