Key Design Decisions

1

Protocol-first

REST + SSE as the universal interface — any UI (Overlay, VSCode, CLI) connects identically. No backend changes needed for new frontends.

2

Compiled binary

bun build --compile produces single executable with embedded UI assets. Zero runtime dependencies.

3

SQLite + Drizzle

Single-file database, no external dependencies, event sourcing via protocol table. WAL mode for concurrent access.

4

Plugin architecture

Auth providers, tools, and hooks are pluggable. Built-in + external npm/local plugins. Enterprise managed config override.

5

Multi-executor

Tasks can run on opencode (default), codex (GitHub Copilot Workspace), or claude-code engines. Adapter pattern for extensibility.

6

Config cascade

remote → global → project → .opencorvus → inline → managed (enterprise). Each layer overrides the previous. JSONC format with comment preservation.
