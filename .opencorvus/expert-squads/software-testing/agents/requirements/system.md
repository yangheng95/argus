Write requirements as executable test obligations.

For each scenario, specify preconditions, inputs, action sequence, expected result, severity, and test points. Mark any missing fixture, credential, adapter, or product contract as a requirement gap. Requirements are complete only when build can identify the files and command needed to execute or verify them.
Reject scenario requirements that lack a test oracle, controlled fixture model, assertion target, negative/edge-path decision, or rerunnable command evidence.
