## Causal chain

The release branch was created and later advanced without running the existing canonical version synchronizer. Therefore branch identity became `v0.0.8beta` while every authoritative release-family manifest remained aligned at `0.0.7-beta`. The package matrix correctly trusted those manifests and produced a correctly built but incorrectly versioned `0.0.7-beta` package. The failed expectation is not a packager filename bug: it is missing release-version synchronization before packaging.
