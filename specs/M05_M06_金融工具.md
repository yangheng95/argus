---

## 1. 模块目标

**M05**：提供 A 股上市公司财务报表与核心财务指标的查询能力（ROE、PE、营收、净利润等）。
**M06**：提供股票 / 指数的历史行情数据（OHLCV）和技术指标计算（MA、MACD、RSI、布林带等）。

两个模块共享同一个 `IFinanceService` 接口，Mock 实现从本地 JSON 数据返回，真实实现调用 tushare / akshare。

## 3. 功能规格

### 3.1 M05：财报工具

**支持字段（fields）**：

| 字段 ID | 含义 | 单位 |
|---|---|---|
| `revenue` | 营业收入 | 元 |
| `net_profit` | 归母净利润 | 元 |
| `gross_margin` | 毛利率 | 小数（0.92 = 92%）|
| `net_margin` | 净利率 | 小数 |
| `roe` | 净资产收益率 | 小数 |
| `roa` | 总资产收益率 | 小数 |
| `pe_ttm` | 市盈率（TTM）| 倍数 |
| `pb` | 市净率 | 倍数 |
| `ev_ebitda` | EV/EBITDA | 倍数 |
| `debt_ratio` | 资产负债率 | 小数 |
| `revenue_yoy` | 营收同比增速 | 小数 |
| `profit_yoy` | 净利润同比增速 | 小数 |

**查询参数约束**：
- `ticker`：必须为 `xxxxxx.SH` 或 `xxxxxx.SZ` 格式（M02 负责转换）
- `freq`：`quarterly`（季报）或 `annual`（年报），默认 `quarterly`
- `fields`：至少 1 个，最多 10 个
- 时间范围：最长 5 年（防止数据量过大）
- 多标的并行查询：最多同时查询 5 个标的（Promise.all）

**数据对齐规则**：
- 返回数据按 `period` 升序排列
- 空值字段返回 `null`，不填充 0（避免误导）
- `period` 格式统一为 `YYYY-QN`（如 `2024-Q3`）或 `YYYY`（年报）

### 3.2 M06：行情与技术指标

**行情查询（getOHLCV）**：

| 字段 | 含义 |
|---|---|
| `date` | YYYY-MM-DD |
| `open / high / low / close` | 价格（元）|
| `volume` | 成交量（股）|
| `amount` | 成交额（元）|
| `turnover` | 换手率（小数，0.023 = 2.3%）|
| `change_pct` | 涨跌幅（小数）|

**技术指标（`indicators.ts` 本地计算）**：

技术指标基于 `getOHLCV` 返回的数据在**客户端本地计算**（不依赖服务端），避免额外接口调用。

| 指标 | 参数 | 说明 |
|---|---|---|
| `MA(n)` | n=5/10/20/60 | 简单移动平均 |
| `EMA(n)` | n=12/26 | 指数移动平均 |
| `MACD` | fast=12, slow=26, signal=9 | DIF / DEA / 柱 |
| `RSI(n)` | n=14 | 相对强弱指标 |
| `BOLL` | n=20, k=2 | 布林带（上/中/下轨）|
| `ATR(n)` | n=14 | 平均真实波幅 |
| `KDJ` | n=9 | K / D / J |

计算函数全部为纯函数（`(bars: OHLCVBar[], params) => number[]`），便于单元测试。

**K 线图 Plotly spec 生成规则**：
- 使用 `candlestick` trace 类型
- MA 线叠加在同一图表 y 轴
- MACD 等振荡器在下方 subplot（`rows: 2, cols: 1`）
- 范围选择器：1M / 3M / 6M / 1Y / ALL

## 4. 数据结构

```typescript
// src/services/types.ts（补充）

export interface FinancialReport {
  ticker: string
  period: string                        // '2024-Q3' | '2023'
  reportDate: string                    // 实际发布日期
  fields: Record<string, number | null>
}

export interface OHLCVBar {
  date: string                          // 'YYYY-MM-DD'
  open: number
  high: number
  low: number
  close: number
  volume: number
  amount?: number
  turnover?: number
  change_pct?: number
}

export interface IndicatorResult {
  name: string                          // 'MA20', 'RSI14' 等
  values: Array<number | null>          // 与 OHLCVBar[] 等长，头部 null 表示计算窗口不足
}
```

```typescript
// src/services/finance/interface.ts

export interface IFinanceService {
  getFinancialReport(params: {
    tickers: string[]                   // 支持批量
    startDate?: string
    endDate?: string
    freq: 'quarterly' | 'annual'
    fields: string[]
  }): Promise<FinancialReport[]>

  getOHLCV(params: {
    ticker: string
    startDate: string
    endDate: string
    freq?: 'D' | 'W' | 'M'
  }): Promise<OHLCVBar[]>

  getIndexComponents(params: {
    indexCode: string
    date?: string
  }): Promise<Array<{ ticker: string; name: string; weight: number }>>

  // 工具调用元数据（用于 SourceTag）
  getSourceInfo(): { name: string; latency?: number }
}
```

## 7. 错误处理

| 场景 | 行为 |
|---|---|
| 标的代码不存在（Mock 中无数据）| 返回空数组 + ToolCallBadge 提示"未找到该标的数据" |
| 时间范围超过 5 年 | 自动截断到最近 5 年，SourceTag 附加提示 |
| 字段名不合法 | 过滤掉非法字段，其余字段正常返回 |
| 多标的批量查询某一个失败 | 其余标的正常返回，失败标的返回 `null` 占位 |
