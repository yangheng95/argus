title: 主题

---

OpenCorvus 的 TUI 继承上游 opencode 的主题系统。主题是 JSON 调色板；可选内置主题或自定义。

## 选择主题

在 `tui.json`（与 `opencorvus.jsonc` 同级或 `~/.config/opencorvus/` 下）：

```json
{
  "$schema": "https://opencorvus.ai/tui.json",
  "theme": "tokyonight"
}
```

## 内置主题

继承自 opencode 的部分主题：

- `tokyonight`
- `catppuccin`
- `dracula`
- `gruvbox`
- `everforest`
- `nord`
- `kanagawa`
- `rose-pine`
- `monokai`
- `one-dark`

实际可用集合依赖编入的 TUI 版本；在 TUI 内打开主题选择器查看你这台机器上的列表。

## 自定义主题

把符合 opencode 主题 schema 的 JSON 放到 `~/.config/opencorvus/themes/<name>.json`，在 `tui.json` 中按名引用。文件改动会被 TUI 热加载。

## Server / Overlay 主题

HTTP server 与 Overlay UI 各自有独立的暗/亮配色，与 TUI 调色板解耦；`tui.json` 的 `theme` 不影响它们。
