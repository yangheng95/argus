Overlay Guide
Positioning

This is the local control overlay for OpenCorvus: one place to switch working directories, choose an executor, track task status, and inspect spec, plan, evaluation, and changes.

How to use
1 Pick an existing session on the left or create a blank one, then confirm the working directory is correct.
2 Choose an executor in the center and send requirements, constraints, or follow-ups from the session composer.
3 Use the right-side Spec, Plan, Goals, Evaluation, and File Diff sections to keep the task aligned.
4 Use Channels, Settings, Logs, and pin-to-top in the titlebar for configuration, debugging, and long-running monitoring.
