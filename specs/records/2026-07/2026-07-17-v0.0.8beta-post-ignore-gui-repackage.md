## Verification

- `file` and `lipo -archs` identify the staged executable as Mach-O 64-bit ARM64.
- `codesign --verify --deep --strict` passed for the built `OpenCorvus.app`; `CFBundleShortVersionString` and `CFBundleVersion` both resolve to `0.0.8-beta`.
- `hdiutil verify` reported a valid disk-image checksum. The gzip archive lists the expected application bundle, executable, icon, metadata, and signature resources.
- The build emitted only the two existing macOS taskbar-badge dead-code warnings. Notarization was correctly skipped because Apple notarization credentials are not configured; this local matrix contract uses ad-hoc signing.
- All three staged deliverables resolve through the canonical `packages/overlay/dist-artifacts/` ignore rule and are absent from `git ls-files`.
- The build also materialized the untracked Tauri-generated `macOS-schema.json` beside four intentional tracked schema sources. Its exact generated path is now ignored and covered by the same repository residue regression, replacing the previous manual post-build deletion practice without hiding the tracked canonical schemas.
