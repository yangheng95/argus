Quick Guide
What This Panel Is For

This workspace is for conversations and acceptance evidence: left selects recent chats, center drives execution, right keeps documents, plan, evaluation, and file changes together.

Fast Path
1 Choose the workspace folder and recent chat before sending anything.
2 Send a concrete request with constraints and acceptance criteria.
3 Watch the workspace while it runs: Spec checks understanding, Plan checks route, Goals and Evaluation catch drift, Files shows what changed.
4 Titlebar menus configure workspace, model, tools, view, acceptance channels, and diagnostics.
