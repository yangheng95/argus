# AimeCode M1-5 · 代码执行沙箱（Pyodide）

> **自包含文档**：一个 AI 模型只读这一个文件，就能实现基于 Pyodide (WASM) 的 Python 代码执行沙箱。
> **前置条件**：M0-1（ExecutionResult 类型、IExecutorService 接口）+ M1-1（API 框架）已完成。
> **包含**：Pyodide 初始化、Python 代码执行、stdout/stderr 捕获、Plotly 图表捕获、超时控制、沙箱隔离。
> **不包含**：Docker 沙箱（M3-1）、R/SQL 执行、文件系统访问。

---

## 1. 目标与验收标准

### 1.1 里程碑目标

实现 `IExecutorService.execute()`，在 Pyodide (WASM) 中执行 LLM 生成的 Python 代码，捕获 stdout、stderr、Plotly 图表，并带超时保护。

### 1.2 验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 基础执行 | 执行 `print("hello")` | `status: 'ok'`, `stdout: 'hello\n'`, `stderr: ''` |
| V2 | pandas 可用 | 执行 `import pandas as pd; df = pd.DataFrame({'a':[1,2,3]}); print(df.shape)` | stdout 含 `(3, 1)` |
| V3 | numpy 可用 | 执行 `import numpy as np; print(np.mean([1,2,3]))` | stdout 含 `2.0` |
| V4 | Plotly 图表捕获 | 执行含 `fig.show()` 的 Plotly 代码 | `charts` 数组包含一个 spec 对象，含 `data` 和 `layout` 字段 |
| V5 | 错误捕获 | 执行 `1/0` | `status: 'error'`, `stderr` 含 `ZeroDivisionError` |
| V6 | 语法错误 | 执行 `def f(` | `status: 'error'`, `stderr` 含 `SyntaxError` |
| V7 | 超时保护 | 执行 `import time; time.sleep(120)` | 30s 后返回 `status: 'timeout'`, durationMs ≈ 30000 |
| V8 | 隔离性 | 会话 A 定义 `x=1`，会话 B 访问 `x` | 会话 B 得到 `NameError` |
| V9 | 执行时间记录 | 执行任意代码 | `durationMs` 为正整数 |
| V10 | API 端点 | `POST /api/execute` body `{"code":"print(1)","language":"python","sessionId":"..."}` | 200，返回 ExecutionResult |

## 4. Pyodide Worker

Bun 支持 `Worker` API。Pyodide 在 Worker 中运行，避免阻塞主线程。

文件路径：`server/services/executor/worker.ts`

```typescript
/// <reference lib="webworker" />

// 此文件在 Worker 线程中运行。
// 主线程通过 postMessage 发送代码，Worker 执行后返回结果。

import type { ExecutionResult } from '@shared/types'

// ── Pyodide 初始化 ──────────────────────────────────────────
let pyodide: any = null
let initialized = false

// 每个会话的 globals 命名空间
const sessionNamespaces = new Map<string, any>()

async function initPyodide() {
  if (initialized) return

  // @ts-ignore - Pyodide 通过 CDN 加载
  const { loadPyodide } = await import('https://cdn.jsdelivr.net/pyodide/v0.26.2/full/pyodide.mjs')

  pyodide = await loadPyodide({
    indexURL: 'https://cdn.jsdelivr.net/pyodide/v0.26.2/full/',
  })

  // 预装常用包
  await pyodide.loadPackage(['pandas', 'numpy', 'micropip'])

  // 通过 micropip 安装 plotly（纯 Python 包）
  await pyodide.runPythonAsync(`
import micropip
await micropip.install('plotly')
  `)

  // 注入 Plotly 图表捕获逻辑
  await pyodide.runPythonAsync(PLOTLY_CAPTURE_SCRIPT)

  initialized = true
  self.postMessage({ type: 'ready' })
}

// ── Plotly 图表捕获脚本 ─────────────────────────────────────
const PLOTLY_CAPTURE_SCRIPT = `
import json

# 全局列表，存储本次执行中所有 fig.show() 产生的图表
_aimecode_charts = []

# 猴子补丁 plotly.io.show
import plotly.io as pio

_original_show = pio.show

def _capture_show(fig, *args, **kwargs):
    """拦截 fig.show()，将 spec 存入列表而非尝试打开浏览器。"""
    spec = json.loads(fig.to_json())
    _aimecode_charts.append({
        'id': f'chart_{len(_aimecode_charts)}',
        'spec': spec,
    })

pio.show = _capture_show

# 同时补丁 Figure.show
import plotly.graph_objects as go
go.Figure.show = lambda self, *a, **kw: _capture_show(self, *a, **kw)
`

// ── 执行代码 ────────────────────────────────────────────────
async function executeCode(
  code: string,
  sessionId: string,
): Promise<ExecutionResult> {
  if (!initialized) {
    await initPyodide()
  }

  const start = performance.now()

  // 获取或创建会话命名空间
  let namespace = sessionNamespaces.get(sessionId)
  if (!namespace) {
    namespace = pyodide.globals.get('dict')()
    // 将内置模块注入命名空间
    pyodide.runPython(`
import builtins
ns = dict(builtins.__dict__)
    `, { globals: namespace })
    sessionNamespaces.set(sessionId, namespace)
  }

  // 重置图表捕获列表
  pyodide.runPython('_aimecode_charts = []')

  // 捕获 stdout/stderr
  pyodide.runPython(`
import sys, io
_stdout_capture = io.StringIO()
_stderr_capture = io.StringIO()
sys.stdout = _stdout_capture
sys.stderr = _stderr_capture
  `)

  try {
    // 执行用户代码
    await pyodide.runPythonAsync(code, { globals: namespace })

    // 收集输出
    const stdout = pyodide.runPython('_stdout_capture.getvalue()') as string
    const stderr = pyodide.runPython('_stderr_capture.getvalue()') as string

    // 收集图表
    const chartsJson = pyodide.runPython('json.dumps(_aimecode_charts)') as string
    const charts = JSON.parse(chartsJson)

    return {
      status: 'ok',
      stdout,
      stderr,
      charts,
      durationMs: Math.round(performance.now() - start),
    }
  } catch (err: any) {
    const stderr = pyodide.runPython('_stderr_capture.getvalue()') as string
    const errorMsg = err.message || String(err)

    return {
      status: 'error',
      stdout: pyodide.runPython('_stdout_capture.getvalue()') as string,
      stderr: stderr + '\n' + errorMsg,
      charts: [],
      durationMs: Math.round(performance.now() - start),
    }
  } finally {
    // 恢复 stdout/stderr
    pyodide.runPython(`
sys.stdout = sys.__stdout__
sys.stderr = sys.__stderr__
    `)
  }
}

// ── 清理会话命名空间 ────────────────────────────────────────
function clearSession(sessionId: string) {
  sessionNamespaces.delete(sessionId)
}

// ── 消息处理 ────────────────────────────────────────────────
self.onmessage = async (event: MessageEvent) => {
  const { type, id, code, sessionId } = event.data

  switch (type) {
    case 'init':
      await initPyodide()
      break

    case 'execute':
      try {
        const result = await executeCode(code, sessionId)
        self.postMessage({ type: 'result', id, result })
      } catch (err: any) {
        self.postMessage({
          type: 'result',
          id,
          result: {
            status: 'error',
            stdout: '',
            stderr: err.message || 'Unknown execution error',
            charts: [],
            durationMs: 0,
          },
        })
      }
      break

    case 'clear':
      clearSession(sessionId)
      self.postMessage({ type: 'cleared', id })
      break
  }
}

// 启动时自动初始化
initPyodide()
```

## 5. 主线程 Service

文件路径：`server/services/executor/pyodide-executor.ts`

```typescript
import type { ExecutionResult } from '@shared/types'

const EXECUTION_TIMEOUT_MS = 30_000  // 30 秒

interface PendingExecution {
  resolve: (result: ExecutionResult) => void
  reject: (error: Error) => void
  timer: ReturnType<typeof setTimeout>
}

export class PyodideExecutorService {
  private worker: Worker | null = null
  private ready = false
  private readyPromise: Promise<void>
  private pending = new Map<string, PendingExecution>()

  constructor() {
    this.readyPromise = this.initWorker()
  }

  private async initWorker(): Promise<void> {
    return new Promise((resolve) => {
      this.worker = new Worker(new URL('./worker.ts', import.meta.url))

      this.worker.onmessage = (event: MessageEvent) => {
        const { type, id, result } = event.data

        if (type === 'ready') {
          this.ready = true
          console.log('[Executor] Pyodide worker ready')
          resolve()
          return
        }

        if (type === 'result' || type === 'cleared') {
          const pending = this.pending.get(id)
          if (pending) {
            clearTimeout(pending.timer)
            this.pending.delete(id)
            pending.resolve(result)
          }
        }
      }

      this.worker.onerror = (event) => {
        console.error('[Executor] Worker error:', event.message)
      }
    })
  }

  async execute(params: {
    code: string
    language: 'python' | 'sql' | 'r'
    sessionId: string
  }): Promise<ExecutionResult> {
    if (params.language !== 'python') {
      return {
        status: 'error',
        stdout: '',
        stderr: `Language '${params.language}' is not supported. Only Python is available.`,
        charts: [],
        durationMs: 0,
      }
    }

    // 等待 Worker 就绪
    if (!this.ready) {
      await this.readyPromise
    }

    const id = crypto.randomUUID()

    return new Promise((resolve, reject) => {
      // 超时保护
      const timer = setTimeout(() => {
        this.pending.delete(id)
        resolve({
          status: 'timeout',
          stdout: '',
          stderr: `Execution timed out after ${EXECUTION_TIMEOUT_MS / 1000}s`,
          charts: [],
          durationMs: EXECUTION_TIMEOUT_MS,
        })
        // 重建 Worker（超时可能导致 Worker 卡死）
        this.rebuildWorker()
      }, EXECUTION_TIMEOUT_MS)

      this.pending.set(id, { resolve, reject, timer })

      this.worker!.postMessage({
        type: 'execute',
        id,
        code: params.code,
        sessionId: params.sessionId,
      })
    })
  }

  private async rebuildWorker() {
    console.log('[Executor] Rebuilding worker after timeout...')
    this.worker?.terminate()
    this.ready = false
    this.readyPromise = this.initWorker()
  }

  async clearSession(sessionId: string): Promise<void> {
    if (!this.ready) return
    this.worker!.postMessage({ type: 'clear', id: crypto.randomUUID(), sessionId })
  }

  terminate() {
    this.worker?.terminate()
    for (const [, pending] of this.pending) {
      clearTimeout(pending.timer)
    }
    this.pending.clear()
  }
}
```

## 6. API 路由

文件路径：`server/routes/execute.ts`

```typescript
import { Hono } from 'hono'
import { PyodideExecutorService } from '../services/executor/pyodide-executor'
import { AppError } from '../types/errors'

export const executeRoutes = new Hono()

// 单例 executor（Worker 线程复用）
const executor = new PyodideExecutorService()

executeRoutes.post('/execute', async (c) => {
  let body: { code: string; language?: string; sessionId: string }

  try {
    body = await c.req.json()
  } catch {
    throw AppError.validation('Invalid JSON body')
  }

  if (!body.code || typeof body.code !== 'string') {
    throw AppError.validation('code is required', 'code')
  }
  if (!body.sessionId || typeof body.sessionId !== 'string') {
    throw AppError.validation('sessionId is required', 'sessionId')
  }
  if (body.code.length > 50_000) {
    throw AppError.validation('code must be at most 50000 characters', 'code')
  }

  const result = await executor.execute({
    code: body.code,
    language: (body.language as 'python') || 'python',
    sessionId: body.sessionId,
  })

  return c.json(result)
})
```

## 7. 安全约束

### 7.1 Pyodide 天然隔离

Pyodide 在 WASM 沙箱中运行，天然无法：
- 访问宿主文件系统
- 发起网络请求（除非显式代理）
- 执行系统命令
- 读取环境变量

### 7.2 额外限制

```python
# 在 Worker 初始化时注入
import builtins

# 禁止 exec/eval（虽然 Pyodide 本身就是在执行用户代码，
# 但防止嵌套 exec 规避会话隔离）
# 注意：不禁止 import（pandas/numpy 需要 import）

# 禁止修改 sys.path（防止路径注入）
import sys
sys.path = list(sys.path)  # 冻结副本
```

### 7.3 资源限制

| 资源 | 限制 | 实现方式 |
|---|---|---|
| 执行时间 | 30s | 主线程 setTimeout → Worker terminate |
| 代码长度 | 50KB | 路由层校验 |
| stdout 大小 | 1MB | Worker 中截断 |
| 图表数量 | 10 个 | Worker 中限制 `_aimecode_charts` 长度 |
| 内存 | ~256MB | Pyodide WASM 默认限制 |

## 8. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | Pyodide 首次加载慢（~5s 下载 WASM + 包） | Worker 在启动时预加载；前端显示 "正在初始化 Python 环境..." |
| T2 | `fig.show()` 在无头环境尝试打开浏览器 | 猴子补丁 `plotly.io.show` 改为收集 spec |
| T3 | matplotlib 在 Pyodide 中需要特殊处理 | M1-5 只支持 Plotly；matplotlib 图表在 M3-1 (Docker) 中支持 |
| T4 | Worker 超时后无法优雅中止 Python 执行 | terminate Worker → 新建 Worker（重新初始化 ~3s） |
| T5 | Bun Worker 与 Node Worker API 差异 | 使用标准 `new Worker(url)` 语法，Bun 原生支持 |
| T6 | 会话隔离靠 Python globals dict | 不同会话用不同 namespace dict，但共享底层模块缓存 |
| T7 | Pyodide CDN 在中国大陆可能慢 | 可配置 `indexURL` 为镜像地址；或预下载到本地 |
| T8 | `micropip.install('plotly')` 需要网络 | 首次初始化时安装，之后 Worker 保持存活复用 |
