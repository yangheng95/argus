Build two independent utility modules using Bun + TypeScript.

Module A: Create src/math-utils.ts with exported functions: add(a, b), subtract(a, b), multiply(a, b), divide(a, b) that work with numbers. divide should throw on zero divisor.

Module B: Create src/string-utils.ts with exported functions: capitalize(s), reverse(s), truncate(s, maxLen), slugify(s) that work with strings.

These two modules are completely independent — they share no imports or dependencies.

Only create or modify these files:
- src/math-utils.ts
- src/string-utils.ts

Do not add package.json, tsconfig.json, README files, or any other files.
The Bun runtime is already available.
