OpenCorvus's TUI inherits its theme system from upstream opencode. Themes ship as JSON palettes; you can pick a built-in or define your own.

## Selecting a theme

In `tui.json` (sibling of `opencorvus.jsonc` or under `~/.config/opencorvus/`):

```json
{
  "$schema": "https://opencorvus.ai/tui.json",
  "theme": "tokyonight"
}
```

## Built-in themes

A non-exhaustive list inherited from opencode:

- `tokyonight`
- `catppuccin`
- `dracula`
- `gruvbox`
- `everforest`
- `nord`
- `kanagawa`
- `rose-pine`
- `monokai`
- `one-dark`

The exact set depends on the TUI version OpenCorvus is built against; run the in-TUI theme picker to see what's available on your install.

## Custom themes

Drop a JSON file under `~/.config/opencorvus/themes/<name>.json` with the standard opencode theme schema, then reference it by name in `tui.json`. The TUI hot-reloads themes when the file changes.

## Server / overlay theming

The HTTP server and Overlay UI have their own dark/light scheme decoupled from the TUI palette; the `theme` key in `tui.json` does not affect them.
