## Causal chain

1. **Observable hover defect:** at a wide scaled left rail, the summary popup can appear over the rail instead of beginning beside it.
2. **Direct hover trigger:** both summary roots request `right-start`, but allow Popper to flip when the popup does not fit; the Project tooltip is also anchored only to its inner toggle instead of the complete row including actions.
3. **Hover root repair:** use Kobalte's public `getAnchorRect` to combine the real left project-column horizontal boundary with the hovered row's vertical rectangle, then disable opposite-side flipping for these read-only context cards. Keep viewport sliding and the current accessible Tooltip/content projection.
4. **Observable tab defect:** a normal Right Dock width displays one tab and moves two ordinary tabs into `···`.
5. **Direct tab trigger:** `.right-dock-tab-shell` forces every label to at least `184px * ui-scale`, independent of its actual icon/title/close content. The overflow budget also uses a hard-coded four-pixel gap while CSS owns an eight-pixel scaled gap.
6. **Tab root repair:** make tab shells compact content-sized capsules within a bounded width and let `RightDock` read the canonical computed TabList gap when budgeting overflow. Preserve the one collection/state model and keep overflow only for real lack of space.

- Right Dock tab shells now have a 112px compact lower bound and 240px upper bound while their capsules size to content. Overflow budgeting reads the rendered TabList `columnGap`, so CSS remains the spacing source of truth.
- The shared Work Ledger browser fixture was stale against the backend timeline contract: its task lacked `orderKey`, so real selection hydrated a board and then correctly rejected the malformed task. The fixture now uses the canonical test timeline-order helper and exposes complete replay/history cursor fields. Selection diagnostics include recent runtime errors, preventing future preparation failures from being misreported as tab timeouts.
