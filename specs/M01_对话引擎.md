# M01 · 对话引擎

**优先级**：P0 · 阶段 0
**依赖**：无
**负责范围**：`session.store` · `useChat` · `ChatPanel` · `MessageList` · `InputBar` · `Sidebar`

---

## 1. 模块目标

管理用户与 AI 之间的全部会话生命周期：消息收发、流式写入、历史持久化、会话切换。
所有其他模块的输入（用户意图）和输出（AI 回复）都经由本模块流转。

---

## 2. 用户故事

- **US-01**：作为用户，我可以在输入框输入自然语言并发送，看到 AI 逐字流式回复，感受接近实时对话的体验。
- **US-02**：作为用户，我可以在侧边栏看到历史会话列表，点击切换，历史消息立即还原。
- **US-03**：作为用户，当 AI 正在回复时，我可以点击「停止」按钮中断流，已生成的内容保留。

---

## 3. 功能规格

### 3.1 会话生命周期

| 操作 | 触发条件 | 行为 |
|---|---|---|
| 创建会话 | 点击「新对话」或首次访问 | 生成 UUID，写入 `sessions`，`currentSessionId` 切换 |
| 自动命名 | 首条用户消息发送后 | 取消息前 30 字作为 `title` |
| 切换会话 | 点击侧边栏某条历史 | `currentSessionId` 更新，消息列表重新渲染 |
| 归档会话 | 右键菜单「归档」 | `isArchived = true`，从主列表消失，进入归档分组 |
| 删除会话 | 右键菜单「删除」，二次确认 | 从 `sessions` 中移除，切换到最近一条有效会话 |

### 3.2 消息收发

**发送流程**（`sendMessage` 函数）：
1. 用户触发发送（Enter 键或按钮）
2. 校验：内容不为空，且当前无进行中的流（`isStreaming === false`）
3. 写入 `user` 消息到 `session.store`
4. 设置 `isStreaming = true`，清空 `streamingBlocks`
5. 调用 `getLLMService().chat(messages)` 获取 `AsyncGenerator`
6. `for await` 消费事件，每个事件调用 `appendStreamEvent`
7. 收到 `type === 'done'` → 调用 `finalizeAssistantMessage`，流结束
8. 收到 `type === 'error'` → 调用 `setStreamError`，显示错误气泡

**中止流程**（`stopStreaming` 函数）：
1. 调用 `llmService.abort()`
2. 将已积累的 `streamingBlocks` 作为 assistant 消息落库（不丢内容）
3. `isStreaming = false`

### 3.3 输入框行为

| 场景 | 行为 |
|---|---|
| Enter | 发送（非 Shift+Enter）|
| Shift+Enter | 换行 |
| 发送中 | 输入框禁用，显示停止按钮 |
| 空内容 | 发送按钮置灰，阻止提交 |
| 粘贴代码 | 保留格式（textarea 原生支持）|
| 最大高度 | 输入框最高 160px，超出内部滚动 |

### 3.4 消息列表行为

- 新消息追加时，自动滚动到底部（仅当用户当前处于底部时）
- 用户向上滚动时，停止自动滚动，显示「↓ 滚动到最新」按钮
- 流式消息渲染：每次 `appendStreamEvent` 后增量更新，不全量重渲
- 消息间距：用户消息右对齐，助手消息左对齐

### 3.5 侧边栏行为

- 展示当前用户的全部未归档会话，按 `updatedAt` 降序
- 每条会话显示：标题 + 相对时间（"2 分钟前"）
- 当前会话高亮
- 右键菜单：重命名 / 归档 / 删除

## 4. 数据结构

```typescript
// src/stores/session.store.ts

export type MessageRole = 'user' | 'assistant'

export interface Message {
  id: string
  role: MessageRole
  content: string                    // 纯文本内容（用于 LLM 上下文构建）
  contentBlocks?: ContentBlock[]     // 结构化块（渲染用，assistant 消息专属）
  createdAt: Date
}

export type ContentBlock =
  | { type: 'text';    content: string }
  | { type: 'code';    language: string; code: string }
  | { type: 'chart';   spec: object }
  | { type: 'table';   columns: string[]; rows: unknown[][] }
  | { type: 'disclaimer'; content: string }

export interface ChatSession {
  id: string
  title: string
  messages: Message[]
  isArchived: boolean
  createdAt: Date
  updatedAt: Date
}

export interface SessionState {
  sessions: ChatSession[]
  currentSessionId: string | null
  isStreaming: boolean
  streamingBlocks: ContentBlock[]
  streamError: string | null

  // ── Actions ──────────────────────────────────────────────
  createSession: () => string
  selectSession: (id: string) => void
  renameSession: (id: string, title: string) => void
  archiveSession: (id: string) => void
  deleteSession: (id: string) => void

  addUserMessage: (content: string) => string      // 返回 messageId
  appendStreamEvent: (event: StreamEvent) => void  // 流式增量写入
  finalizeAssistantMessage: (id: string) => void   // 流结束，落库
  setStreaming: (v: boolean) => void
  setStreamError: (err: string | null) => void
  clearStreamingBlocks: () => void
}
```

## 5. Store 状态机

```
空闲（isStreaming=false）
  → sendMessage()
  → 写入 user 消息
  → setStreaming(true)
  → 流式中（isStreaming=true）
      → appendStreamEvent() × N
      → 收到 'done'  → finalizeAssistantMessage() → 空闲
      → 收到 'error' → setStreamError() → 错误态（isStreaming=false）
      → stopStreaming() → finalizeAssistantMessage() → 空闲
```

## 7. Mock 设计

Mock 模式下 `MockLLMService` 根据用户输入匹配场景（见 M02），
返回预制的 `StreamEvent[]`。`session.store` 的全部逻辑不变，
与 Mock/Real 无关。

会话历史通过 `zustand/middleware/persist` 写入 `localStorage`，
本地刷新后自动恢复。Mock 模式下完全可用。

---

## 8. 错误处理

| 错误场景 | 处理方式 |
|---|---|
| LLM 调用超时 / 网络断开 | `setStreamError('连接超时，请重试')` |
| 流式中用户刷新页面 | 已写入的流式块落库（persist 实时写入）|
| 会话列表为空 | 自动创建一个默认会话 |
| 删除当前会话 | 自动切换到最近的其他会话；若无则创建新会话 |

---

## 9. 验收标准

- [ ] 发送消息后，用户消息立即出现在列表，不等待 AI 回复
- [ ] 流式文本逐字追加，无闪烁，无全量重渲
- [ ] Shift+Enter 换行，Enter 发送，二者互不干扰
- [ ] 流式进行中点击停止，已生成内容不丢失
- [ ] 切换会话后，消息历史完整还原
- [ ] 刷新页面后，会话历史通过 localStorage 自动恢复
- [ ] 删除最后一条会话后，自动创建新会话
