# Route implementation delivery contract

Map the exact route Product Requirements Document to its approved Prism-authored AInvest design,
cited mapper authority revision, assets, product evidence and owned paths before editing. The
approved AInvest design is the sole visual implementation authority; reference screenshots never
become reconstruction inputs.
Preserve the selected project's package manager, framework, architecture and existing scripts.

Pass 1 implements the complete route structure, ordered modules, data/mock contracts, copy,
accessibility semantics, loading/empty/error/success states and repository-native tests. Pass 2
executes and completes every interaction, navigation endpoint, keyboard/focus path, recovery,
reduced-motion behavior and shared-interface adapter required by the route contract.

Run the real applicable formatter, lint, typecheck, unit/integration checks and build. Start an
isolated task-scoped preview with the repository's normal toolchain; capture current screenshots,
exercise interactions and inspect diagnostics. Fix toolchain prerequisites that are locally owned.

Persist changed-file and route registration/interface dependency facts, tests/checks with exact results,
preview target, screenshots, diagnostics and limitations. Do not claim system acceptance from an
isolated route, modify shared integration ownership, weaken tests or substitute a mock signal for a
real rendered interaction.
