## 2. 设计哲学

### 2.1 核心原则

| 原则 | 描述 | 正例 | 反例 |
|---|---|---|---|
| **金融级专业感** | 视觉风格借鉴 Bloomberg Terminal / Wind 金融终端的信息密度与克制用色 | 深色背景 + 高对比度数据 + 统一间距 | 彩色渐变背景、圆角过大、过度装饰 |
| **信息密度优先** | 单屏展示尽可能多的有效信息，减少空白浪费 | 紧凑的表格行高（36px）、侧边栏收窄（240px） | 大量留白、超宽 padding |
| **一致性** | 同类元素在任何位置的视觉表现相同 | 所有 Badge 用同一套 size/color token | 不同页面的 Badge 各写各的样式 |
| **无障碍底线** | 文字/背景对比度 ≥ 4.5:1（WCAG AA） | `#E2E8F0` on `#0F1117` = 15.4:1 ✓ | `#64748B` on `#1E293B` = 2.8:1 ✗ |

### 2.2 视觉参考

- **主色调**：冷灰蓝（Slate 色系）
- **强调色**：蓝色（#3B82F6），仅用于可交互元素和当前态
- **金融数据色**：涨（#10B981 绿）、跌（#EF4444 红）、中性（#94A3B8 灰）
- **品牌金**：#D4A853，仅用于 Logo 和极少数品牌标记

### 3.3 主题切换 Hook

文件路径：`src/hooks/useTheme.ts`

```typescript
import { useCallback, useSyncExternalStore } from 'react'

type Theme = 'dark' | 'light'

const STORAGE_KEY = 'aimecode-theme'

function getTheme(): Theme {
  return (document.documentElement.getAttribute('data-theme') as Theme) || 'dark'
}

function subscribe(callback: () => void): () => void {
  // 监听 data-theme 变化
  const observer = new MutationObserver(callback)
  observer.observe(document.documentElement, {
    attributes: true,
    attributeFilter: ['data-theme'],
  })
  return () => observer.disconnect()
}

export function useTheme() {
  const theme = useSyncExternalStore(subscribe, getTheme, () => 'dark' as Theme)

  const setTheme = useCallback((t: Theme) => {
    document.documentElement.setAttribute('data-theme', t)
    localStorage.setItem(STORAGE_KEY, t)
  }, [])

  const toggleTheme = useCallback(() => {
    setTheme(getTheme() === 'dark' ? 'light' : 'dark')
  }, [setTheme])

  return { theme, setTheme, toggleTheme }
}
```

## 10. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | Tailwind purge 删掉动态拼接的 class（如 `badge-${status}`） | 在 tailwind.config.js 的 safelist 中加入 `badge-success`、`badge-error` 等；或改用对象映射 `{ success: 'badge-success' }[status]` |
| T2 | Google Fonts 加载慢导致 FOUT | `<link>` 使用 `display=swap`，且 body 字体设 fallback 到 system-ui |
| T3 | CSS Custom Properties 不参与 Tailwind JIT purge | 颜色定义在 `tailwind.config.js` 中用 `var()` 引用——Tailwind 不解析 var() 的实际值，但会正确输出 class |
| T4 | Plotly.js paper_bgcolor / plot_bgcolor 不响应 CSS 变量 | 在 `getPlotlyThemeLayout()` 中读取当前主题后传入固定 hex 值 |
| T5 | 暗色主题首次加载白闪 | `index.html` `<head>` 内联同步脚本读取 localStorage，在任何 CSS 加载前设置 `data-theme` |
| T6 | 主题切换时滚动条颜色延迟 | Firefox `scrollbar-color` 跟随 CSS 变量自动变化；Webkit `::-webkit-scrollbar-thumb` 也用 var()，同步生效 |
| T7 | `react-resizable-panels` 的 handle 在暗色下不可见 | 给 handle 设置 `background: var(--color-border)` + hover 时变亮 + 4px 宽度 |
| T8 | Sonner toast 默认样式与设计系统冲突 | 用 `<Toaster />` 的 `toastOptions` 覆盖默认样式，或完全自定义 Toast 组件 |
| T9 | Inter/JetBrains Mono 的 font-weight 不完整 | 只加载 400/500/600/700（Inter）和 400/500/600（JetBrains Mono），不加载全部 |
| T10 | 浅色主题下 accent 色（#3B82F6）对比度不够 | 浅色主题 accent 改用 #2563EB（对比度 4.6:1 on white） |
