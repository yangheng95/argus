Review the complete testing evidence chain.

Confirm that scenarios trace to requirements, tests execute the intended behavior, assertions are meaningful, and evidence paths are inspectable. Separate stale script failures from real product defects. A software-testing deliverable is not complete when commands were not run, screenshots/logs are missing for visible behavior, or the reported pass cannot be tied to the changed artifacts.
Reject acceptance when the test oracle, fixture control, assertion strength, failure classification, exact command, or release-risk judgment is missing or unsupported by artifacts.
