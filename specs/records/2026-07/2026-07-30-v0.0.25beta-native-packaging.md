- 当前无 Apple notarization 凭据，只能交付 ad-hoc signed、未 notarize 的本地 beta 包。

## 打包与修复记录

- `bun run version:check` 确认 release-family 版本一致为 `0.0.25-beta`。
- `bun run package:gui-installer-matrix` 完成 `darwin-arm64` GUI executable、DMG 与 App archive。
- `bun run package:binary-matrix` 完成 `darwin-arm64` CLI runtime 与 archive。
- 构建器发现检入的 OpenTest payload 仍为 `2026.07.24.2`，而当前 package 源为 `2026.07.30.1` 且已声明 `capability_search`；canonical generator 已更新 payload。
- resolver 正向测试进一步发现 package tool 与 Browser MCP owner 完整集合仍引用旧事实；测试已同步为当前 manifest 的精确正向合同，不增加 alias 或兼容路径。

## 交付验证

- GUI 与 CLI executable 均为 thin `arm64` Mach-O。
- App bundle、staged GUI executable 与 CLI executable 均通过 `codesign --verify --strict`；App 为 ad-hoc runtime signature。
- `hdiutil verify` 确认 DMG checksum 有效。
- App archive 包含 `OpenCorvus.app`、签名资源和 executable。
- CLI archive 包含 `opencorvus`、`ui/index.html`、`bin/rg`、Browser MCP Node runtime 与 package metadata。
- CLI `--version`、App `CFBundleShortVersionString` 与 `CFBundleVersion` 均为 `0.0.25-beta`。
- Linux x64 / ARM64、macOS x64、Windows x64 rows 因非本机原生环境明确 skipped。
- expert-squad payload / resolver 正向合同测试 25 项通过；历史文档链接测试 22 项通过。
- 全仓 typecheck 8 / 8 通过；`docs:check`、`api:routes-check`、`version:check` 与 `git diff --check` 通过。
