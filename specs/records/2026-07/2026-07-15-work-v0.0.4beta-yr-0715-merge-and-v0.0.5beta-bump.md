## Codex review feedback

- The initial path audit found no overlap between the then-current dirty tree and the fetched
  target. During the subsequent Recall read, parallel work added modifications to the generated
  JavaScript SDK and OpenAPI artifacts; both are target-branch paths. The zero-overlap premise is
  therefore stale and a direct merge is no longer safe.
- The implementation plan is revised to preserve the entire live dirty tree in an explicit
  `dsw-33987` checkpoint commit before merging. This follows the prior branch-sync precedent and
  gives every concurrent change a recoverable Git object without using stash, reset, restore, or
  a second worktree. Any edits that arrive after that checkpoint remain ordinary dirty changes
  and must still be retained outside the merge/version delivery.
- The checkpoint push exposed a pre-existing defect in `script/check-sdk-imports.ts`: it scans raw
  lines with a regular expression and therefore treats generated documentation strings as live
  TypeScript symbols. The new MirrorTest package payload contains migration documentation mentioning
  `OpencodeClient`, which is not an executable SDK reference, so the hook rejected a valid payload.
  Whole-repository search found one production checker and one contract test duplicating the same
  text-scan semantics. The checker must be repaired first to inspect TypeScript identifier nodes,
  with regression coverage proving that real deprecated identifiers fail while strings and comments
  do not; exempting the payload path or editing the documentation would be a fallback.
- The first merged focused run reached the real Overlay checker and exposed nine failures in
  `overlay-architecture-guards.test.ts`. Source comparison showed that the guard still assigned
  mounts and task-scope headers to `App.tsx` even though `main.tsx` and `Board.tsx` are now the
  canonical owners, and it still asserted retired composer, Integrity, palette, and header values.
  Those assertions were updated to the current single owners. The same run found real duplicate
  selector debt and raw `999px` / `1px` literals in merged surface styles; the selectors were
  consolidated without raising budgets and the literals now use existing radius and border tokens.
- The Node-launched browser run then found two cross-branch expectation conflicts. The fetched
  browser test expected the pre-redesign transparent Agent bubble, while the current branch's
  source and static tests intentionally own a quiet inset surface with a full-height identity rail.
  The browser contract now checks that the surface stays stable across rest and hover. The titlebar
  test also expected retired 32px/26px geometry although both sources declare 30px search and 28px
  environment controls. Browser evidence additionally proved the environment SVG was being expanded
  to 24px by the shared icon-button rule, so the owning conversation selector now enforces the JSX
  contract of 14px with a static regression test.
