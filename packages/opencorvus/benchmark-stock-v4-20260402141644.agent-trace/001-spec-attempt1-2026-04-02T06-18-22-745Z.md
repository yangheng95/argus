### 后端 API

1. **认证**
   - `POST /api/auth/register` — 用户名+密码注册，初始资金 1,000,000

   - `GET /api/market/stocks` — 股票列表（代码、名称、最新价、涨跌幅、成交量）

   - `GET /api/market/sse` — SSE 实时行情推送（每 2 秒一次全量快照）

3. **交易**
   - `POST /api/trading/buy` — 限价买入（股票代码、数量、价格）
   - `POST /api/trading/sell` — 限价卖出
   - `POST /api/trading/cancel/:id` — 撤销挂单
   - `GET /api/trading/orders` — 当前委托单列表（pending/filled/cancelled）

4. **持仓**
   - `GET /api/portfolio` — 当前持仓（股票、数量、成本价、市值、盈亏）
   - `GET /api/portfolio/summary` — 总资产、可用资金、总市值、总盈亏、收益率

5. **历史**
   - `GET /api/history/trades` — 成交记录（支持 ?stock=&limit=&offset=）
   - `GET /api/history/daily` — 每日资产曲线（最近 30 天）

### 行情模拟引擎

- 预置 10 只模拟股票（代码 SH600001-SH600010，中文名称）
- 每 2 秒生成一次新价格：
  - 基于上一个价格 ± 随机波动（正态分布，σ=0.5%）
  - 叠加趋势因子（每只股票有隐含趋势 -0.1% ~ +0.1%）
  - 涨跌幅限制 ±10%（基于当日开盘价）
- 每次价格变动自动撮合挂单：
  - 买单：市价 ≤ 买入价 → 成交
  - 卖单：市价 ≥ 卖出价 → 成交
- 服务启动时生成当日历史价格（60 个点，模拟开盘至今）

## 关键实现决策

### 1. 数据库初始化策略 (`src/db.ts`)
- 使用 `bun:sqlite` 的 `Database` 类
- 启动时检查表是否存在，不存在则执行 DDL
- 种子数据插入 10 只股票（SH600001-SH600010）
- 生成当日 60 个历史价格点（模拟开盘至今）

### 2. SSE 实现 (`src/market.ts`)
- 使用 Hono 的 `stream` 辅助函数
- 维护全局客户端连接列表（Set）
- 每 2 秒广播全量股票快照（JSON 格式）
- 连接断开时从列表移除

### 3. 行情模拟引擎 (`src/simulator.ts`)
- 使用 `setInterval` 每 2 秒执行一次
- 价格生成算法：
  ```typescript
  const randomChange = (Math.random() - 0.5) * 0.01; // ±0.5%
  const trendChange = stock.trend;
  let newPrice = lastPrice * (1 + randomChange + trendChange);
  // 涨跌停限制 ±10%
  const limitUp = stock.open_price * 1.1;
  const limitDown = stock.open_price * 0.9;
  newPrice = Math.max(limitDown, Math.min(limitUp, newPrice));
  ```
- 撮合逻辑：遍历 pending 订单，市价满足条件则成交

### 4. 认证中间件 (`src/auth.ts`)
- 从 `Authorization: Bearer <token>` 提取 token
- 查询 sessions 表验证
- 未认证返回 401 JSON 响应

### 5. 前端路由结构

### 6. 前端状态管理
- 使用 React Context + useState 管理全局认证状态
- SSE 连接在 `useSSE` hook 中管理，自动重连
- API client 封装 fetch，自动附加 Authorization header
