# Bug Hunt Findings - 2026-06-17

## Scope

User objective: run an unattended, self-iterating bug hunt using independent agents as colleagues. Each iteration must use an independent agent to look for new shallow and deep defects. Found issues are recorded in this document only; no implementation fixes are performed.

Status: in progress. Iteration 26 is running at the time this document is first written. The stop condition has not been met yet because every completed convergence round through iteration 25 still found at least one new issue.

Glossary: API means Application Programming Interface. SDK means Software Development Kit. CLI means Command Line Interface. UI means User Interface. LSP means Language Server Protocol. PTY means Pseudo Terminal. CORS means Cross-Origin Resource Sharing. DB means Database. MCP means Model Context Protocol. LLM means Large Language Model. PR means Pull Request. SVG means Scalable Vector Graphics. SSE means Server-Sent Events.

## Method

- Read project rules and recent design records before modifying anything.
- Spawned independent read-only explorer agents across backend, runtime, frontend, tooling, security, and release surfaces.
- Excluded already known findings on each later iteration to force new discovery.
- Locally spot-checked major findings with read-only file inspection and focused searches.
- Ran a small set of targeted tests during early triage only; no fixes were attempted.
- Current finding records are grouped by root-cause family, but each entry keeps a concrete file surface and regression-test direction.
