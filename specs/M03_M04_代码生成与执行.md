# M03 · 代码生成引擎 & M04 · 代码执行沙箱

> M03 和 M04 在客户端共用同一个 `CodeBlock` 组件，PRD 合并撰写。

**优先级**：M03 P0 · M04 P0（阶段0）
**依赖**：M01（会话上下文）· M07（渲染展示）
**负责范围**：`code_block` StreamEvent · `CodeBlock` 组件 · `useExecutor` hook · `IExecutorService`

> **阶段 0 必须交付（M03）**：Python 内联数据代码生成（规则 R1–R4）、`code_block` StreamEvent 接收与渲染、一键复制按钮。
> **阶段 0 必须交付（M04）**：运行按钮 UI + MockExecutorService（延迟 800ms 返回预制结果）、执行结果区域渲染（stdout + 图表）。
> **阶段 1 交付（M04 Real）**：真实 Python 沙箱 SandboxService（`POST /execute`），安全隔离部署。SQL / R 代码生成也推迟到阶段 1 按需开启。

---

## 1. 模块目标

**M03**：LLM 输出可直接运行的代码，代码中内联真实数据，无占位符。
**M04**：用户点击「运行」按钮后，代码在安全环境中执行，结果（输出文本 + 图表）渲染在代码块下方。

---

## 2. 用户故事

- **US-01**：AI 生成的 Python 代码我可以一键复制，粘贴到 Jupyter 直接运行，无需修改任何变量。
- **US-02**：我在代码块内点击「运行」，几秒后看到执行结果（print 输出 + 图表），不需要切换到任何外部工具。
- **US-03**：代码执行出错时，我看到清晰的错误提示（哪一行、什么类型的错误），而不是原始 traceback。

## 3. 功能规格

### 3.1 M03：代码生成规范

AI 在生成代码时必须遵守以下规则（通过 system prompt 约束，见 `src/services/llm/mock.ts` 中的预制代码片段）：

**规则 R1 · 内联数据**
代码中使用工具查询返回的真实数据（Hard-code 为 dict / list），不使用 `fetch_data()` 之类的占位符。

```python
# ✅ 正确：数据已内联
data = {'period': ['2023Q1', '2023Q2'], 'roe': [0.30, 0.32]}

# ❌ 错误：占位符
data = fetch_financial_data(ticker='600519.SH')
```

**规则 R2 · 关键步骤注释**
每个逻辑段落前有一行中文注释，说明该步骤目的。

**规则 R3 · 优先使用标准库**
按优先级：`pandas / numpy / matplotlib / plotly`，不引入未预装的包。

**规则 R4 · 图表自包含**
若代码生成图表，末尾调用 `fig.show()` 或 `plt.show()`，在 Mock 模式中沙箱捕获 Figure 对象序列化为 JSON。

### 3.2 M04：代码执行流程

```
用户点击 CodeBlock 的「运行」按钮
  ↓
useExecutor.execute(code, sessionId)
  ↓
IExecutorService.execute({ code, language: 'python', sessionId })
  ↓
  [Mock 模式] MockExecutorService：
    - 延迟 800ms
    - 根据代码内容匹配预制执行结果
    - 返回 ExecutionResult
  ↓
  [Real 模式] SandboxService：
    - POST http://sandbox:8001/execute
    - 返回真实执行结果
  ↓
CodeBlock 渲染执行结果区域
```

### 3.3 执行结果展示规则

| 结果类型 | 渲染方式 |
|---|---|
| `stdout` 非空 | 黑底白字终端风格文本框，最多展示 50 行，超出折叠 |
| `charts` 非空 | 在终端输出下方渲染 Plotly 图表（复用 ChartRenderer）|
| `status === 'error'` | 红色背景错误面板，显示错误类型 + 关键行 |
| `status === 'timeout'` | 黄色警告：执行超时（超过 30 秒），代码可能有无限循环 |
| `durationMs` | 右下角显示执行耗时，如 `1.2s` |

### 3.4 代码块 UI 状态机

```
idle（默认）
  → 用户点击「运行」
  → running（显示 loading spinner，禁用运行按钮）
      → 收到结果
      → done（展示结果区域，运行按钮恢复）
      → 用户再次点击「运行」
      → running（清空上次结果，重新执行）
  → error（显示错误面板）
  → timeout（显示超时警告）
```

## 5. Hook 规格

### useExecutor（`src/hooks/useExecutor.ts`）

```typescript
export function useExecutor() {
  const [status, setStatus] = useState<'idle'|'running'|'done'|'error'|'timeout'>('idle')
  const [result, setResult] = useState<ExecutionResult | null>(null)

  const execute = async (code: string) => {
    setStatus('running')
    setResult(null)
    try {
      const svc = getExecutorService()
      const res = await svc.execute({
        code, language: 'python',
        sessionId: useSessionStore.getState().currentSessionId ?? ''
      })
      setResult(res)
      setStatus(res.status === 'ok' ? 'done' : res.status)
    } catch {
      setStatus('error')
    }
  }

  return { execute, status, result }
}
```

## 7. Mock 设计

### MockExecutorService（`src/services/executor/mock.ts`）

```typescript
export class MockExecutorService implements IExecutorService {
  async execute({ code }: { code: string; language: 'python' | 'sql' | 'r'; sessionId: string }) {
    await sleep(800)  // 模拟执行延迟

    // 根据代码内容选择预制结果
    if (code.includes('go.Figure') || code.includes('plotly')) {
      return MOCK_RESULTS.plotlyChart
    }
    if (code.includes('plt.') || code.includes('matplotlib')) {
      return MOCK_RESULTS.matplotlibChart
    }
    if (code.includes('print(')) {
      return MOCK_RESULTS.printOutput
    }
    return MOCK_RESULTS.default
  }
}
```

## 8. 错误处理

| 场景 | 显示 |
|---|---|
| `KeyError` / `NameError` | "变量 'xxx' 未定义，请检查数据字段名" |
| `ImportError` | "模块 'xxx' 未安装，请使用预装库（pandas/numpy/plotly）" |
| 超时 | "执行超时（>30s），代码中可能存在无限循环" |
| 沙箱服务不可用 | "代码执行服务暂不可用，代码已复制到剪贴板，可粘贴到本地环境运行" |

所有错误信息面向用户（非原始 traceback），同时在 console 中保留完整 traceback 供调试。
