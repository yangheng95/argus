Tank Battle FC 风格重制 PRD

1. 目标

将当前 Tank Battle 游戏的视觉风格从简陋的纯色方块升级为经典 FC/NES 8-bit 像素风格。
不使用任何外部图片资源，全部用 Canvas API 逐像素绘制精灵（sprite）。
保持现有游戏逻辑不变，只重写 renderer.ts 和相关绘制代码。

技术约束：纯 Canvas API，零外部依赖，零图片文件，所有精灵用代码绘制。

2. FC 风格精灵规范

每个精灵用 16×16 像素矩阵定义，缩放 3 倍绘制为 48×48。
用二维数组存储精灵数据，每个值对应调色板索引。

2.1 调色板（NES 风格）

```
const PALETTE = {
  0: 'transparent',
  1: '#000000',  // 黑色（轮廓）
  2: '#FCE4A8',  // 浅黄（坦克高光）
  3: '#E8A838',  // 金黄（玩家坦克主色）
  4: '#885818',  // 深棕（玩家坦克阴影）
  5: '#F83800',  // 红色（敌方坦克/爆炸）
  6: '#A80000',  // 暗红（敌方坦克阴影）
  7: '#00A800',  // 绿色（草丛/Armor 坦克）
  8: '#005800',  // 深绿（草丛阴影）
  9: '#3CBCFC',  // 浅蓝（水面/Fast 坦克/冰面）
  10: '#0078F8', // 蓝色（水面深色）
  11: '#BCBCBC', // 浅灰（钢墙高光）
  12: '#7C7C7C', // 深灰（钢墙阴影）
  13: '#A84000', // 砖红（砖墙主色）
  14: '#E87040', // 浅砖红（砖墙高光）
  15: '#FFFFFF', // 白色（子弹/文字/闪烁）
  16: '#FC74B4', // 粉色（Power 坦克）
  17: '#F8B800', // 橙黄（爆炸火焰）
  18: '#503000', // 深棕（地面底色）
  19: '#FCB8B8', // 浅粉（Boss 坦克高光）
}
```

2.2 玩家坦克精灵（朝上）

必须有清晰的炮管、履带、车身结构：
- 中央上方突出 2 像素宽的炮管
- 左右两侧各 3 像素宽的履带（带锯齿纹理）
- 车身中央 8×8 区域，带十字或菱形装甲花纹
- 颜色：金黄为主（调色板 2,3,4），黑色轮廓（1）
- 四个方向各一个精灵（旋转绘制，炮管朝向对应方向）
- 移动时履带有 2 帧动画（锯齿交替）

2.3 敌方坦克精灵

四种类型各有独立配色：
- Basic：灰白色（11,12），方正朴素造型
- Fast：浅蓝色（9,10），流线型，小巧
- Power：粉紫色（16,6），炮管更粗
- Armor：绿色（7,8），厚重，两侧有装甲板
  - 被击中变色：绿 → 黄(3) → 橙(17) → 红(5)
- Boss：大型（占 2×2 格），深红+金色，有双炮管

每种类型 4 方向 × 2 帧 = 8 个精灵变体

2.4 地形精灵

砖墙（16×16）：
- 4×4 砖块排列，每块砖之间有 1 像素深色缝隙
- 主色 #A84000，高光边 #E87040，缝隙 #503000
- 被击中时只破坏半块（支持半砖状态）

钢墙（16×16）：
- 金属面板效果，左上高光，右下阴影
- 表面有 2×2 铆钉装饰（4 个角各一个）
- 主色 #BCBCBC，高光 #FFFFFF，阴影 #7C7C7C

河流（16×16，2 帧动画）：
- 波纹效果，蓝色为主
- 帧 1：波纹朝右
- 帧 2：波纹朝左
- 每 500ms 切换帧

草丛（16×16）：
- 密集的草叶效果，随机分布的深浅绿色像素
- 绘制在坦克上层（遮挡效果）
- 边缘不规则（不是整齐的方块）

冰面（16×16）：
- 浅蓝半透明效果，表面有对角裂纹
- 偶尔闪光效果

炸药桶（16×16）：
- 红色圆桶，顶部有导火索
- 桶身有横条纹

传送门（16×16，4 帧动画）：
- 旋转的蓝紫色漩涡
- 每 200ms 切换帧

2.5 基地鹰徽（16×16）：
- 金色老鹰图案，展翅造型
- 被摧毁后变为灰色废墟

2.6 子弹（4×4 像素）：
- 白色核心 + 黄色光晕
- 方向朝前略拉长

2.7 爆炸动画（5 帧）：
- 帧 1：小十字形火花（8×8）
- 帧 2：放射形火焰（16×16）
- 帧 3：最大火焰（24×24），红橙黄渐变
- 帧 4：收缩火焰 + 烟雾（16×16）
- 帧 5：烟雾消散（8×8）
- 每帧 80ms

3. 渲染系统重构

3.1 精灵系统 (sprites.ts)
```
// 新增文件，存储所有精灵数据
export const SPRITES = {
  playerUp: number[][]     // 16×16 调色板索引数组
  playerDown: number[][]
  playerLeft: number[][]
  playerRight: number[][]
  playerUpAlt: number[][]  // 移动帧 2
  // ... 4种敌人 × 4方向 × 2帧
  brick: number[][]
  brickHalfLeft: number[][]
  brickHalfRight: number[][]
  brickHalfTop: number[][]
  brickHalfBottom: number[][]
  steel: number[][]
  water1: number[][]
  water2: number[][]
  trees: number[][]
  ice: number[][]
  barrel: number[][]
  portal1: number[][]
  portal2: number[][]
  portal3: number[][]
  portal4: number[][]
  base: number[][]
  baseDestroyed: number[][]
  bullet: number[][]       // 4×4
  explosion1-5: number[][] // 爆炸帧
}
```

3.2 精灵渲染函数
```typescript
function drawSprite(ctx: CanvasRenderingContext2D, sprite: number[][], x: number, y: number, scale: number = 3) {
  for (let row = 0; row < sprite.length; row++) {
    for (let col = 0; col < sprite[row].length; col++) {
      const colorIndex = sprite[row][col]
      if (colorIndex === 0) continue // transparent
      ctx.fillStyle = PALETTE[colorIndex]
      ctx.fillRect(x + col * scale, y + row * scale, scale, scale)
    }
  }
}
```

3.3 动画管理器
- 每个有动画的对象维护 frameIndex 和 frameTimer
- 坦克移动时每 100ms 切换履带帧
- 河流每 500ms 切换波纹帧
- 传送门每 200ms 切换旋转帧
- 爆炸每 80ms 切换帧，播完自动销毁

4. HUD 面板 FC 风格

- 背景：纯黑 #000000
- 文字：FC 风格像素字体（用 Canvas 像素绘制，非系统字体）
  - 每个字符 8×8 像素，缩放 2 倍显示为 16×16
  - 至少实现 0-9 数字 + A-Z 字母 + 基本符号
- 敌方坦克剩余：用小坦克图标（8×8 缩放）排成网格
- 生命图标：小坦克图标 + 数字
- 关卡标识："IP" + 旗子图标 + 数字
- 分数：上方显示 "1P" 和分数数字

5. 菜单界面 FC 风格

5.1 主菜单
- 黑色背景
- 标题 "TANK BATTLE" 用大号像素字体（每字符 16×16）
- 标题下方有小坦克图标装饰
- 选项前用坦克图标作为光标指示器
- "1 PLAYER" / "START GAME" 选项
- 底部版权文字 "© 2026"

5.2 关卡过场
- 灰色背景从上下两侧合拢的curtain动画
- 中央显示 "STAGE X"（大号像素字）
- 停留 2 秒后 curtain 展开

5.3 Game Over
- "GAME OVER" 从底部缓慢上升到中央
- FC 风格红色大字
- 停留 3 秒后回到菜单

5.4 关卡结算
- 黑色背景
- 逐行显示击杀统计（带计数动画和音效位占位）
- 每种坦克图标 + 数量 + 分数
- 底部总分

6. 特效

6.1 出生动画
- 坦克出生时有 4 帧闪烁旋转光环动画
- 光环从大到小收缩到坦克位置

6.2 无敌闪烁
- 玩家重生后 3 秒无敌
- 无敌时坦克周围有半透明护盾光圈
- 坦克自身快速闪烁（交替显示/透明）

6.3 关卡过渡
- curtain 效果（上下灰色幕布合拢再展开）

6.4 屏幕震动
- 基地被击中/Boss 被消灭时屏幕抖动 300ms
- 偏移量 ±4 像素随机
