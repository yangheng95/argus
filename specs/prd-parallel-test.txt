Build a minimal task tracker using Bun + TypeScript.

Create a shared types module (src/types.ts) with Task interface and TaskFilter type.

Create a store module (src/store.ts) with TaskStore class backed by an in-memory Map. It should support add, toggle, remove, and list operations with filter support.

Create a formatting module (src/format.ts) with functions to format a single task as "[x] title" or "[ ] title", and format a list of tasks with index numbers.

Create tests (src/store.test.ts) using bun:test with at least 6 test cases covering add, toggle, remove, and list with each filter.

Only create or modify these files:
- src/types.ts
- src/store.ts
- src/store.test.ts
- src/format.ts

Do not add package.json, tsconfig.json, README files, or any other files.
The Bun runtime and bun:test are already available.
