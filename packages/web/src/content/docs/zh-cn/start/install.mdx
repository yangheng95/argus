## 前置依赖

| 依赖    | 版本          | 说明                                   |
| ------- | ------------- | -------------------------------------- |
| Bun     | ≥ 1.3.13      | `package.json` 声明为 `packageManager` |
| Node.js | ≥ 22          | `@tsconfig/node22` 目标                |
| Git     | 任意          | 用于 worktree 并行执行                 |
| Python  | ≥ 3.9（可选） | 代码执行与部分 skill 使用              |

Windows 用户：请用 `python`，**不要用 `python3`**（Store stub 会拦截）。

## 安装方式

### 从源码编译

```bash
git clone https://github.com/yangheng95/opencorvus.git
cd opencorvus
bun install
bun run --cwd packages/opencorvus build
bun packages/opencorvus/src/index.ts doctor
# 产物位于 packages/opencorvus/dist/opencorvus-<platform>/opencorvus
```

源码构建是当前唯一写入公开文档的仓库内可验证安装路径。发布 install
脚本或包管理器命令前，必须先在仓库内建立对应分发渠道的自动验证。

仓库 monorepo 结构：`packages/opencorvus`（核心）、`packages/overlay`（Tauri 桌面端）、`packages/channel-runtime`（多 channel 适配）、`packages/channel-config`（channel 注册表与 schema）。

## 验证安装

```bash
bun packages/opencorvus/src/index.ts doctor
```

`doctor` 子命令会检查依赖、网络、LLM provider 连通性。

## 第一次启动前的配置

推荐先创建一份最小项目配置 `<repo>/.opencorvus/opencorvus.jsonc`：

```jsonc
{
  "model": "openai/gpt-5.5",
}
```

然后设置 API Key（选一个 provider）：

```bash
export DASHSCOPE_API_KEY=sk-...       # 阿里云 DashScope
# 或
export ANTHROPIC_API_KEY=sk-ant-...   # Anthropic
# 或
export OPENAI_API_KEY=sk-...          # OpenAI
```

完整配置见 [OpenCorvus 配置](/docs/zh-cn/config/)。

## 启用外部 executor（可选）

若本机已装 `codex` 或 `claude-code` CLI，让 OpenCorvus 自动发现并调度：

```bash
export OPENCORVUS_AUTO_DISCOVER_EXECUTORS=1
```

未安装但在任务中指定对应 executor 时，OpenCorvus **直接拒绝**而不是静默回退。符合「Let it crash」原则。
