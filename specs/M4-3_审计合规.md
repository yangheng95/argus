# AimeCode M4-3 · 审计合规

> **自包含文档**：一个 AI 模型只读这一个文件，就能实现审计日志和数据脱敏。
> **前置条件**：M4-1（用户认证）+ M4-2（多租户权限）已完成。
> **包含**：审计日志表、审计中间件、数据脱敏规则、合规导出、日志查询 API。
> **不包含**：SIEM 集成、实时告警、日志轮转压缩。

---

## 1. 目标与验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 工具调用审计 | 用户通过 chat 调用 `get_financial_report` | `audit_logs` 表新增一条含 userId/timestamp/toolName/params |
| V2 | 登录审计 | 用户登录 | audit_logs 记录 login 事件，含 IP 和 User-Agent |
| V3 | 数据脱敏 | 查询含身份证号的数据 | 返回值中 `身份证` 字段显示 `******1234` |
| V4 | 日志查询 | `GET /api/admin/audit-logs?userId=xxx&from=2024-01-01` | 返回审计日志列表 |
| V5 | 合规导出 | `GET /api/admin/audit-logs/export?format=csv` | 下载 CSV 文件 |
| V6 | 日志不可篡改 | 尝试 `DELETE /api/admin/audit-logs/:id` | 405，审计日志只增不删 |

## 3. 审计中间件

```typescript
// server/middleware/audit.ts

import type { MiddlewareHandler } from 'hono'
import { db } from '../db'
import { auditLogs } from '../db/schema'

export function audit(action: string): MiddlewareHandler {
  return async (c, next) => {
    const start = performance.now()
    const userId = c.get('userId') || null
    const workspaceId = c.get('workspaceId') || null

    await next()

    const durationMs = Math.round(performance.now() - start)
    const status = c.res.status >= 400 ? 'failure' : 'success'

    // 异步写入，不阻塞响应
    queueMicrotask(() => {
      db.insert(auditLogs).values({
        id: crypto.randomUUID(),
        timestamp: new Date().toISOString(),
        userId,
        workspaceId,
        action,
        resource: extractResource(c.req.path),
        resourceId: c.req.param('id') || null,
        details: JSON.stringify(extractSafeDetails(c)),
        ip: c.req.header('X-Forwarded-For') || c.req.header('CF-Connecting-IP') || 'unknown',
        userAgent: c.req.header('User-Agent') || null,
        durationMs,
        status,
      }).run()
    })
  }
}

function extractResource(path: string): string {
  if (path.includes('/sessions')) return 'session'
  if (path.includes('/chat')) return 'chat'
  if (path.includes('/execute')) return 'execution'
  if (path.includes('/auth')) return 'auth'
  return 'other'
}

function extractSafeDetails(c: any): Record<string, unknown> {
  // 不记录敏感字段（API key、密码）
  return { method: c.req.method, path: c.req.path }
}
```

## 4. 数据脱敏

```typescript
// server/services/masking.ts

const MASKING_RULES: Array<{ pattern: RegExp; mask: (match: string) => string }> = [
  // 身份证号
  { pattern: /\d{17}[\dXx]/, mask: (m) => '******' + m.slice(-4) },
  // 手机号
  { pattern: /1[3-9]\d{9}/, mask: (m) => m.slice(0, 3) + '****' + m.slice(-4) },
  // 银行卡号
  { pattern: /\d{16,19}/, mask: (m) => m.slice(0, 4) + '****' + m.slice(-4) },
  // 邮箱
  { pattern: /[\w.-]+@[\w.-]+/, mask: (m) => m[0] + '***@' + m.split('@')[1] },
]

export function maskSensitiveData(text: string): string {
  let result = text
  for (const rule of MASKING_RULES) {
    result = result.replace(new RegExp(rule.pattern, 'g'), rule.mask)
  }
  return result
}
```

## 5. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | 审计写入阻塞响应 | 用 `queueMicrotask` 异步写入 |
| T2 | 审计日志表增长快 | 按月分表或配置自动归档 |
| T3 | details 字段不能含敏感信息 | `extractSafeDetails` 过滤密码和 key |
| T4 | 脱敏规则误伤正常数据 | 只在标记为敏感的字段上应用脱敏 |
