# M07 · 输出渲染层

**优先级**：P0 · 阶段 0
**依赖**：M01（session.store 的 ContentBlock）· M03（code_block）· M05/M06（chart/table 数据）
**负责范围**：`OutputPanel` · `ChartRenderer` · `DataTable` · `CodeBlock`（渲染侧）· `SourceTag` · `Disclaimer` · `useStream`

> **阶段 0 必须交付**：双栏布局（5:7 默认比例，可拖拽调整）、全部 ContentBlock 类型渲染（text/code/chart/table/disclaimer）、DataTable 列排序与数字格式化、MarkdownText 左栏渲染、Disclaimer 渲染、CSV 导出、Plotly 图表下载 PNG。
> **阶段 1 可推迟**：历史消息切换时右栏联动滚动（阶段 0 允许切换后右栏仅清空不联动）、DataTable 超出 200 行时的分页功能（阶段 0 截断展示 + 提示）。

---

## 1. 模块目标

将 `session.store` 中的 `ContentBlock[]` 和流式的 `StreamEvent` 序列，
转换为用户可读、可操作的富文本界面。
这是用户直接感知产品价值的「最后一公里」。

---

## 2. 用户故事

- **US-01**：我看到的图表可以直接截图放进报告，不需要额外处理。
- **US-02**：我可以对数据表格按列排序，快速找到最大/最小值。
- **US-03**：AI 的文字解读和图表、代码块在视觉上有清晰层次，不会混在一起难以阅读。
- **US-04**：流式输出时，文字逐字显示，图表和表格在数据完整后一次性出现，不会出现半渲染的图表。

## 3. 功能规格

### 3.1 双栏布局

```
┌────────────────────┬─────────────────────────────────┐
│  ChatPanel（左）    │  OutputPanel（右）               │
│  - 用户消息        │  - 当前消息的结构化输出           │
│  - 助手文字回复     │  - 图表 / 表格 / 代码块           │
│  - ToolCallBadge   │  - 来源标签 / 免责声明            │
│  - 输入框          │                                  │
└────────────────────┴─────────────────────────────────┘
```

**宽度比例**：默认 5:7，用户可拖拽分隔线调整（最小各 300px）。

**输出面板同步逻辑**：
- 左栏点击某条 assistant 消息 → 右栏滚动到对应输出块
- 右栏内容跟随当前正在流式输出的消息实时更新
- 历史消息切换：点击左栏历史消息 → 右栏渲染该消息的 contentBlocks

### 3.2 ContentBlock 渲染规则

每种 `ContentBlock` 类型对应一个渲染组件：

| ContentBlock 类型 | 渲染组件 | 渲染时机 |
|---|---|---|
| `text` | `MarkdownText`（内联在左栏） | 实时流式追加 |
| `code` | `CodeBlock`（右栏）| 完整 code_block 事件到达后 |
| `chart` | `ChartRenderer`（右栏）| 完整 chart_data 事件到达后 |
| `table` | `DataTable`（右栏）| 完整 table_data 事件到达后 |
| `disclaimer` | `Disclaimer`（右栏底部）| disclaimer 事件到达后 |

**流式渲染策略**：
- `text_delta` 事件：每个 delta 立即追加到左栏当前文本块，使用 `requestAnimationFrame` 批量更新（避免每帧重排）
- `code_block` / `chart_data` / `table_data`：数据完整后一次性渲染到右栏
- 右栏块的出现顺序：与 StreamEvent 到达顺序一致

### 3.4 DataTable 规格

```typescript
interface DataTableProps {
  columns: string[]
  rows: unknown[][]
  sourceInfo?: { source: string; asOf?: string; count?: number }
  maxRows?: number          // 默认 200，超出分页
  highlightColumn?: string  // 高亮某列（如对比场景高亮差值列）
}

// 功能：
// - 点击列标题排序（升序 → 降序 → 原始顺序 循环）
// - 数字列自动右对齐，百分比列自动格式化（0.921 → 92.1%）
// - 金额列自动格式化（1736000000 → 17.36亿）
// - 表头固定，可纵向滚动
// - 右上角导出 CSV 按钮
```

**数字格式化规则**：

| 字段名包含关键词 | 格式化方式 | 示例 |
|---|---|---|
| `margin` / `rate` / `ratio` / `yoy` / `roe` / `roa` | 百分比，1位小数 | 0.921 → 92.1% |
| `revenue` / `profit` / `amount` | 亿元，2位小数 | 1736000000 → 17.36亿 |
| `pe` / `pb` / `ev` | 倍数，1位小数 | 28.4 → 28.4x |
| 其他数字 | 保留2位小数 | |

### 3.5 MarkdownText 规格（左栏文字区）

AI 回复的文字部分在左栏以 Markdown 渲染：
- 支持：**加粗**、`行内代码`、> 引用、有序 / 无序列表、标题
- 不支持：HTML 标签、外链图片（安全考量）
- 代码块（三反引号）：渲染为简化版代码块（无运行按钮），全量代码在右栏 CodeBlock

## 4. Hook 规格

### useStream（`src/hooks/useStream.ts`）

```typescript
// 职责：消费 session.store 的实时状态，为渲染层提供稳定的数据视图
export function useStream() {
  const { streamingBlocks, isStreaming } = useSessionStore()

  // 将 streamingBlocks 分组：左栏文本 vs 右栏结构化块
  const textBlocks  = streamingBlocks.filter(b => b.type === 'text')
  const richBlocks  = streamingBlocks.filter(b => b.type !== 'text')

  const currentText = textBlocks.map(b => b.content).join('')

  return { currentText, richBlocks, isStreaming }
}
```

## 5. 视觉规范

### 块间距与视觉层次

```
右栏布局（从上到下）：
├── [ToolCallBadge × N]       8px gap
├── [CodeBlock]               16px gap
├── [ChartRenderer]           16px gap
├── [DataTable]               16px gap
└── [Disclaimer]              24px top margin，底部 padding
```

### 空状态

- 右栏无内容时：显示「← 向左侧发送消息开始分析」提示（居中，muted 颜色）
- 历史消息无结构化输出时：显示「此消息无图表或表格」提示

## 6. 错误处理

| 场景 | 处理 |
|---|---|
| Plotly spec 格式错误 | ChartRenderer 内部 try/catch，显示「图表渲染失败，原始数据：{JSON}」|
| 表格列数与行数不匹配 | DataTable 过滤掉多余列 / 填充空字符串 |
| 图表宽度为 0（容器未就绪）| useResizeObserver 监听，宽度 > 0 时触发重渲 |
