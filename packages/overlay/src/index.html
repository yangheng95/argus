What This Panel Is For

This is the task cockpit, not decorative chrome: left sets scope, center drives the session, right verifies spec, plan, evaluation, and file changes so the agent does not drift.

Fast Path
1 Set scope first: pick the session or task on the left, and verify the working directory before you send anything.
2 Then give a real brief: choose an executor and send the goal, constraints, and acceptance bar, not just a vague prompt.
3 Watch the right side while it runs: Spec checks understanding, Plan checks route, Goals and Evaluation catch drift, Files shows what actually changed.
4 The titlebar actions are operational tools: Channels for delivery, Settings and Logs for debugging, pin-to-top for long-running supervision.
