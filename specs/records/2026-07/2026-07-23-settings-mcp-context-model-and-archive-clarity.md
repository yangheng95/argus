## Causal Chain

1. The MCP page exposes correct but differently scoped facts without describing their relationship. `capabilityCatalog.active.effective` and `declaration_hash` identify the active expert-squad projection, the member selector shows one Agent’s MCP grants, `/mcp` reports configured server connection state, and the projected pool lists all MCP references available after projection. Presenting them as peers under “Service configuration” makes the internal projection model look like one editable server form.
2. Task Context already reloads reactively whenever the canonical selected Task or directory changes. The manual refresh button duplicates that lifecycle. The empty-state text omits the actual selection surface, so users cannot infer that the left Work Ledger drives this page.
3. Agent Models originally hard-coded the information column to 260 px, then an intermediate 45/55 responsive split still gave the selector more width than its content required. The descriptions in the screenshot are normal data, not exceptional overflow; the correct allocation gives the information column 65% and the selector column 35%.
4. Archive uses the shared `SettingsRow`, but its leading slot and title are separate flex siblings and its base title permits wrapping. Restore also renders a text label while Delete is icon-only. A surface-scoped Archive row layout can align icon/title, clamp the title, and normalize both actions without changing the shared primitive or deletion lifecycle.
