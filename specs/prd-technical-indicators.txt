技术指标与专业 K 线 PRD
==========================

本文档是 `prd-stock-trading-sim.txt` 的扩展规格，全面定义盯盘场景下的图表系统。
覆盖专业 K 线画法、主图叠加指标、副图技术指标、图表工具栏、交互操作与后端计算要求，
使模拟交易终端的看盘能力达到主流券商 App（同花顺/东方财富/通达信）的基线水准。

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 一、图表架构总览

### 1.1 图表区域划分

整个图表区域采用「主图 + N 个副图」的垂直堆叠结构，所有子图共享同一根 X 轴（时间轴），
各自拥有独立 Y 轴。用户可自由增删副图、调整副图高度。

```
┌─────────────────────────────────────────────────────────────────┐
│  工具栏: [K线类型 ▾] [周期 ▾] [主图指标 ▾] [副图指标 ▾] [⊞ ✛ ✎] │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│                      主图区域 (≈55% 高度)                        │
│        K 线 / 分时线 + 主图叠加指标（MA/EMA/BOLL/SAR…）          │
│                                                                 │
│  Y轴                                                        Y轴 │
├─────────────────────────────────────────────────────────────────┤
│                      副图 1: VOL (≈15%)                         │
├─────────────────────────────────────────────────────────────────┤
│                      副图 2: MACD (≈15%)                        │
├─────────────────────────────────────────────────────────────────┤
│                      副图 3: KDJ / RSI / … (≈15%)               │
├─────────────────────────────────────────────────────────────────┤
│  ◄━━━━━━━━━━━━━━━ 共享 X 轴（时间）━━━━━━━━━━━━━━━━►            │
└─────────────────────────────────────────────────────────────────┘
```

#### 高度分配规则

| 配置 | 主图 | 副图 1 | 副图 2 | 副图 3 |
|------|------|--------|--------|--------|
| 主图 + 1 副图 | 70% | 30% | — | — |
| 主图 + 2 副图 | 55% | 22.5% | 22.5% | — |
| 主图 + 3 副图 | 50% | 18% | 16% | 16% |
| 主图 + 4 副图 | 45% | 15% | 14% | 13%+13% |

- 副图之间用 4px 高度的可拖拽分隔条隔开
- 分隔条 hover: cursor `row-resize`，背景 `var(--color-fill-tertiary)`
- 拖拽时实时调整上下两个区域高度（最小高度 60px）
- 最多同时显示 4 个副图

### 1.2 默认配置

首次进入个股详情页时的默认图表状态：
- K 线类型：标准蜡烛图
- 周期：分时
- 主图指标：MA（MA5 + MA10 + MA20）
- 副图 1：VOL（成交量）
- 副图 2：MACD（12, 26, 9）

## 二、K 线类型（主图画法）

提供 6 种主图画法，通过工具栏下拉选择切换。切换不影响已叠加的主图指标。

### 2.1 标准蜡烛图（Candlestick）— 默认

最常用的 K 线类型，实体矩形 + 上下影线。

#### 绘制规则

```
      ┃  ← high（上影线顶部）
      ┃
   ┏━━┻━━┓  ← max(open, close)（实体顶边）
   ┃      ┃
   ┃ 实体  ┃  ← 实体高度 = |open - close|
   ┃      ┃
   ┗━━┳━━┛  ← min(open, close)（实体底边）
      ┃
      ┃  ← low（下影线底部）
```

#### 颜色规则

| 条件 | 实体 | 边框 | 影线 |
|------|------|------|------|
| close > open（涨） | 填充 `var(--color-chart-candle-up)` (#ff453a) | 同色加深 20% (#cc3a2e) | 同实体色 |
| close < open（跌） | 填充 `var(--color-chart-candle-down)` (#30d158) | 同色加深 20% (#26a746) | 同实体色 |
| close == open（十字星） | 无实体，仅一条水平线 | `var(--color-flat)` | `var(--color-flat)` |

#### SVG 绘制参数

- 实体宽度：根据可视蜡烛数量自动计算，`barWidth = (chartWidth / visibleBars) * 0.7`
- 最小实体宽度：3px（缩放极限）
- 最大实体宽度：30px
- 影线 strokeWidth：1px（实体宽度 ≤ 8px 时）或 1.5px（> 8px 时）
- 十字星水平线宽度：等于实体宽度
- 蜡烛间距：实体宽度 × 0.3（即 barGap = barWidth * 0.3）

### 2.2 空心蜡烛图（Hollow Candlestick）

与标准蜡烛图相同的几何形状，但颜色逻辑不同：
- **实心**表示收盘低于开盘（跌）
- **空心**表示收盘高于开盘（涨）

| 条件 | 实体 | 边框 | 影线 |
|------|------|------|------|
| close > open（涨） | 空心（仅边框，内部透明） | `var(--color-chart-candle-up)` | 同边框色 |
| close < open（跌） | 实心填充 | `var(--color-chart-candle-down)` | 同实体色 |
| close > prev_close（相对涨） | 边框/填充色使用涨色 | — | — |
| close < prev_close（相对跌） | 边框/填充色使用跌色 | — | — |

注意：空心蜡烛图的颜色同时考虑两个维度——实心/空心由当根 open vs close 决定，
红/绿由 close vs prev_close 决定。这意味着可能出现「红色空心」「红色实心」
「绿色空心」「绿色实心」四种组合。

### 2.3 Heikin-Ashi 平均 K 线

使用修正后的 OHLC 值绘制，过滤噪音、突出趋势。

#### 计算公式

```
HA_close = (open + high + low + close) / 4
HA_open  = (prev_HA_open + prev_HA_close) / 2     （首根用 (open + close) / 2）
HA_high  = max(high, HA_open, HA_close)
HA_low   = min(low, HA_open, HA_close)
```

#### 特征

- 趋势中蜡烛体更均匀，影线方向一致
- 绘制方式与标准蜡烛图相同（实心、颜色按 HA_close vs HA_open 判断）
- Y 轴刻度仍然使用原始价格范围
- tooltip 同时显示 HA 值和原始 OHLCV 值

### 2.4 美国线 / OHLC Bar

经典的价格柱线画法，无实体填充。

#### 绘制规则

```
      ┃       ← high
      ┃
   ━━━┫       ← open（左侧短横）
      ┃
      ┣━━━    ← close（右侧短横）
      ┃
      ┃       ← low
```

- 竖线：从 high 到 low，strokeWidth 1.5px
- 左横线（open）：从蜡烛中心向左延伸 barWidth/2
- 右横线（close）：从蜡烛中心向右延伸 barWidth/2
- 颜色：close > open 涨色，close < open 跌色

### 2.5 收盘价线（Line Chart）

仅连接每根 K 线的收盘价，形成折线。

- 折线颜色：`var(--color-accent-blue)` (#0a84ff)
- strokeWidth：1.5px
- 无面积填充
- 折线上不显示数据点圆圈（数据密集时会混乱）
- hover 时在最近 bar 位置显示一个 4px 圆点

### 2.6 面积图（Area Chart）

收盘价折线 + 下方渐变填充面积。

- 折线颜色：`var(--color-accent-blue)` (#0a84ff)
- strokeWidth：1.5px
- 面积渐变：
  - 如果当前价 > 昨收：`var(--color-chart-area-up)` → 透明
  - 如果当前价 < 昨收：`var(--color-chart-area-down)` → 透明
- 渐变方向：从折线到图表底部（垂直线性渐变）
- 面积底边固定在图表区域底部

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

## 三、分时图（Timeshare Chart）

分时图是独立于 K 线周期的特殊主图模式，选择「分时」周期时显示。

### 3.1 主区域

- X 轴范围：09:30 ~ 15:00（A 股交易时间），中间 11:30~13:00 为午休（用虚线分隔或灰色区域标记）
- Y 轴：以昨收价为中心对称展开，上下范围相等
- 昨收基准线：水平虚线，`var(--color-text-tertiary)`，dashArray "4 4"
  - 线右端标注「昨收 ¥X.XX」，`--text-caption-2`
- 分时折线：
  - 颜色：`var(--color-accent-blue)` (#0a84ff)
  - strokeWidth：1.5px
  - 折线下方渐变面积填充：
    - 折线在昨收上方的部分：`rgba(255, 69, 58, 0.08)` 向下渐变到透明
    - 折线在昨收下方的部分：`rgba(48, 209, 88, 0.08)` 向上渐变到透明
- 均价线：
  - 颜色：`var(--color-accent-orange)` (#ff9f0a)
  - strokeWidth：1px
  - dashArray："4 4"
  - 计算：累计成交额 / 累计成交量
- Y 轴标注：
  - 左侧 Y 轴：绝对价格
  - 右侧 Y 轴：相对于昨收的涨跌幅百分比
  - 上半部分刻度文字：`var(--color-up)`
  - 下半部分刻度文字：`var(--color-down)`
  - 中心（0%）刻度文字：`var(--color-flat)`

### 3.2 成交量子图

- 与分时主图共享 X 轴
- 占总高度约 20%
- 每根 Bar 颜色：该分钟收盘价 ≥ 开盘价则涨色，否则跌色
- Bar 之间无间隔（分时成交量柱密排）

### 3.3 Tooltip

分时图 hover 时，Tooltip 显示：
- 时间：`HH:mm`
- 价格：`¥X.XX`
- 均价：`¥X.XX`
- 涨跌额：`+X.XX` / `-X.XX`
- 涨跌幅：`+X.XX%` / `-X.XX%`
- 成交量：`XXXX 手`

## 四、K 线周期

### 4.1 周期列表

| 周期标识 | 显示名称 | 每根 bar 时长 | X 轴刻度格式 | 说明 |
|---------|---------|-------------|-------------|------|
| `timeshare` | 分时 | 1 tick（~2s） | `HH:mm` | 特殊模式，见第三章 |
| `1m` | 1分 | 1 分钟 | `HH:mm` | 原始 bar |
| `5m` | 5分 | 5 分钟 | `HH:mm` | 合并 5 根 1m |
| `15m` | 15分 | 15 分钟 | `HH:mm` | 合并 15 根 1m |
| `30m` | 30分 | 30 分钟 | `HH:mm` | 合并 30 根 1m |
| `60m` | 60分 | 60 分钟 | `HH:mm` | 合并 60 根 1m |
| `1d` | 日K | 1 交易日 | `MM/DD` | 合并当日全部 1m |

### 4.2 周期切换 UI

使用 Apple 风格 Segmented Control，位于工具栏中。

选项排列：`分时 | 1分 | 5分 | 15分 | 30分 | 60分 | 日K`

切换时：
1. 立即显示 loading skeleton（保留图表区域大小，内容用 shimmer 占位）
2. 请求对应周期数据
3. 数据到达后平滑替换（opacity 0→1，200ms）
4. 主图指标和副图指标保持不变，基于新周期数据重新计算

## 五、主图叠加指标

主图叠加指标直接绘制在 K 线/分时线之上，与价格共享 Y 轴。
可同时叠加多个主图指标（如 MA + BOLL）。

### 5.1 MA — 简单移动平均线

#### 公式

```
MA(N) = (C₁ + C₂ + ... + Cₙ) / N
```

其中 `C` 为收盘价，`N` 为周期。

#### 默认参数与线条样式

| 参数 | 周期 | 颜色 | strokeWidth | opacity |
|------|------|------|-------------|---------|
| MA5 | 5 | `#ff9f0a` (橙) | 1px | 0.85 |
| MA10 | 10 | `#64d2ff` (青) | 1px | 0.85 |
| MA20 | 20 | `#bf5af2` (紫) | 1px | 0.85 |
| MA30 | 30 | `#ff453a` (红) | 1px | 0.85 |
| MA60 | 60 | `#30d158` (绿) | 1px | 0.85 |

#### 配置

- 默认启用：MA5、MA10、MA20
- 最多同时启用 6 条 MA
- 每条 MA 可单独开关
- 周期可自定义编辑（1~250）
- 图表左上角显示 MA 图例：`MA5: 8.52  MA10: 8.49  MA20: 8.47`
  - 图例文字颜色与对应线条颜色一致
  - hover 到某根 K 线时，图例数值更新为该根 bar 的 MA 值

#### 数据不足时

- 当可用 bar 数量 < N 时，该 MA 值不绘制（断开）
- 不使用 fallback 或补零

### 5.2 EMA — 指数移动平均线

#### 公式

```
EMA(N) = 价格今 × k + EMA昨 × (1 - k)
k = 2 / (N + 1)
```

首个 EMA 值 = 前 N 根 bar 的 SMA。

#### 默认参数

| 参数 | 周期 | 颜色 |
|------|------|------|
| EMA5 | 5 | `#ff9f0a` |
| EMA10 | 10 | `#64d2ff` |
| EMA20 | 20 | `#bf5af2` |
| EMA60 | 60 | `#30d158` |

#### 配置

- 线条样式与 MA 一致（strokeWidth 1px, opacity 0.85）
- 与 MA 互斥选择：选择 EMA 时自动关闭 MA，反之亦然
- 图例显示格式：`EMA5: 8.52  EMA10: 8.49`

### 5.3 BOLL — 布林带 (Bollinger Bands)

#### 公式

```
中轨 = MA(N)
标准差 σ = sqrt( Σ(Cᵢ - MA)² / N )
上轨 = 中轨 + K × σ
下轨 = 中轨 - K × σ
```

#### 默认参数

- N = 20（周期）
- K = 2（标准差倍数）
- 可配置范围：N ∈ [5, 120]，K ∈ [1, 4]，步进 0.5

#### 视觉规格

| 线条 | 颜色 | strokeWidth | dashArray |
|------|------|-------------|-----------|
| 上轨 (Upper) | `#ff9f0a` (橙) | 1px | — |
| 中轨 (Middle) | `#64d2ff` (青) | 1px | "4 4" |
| 下轨 (Lower) | `#bf5af2` (紫) | 1px | — |

- 上轨与下轨之间填充半透明色：`rgba(100, 210, 255, 0.06)`
- 当价格触及上轨或下轨时，对应区域填充色加深到 0.12

#### 图例

`BOLL(20,2): MID 8.52  UP 8.78  LOW 8.26`

### 5.4 SAR — 抛物线转向指标 (Parabolic SAR)

#### 公式

```
初始 AF = 0.02（加速因子），最大 AF = 0.20，AF 步长 = 0.02

多头阶段：
  SAR(t) = SAR(t-1) + AF × (EP - SAR(t-1))
  EP = 当前多头阶段的最高价

空头阶段：
  SAR(t) = SAR(t-1) + AF × (EP - SAR(t-1))
  EP = 当前空头阶段的最低价

转向条件：
  多头时，若 low(t) < SAR(t)，则转为空头
  空头时，若 high(t) > SAR(t)，则转为多头
  转向时 AF 重置为初始值
```

#### 默认参数

- AF 初始值 = 0.02
- AF 最大值 = 0.20
- AF 步长 = 0.02
- 可配置范围：初始 AF ∈ [0.01, 0.10]，最大 AF ∈ [0.10, 0.50]

#### 视觉规格

- SAR 点绘制为小圆点（dot），半径 2.5px
- 多头 SAR（价格上方）：`var(--color-down)` (#30d158，绿)
- 空头 SAR（价格下方）：`var(--color-up)` (#ff453a，红)
- 每个点独立绘制，不连线

#### 图例

`SAR(0.02, 0.20): 8.35 ↑` / `SAR(0.02, 0.20): 8.72 ↓`

### 5.5 VWAP — 成交量加权平均价

#### 公式

```
VWAP = Σ(典型价格ᵢ × 成交量ᵢ) / Σ(成交量ᵢ)
典型价格 = (high + low + close) / 3
```

每个交易日重置计算，从 09:30 开始累计。

#### 视觉规格

- 单条折线：`#ffd60a`（黄色），strokeWidth 1.5px
- dashArray："6 3"（长虚线，与均线区分）

#### 图例

`VWAP: 8.48`

### 5.6 ENV — 移动平均包络线 (Envelope)

#### 公式

```
中轨 = MA(N)
上轨 = MA(N) × (1 + P%)
下轨 = MA(N) × (1 - P%)
```

#### 默认参数

- N = 20
- P = 6%（偏离百分比）
- 可配置范围：N ∈ [5, 120]，P ∈ [1%, 20%]

#### 视觉规格

| 线条 | 颜色 | strokeWidth |
|------|------|-------------|
| 上轨 | `#ff9f0a` | 1px |
| 中轨 | `#64d2ff` | 1px，dashArray "4 4" |
| 下轨 | `#bf5af2` | 1px |

- 上下轨之间填充：`rgba(100, 210, 255, 0.04)`

### 5.7 BBI — 多空指标 (Bull and Bear Index)

#### 公式

```
BBI = (MA3 + MA6 + MA12 + MA24) / 4
```

#### 视觉规格

- 单条折线：`#ff9f0a`，strokeWidth 1.5px
- 与 K 线颜色对比：BBI 上穿收盘价线为多头信号，下穿为空头信号

#### 图例

`BBI: 8.51`

## 六、副图技术指标

副图指标在主图下方的独立区域绘制，拥有独立 Y 轴。
用户通过工具栏的「副图指标」下拉菜单选择添加/移除，最多同时显示 4 个副图。

### 6.1 VOL — 成交量

#### 描述

最基础的副图指标，默认始终显示在副图第一位。

#### 绘制

- 柱状图 (Bar Chart)
- 颜色规则：
  - 该 bar 的 close ≥ open：`var(--color-up)` (#ff453a)
  - 该 bar 的 close < open：`var(--color-down)` (#30d158)
- 柱宽：与主图蜡烛宽度一致
- 柱间距：与主图一致
- Y 轴：0 到最大 volume，无负值
- 叠加均量线：
  - VOL_MA5：5 周期成交量简单移动平均，`#ff9f0a`，strokeWidth 1px
  - VOL_MA10：10 周期成交量简单移动平均，`#64d2ff`，strokeWidth 1px

#### 图例

`VOL: 12345  MA5: 11234  MA10: 10456`

### 6.2 MACD — 指数平滑异同移动平均线

#### 公式

```
EMA(N, price) = price × (2/(N+1)) + EMA_prev × (1 - 2/(N+1))

DIF = EMA(SHORT, close) - EMA(LONG, close)
DEA = EMA(M, DIF)
BAR = (DIF - DEA) × 2
```

#### 默认参数

- SHORT = 12（短期 EMA 周期）
- LONG = 26（长期 EMA 周期）
- M = 9（信号线平滑周期）
- 可配置范围：SHORT ∈ [2, 60]，LONG ∈ [2, 120]，M ∈ [2, 60]
- 约束：SHORT < LONG

#### 视觉规格

| 元素 | 类型 | 颜色 | strokeWidth |
|------|------|------|-------------|
| DIF | 折线 | `#0a84ff` (蓝) | 1.5px |
| DEA | 折线 | `#ff9f0a` (橙) | 1.5px |
| BAR > 0 | 柱状 | `var(--color-up)` (#ff453a) | — |
| BAR < 0 | 柱状 | `var(--color-down)` (#30d158) | — |
| BAR 缩小（正→正变小 / 负→负变小） | 柱状 | 同上但 opacity 0.5 | — |
| 零轴 | 水平线 | `var(--color-separator)` | 0.5px |

BAR 柱颜色细化规则（同花顺标准）：
- BAR > 0 且 BAR ≥ 前值：实心红色（动能增强）
- BAR > 0 且 BAR < 前值：空心红色 / 浅红（动能减弱）
- BAR < 0 且 BAR ≤ 前值：实心绿色（动能增强）
- BAR < 0 且 BAR > 前值：空心绿色 / 浅绿（动能减弱）

#### 图例

`MACD(12,26,9): DIF 0.012  DEA 0.008  BAR 0.008`

#### 信号标注（可选开关）

- DIF 上穿 DEA（金叉）：在交叉点标注 ▲ 图标，`var(--color-up)`
- DIF 下穿 DEA（死叉）：在交叉点标注 ▼ 图标，`var(--color-down)`

### 6.3 KDJ — 随机指标 (Stochastic Oscillator)

#### 公式

```
RSV = (C - L_N) / (H_N - L_N) × 100

其中：
  C = 当前收盘价
  L_N = N 周期内最低价
  H_N = N 周期内最高价

K = (2/3) × K_prev + (1/3) × RSV     （初始 K = 50）
D = (2/3) × D_prev + (1/3) × K       （初始 D = 50）
J = 3K - 2D
```

#### 默认参数

- N = 9（RSV 周期）
- M1 = 3（K 平滑系数的分母）
- M2 = 3（D 平滑系数的分母）
- 可配置范围：N ∈ [2, 90]，M1 ∈ [2, 30]，M2 ∈ [2, 30]

#### 视觉规格

| 线条 | 颜色 | strokeWidth |
|------|------|-------------|
| K 线 | `#0a84ff` (蓝) | 1.5px |
| D 线 | `#ff9f0a` (橙) | 1.5px |
| J 线 | `#bf5af2` (紫) | 1px |

- Y 轴范围：0~100（J 线可能超出，但 Y 轴固定 0~100，J 线超出部分裁剪）
- 超买区参考线：80，水平虚线，`var(--color-text-quaternary)`，dashArray "4 4"
- 超卖区参考线：20，同上
- 超买区 (80~100) 填充：`rgba(255, 69, 58, 0.05)`
- 超卖区 (0~20) 填充：`rgba(48, 209, 88, 0.05)`

#### 图例

`KDJ(9,3,3): K 72.5  D 68.3  J 80.9`

### 6.4 RSI — 相对强弱指标 (Relative Strength Index)

#### 公式

```
U = max(close - prev_close, 0)       （上涨幅度）
D = max(prev_close - close, 0)       （下跌幅度）

SMA_U = N 周期 U 的指数移动平均
SMA_D = N 周期 D 的指数移动平均

RS = SMA_U / SMA_D
RSI = 100 - 100 / (1 + RS)
```

#### 默认参数

最多同时显示 3 条 RSI：

| 参数 | 周期 | 颜色 | strokeWidth |
|------|------|------|-------------|
| RSI6 | 6 | `#0a84ff` (蓝) | 1.5px |
| RSI12 | 12 | `#ff9f0a` (橙) | 1px |
| RSI24 | 24 | `#bf5af2` (紫) | 1px |

- 可配置范围：N ∈ [2, 100]

#### 视觉规格

- Y 轴范围：0~100
- 超买区参考线：80（或 70），dashArray "4 4"
- 超卖区参考线：20（或 30），dashArray "4 4"
- 中轴参考线：50，dashArray "2 2"，`var(--color-text-quaternary)`
- 超买区填充：`rgba(255, 69, 58, 0.05)`
- 超卖区填充：`rgba(48, 209, 88, 0.05)`

#### 图例

`RSI(6,12,24): RSI6 65.3  RSI12 58.7  RSI24 52.1`

### 6.5 WR — 威廉指标 (Williams %R)

#### 公式

```
WR = (H_N - C) / (H_N - L_N) × (-100)

其中：
  H_N = N 周期内最高价
  L_N = N 周期内最低价
  C = 当前收盘价
```

#### 默认参数

| 参数 | 周期 | 颜色 |
|------|------|------|
| WR10 | 10 | `#0a84ff` |
| WR6 | 6 | `#ff9f0a` |

- 可配置范围：N ∈ [2, 100]

#### 视觉规格

- Y 轴范围：-100 ~ 0（注意负值）
- Y 轴标签翻转显示：顶部 0，底部 -100
- 超买区参考线：-20，dashArray "4 4"
- 超卖区参考线：-80，dashArray "4 4"
- strokeWidth：1.5px

#### 图例

`WR(10,6): WR10 -35.2  WR6 -28.7`

### 6.6 DMI — 趋向指标 (Directional Movement Index)

#### 公式

```
+DM = max(high - prev_high, 0)，当 +DM > -DM 时保留，否则 = 0
-DM = max(prev_low - low, 0)，当 -DM > +DM 时保留，否则 = 0

TR = max(high - low, |high - prev_close|, |low - prev_close|)

+DI = EMA(N, +DM) / EMA(N, TR) × 100
-DI = EMA(N, -DM) / EMA(N, TR) × 100

DX = |+DI - (-DI)| / (+DI + (-DI)) × 100
ADX = EMA(M, DX)
ADXR = (ADX + ADX_M周期前) / 2
```

#### 默认参数

- N = 14（DI 周期）
- M = 6（ADX 平滑周期）
- 可配置范围：N ∈ [2, 60]，M ∈ [2, 60]

#### 视觉规格

| 线条 | 颜色 | strokeWidth | dashArray |
|------|------|-------------|-----------|
| +DI | `#ff453a` (红) | 1.5px | — |
| -DI | `#30d158` (绿) | 1.5px | — |
| ADX | `#0a84ff` (蓝) | 1.5px | — |
| ADXR | `#ff9f0a` (橙) | 1px | "4 4" |

- Y 轴范围：0~100
- 参考线：20（趋势强度分界），dashArray "4 4"

#### 图例

`DMI(14,6): +DI 28.3  -DI 18.7  ADX 35.2  ADXR 32.1`

### 6.7 CCI — 顺势指标 (Commodity Channel Index)

#### 公式

```
TP = (high + low + close) / 3       （典型价格）
MA_TP = MA(N, TP)                   （TP 的简单移动平均）
MD = MA(N, |TP - MA_TP|)            （平均偏差）
CCI = (TP - MA_TP) / (0.015 × MD)
```

#### 默认参数

- N = 14
- 可配置范围：N ∈ [2, 120]

#### 视觉规格

- 单条折线：`#0a84ff`，strokeWidth 1.5px
- Y 轴范围：动态（一般 -300 ~ +300，跟随数据）
- 超买参考线：+100，dashArray "4 4"
- 超卖参考线：-100，dashArray "4 4"
- 零轴：实线，`var(--color-separator)`，0.5px
- +100 以上区域填充：`rgba(255, 69, 58, 0.05)`
- -100 以下区域填充：`rgba(48, 209, 88, 0.05)`

#### 图例

`CCI(14): 85.3`

### 6.8 OBV — 能量潮指标 (On Balance Volume)

#### 公式

```
如果 close > prev_close: OBV = OBV_prev + volume
如果 close < prev_close: OBV = OBV_prev - volume
如果 close == prev_close: OBV = OBV_prev
```

#### 默认参数

无可配置参数。

#### 视觉规格

- 单条折线：`#0a84ff`，strokeWidth 1.5px
- Y 轴：OBV 绝对值（可能很大，用 K/M/B 缩写）
- 叠加 OBV 均线：MA_OBV(30)，`#ff9f0a`，strokeWidth 1px

#### 图例

`OBV: 1.23M  MA30: 1.15M`

### 6.9 TRIX — 三重指数平滑均线

### 6.12 VR — 成交量比率 (Volume Ratio)

### 6.13 CR — 能量指标

## 九、图表交互

### 9.1 十字线 (Crosshair)

鼠标在图表区域移动时，显示跟随鼠标的十字线：

- 水平线：全宽，从左 Y 轴到右 Y 轴
- 垂直线：全高，贯穿主图和所有副图（共享 X 轴）
- 线样式：`var(--color-chart-crosshair)` rgba(235,235,245,0.3)，0.5px，dashArray "4 4"
- 水平线右端标签：当前鼠标对应的价格值，
  背景 `var(--color-bg-elevated)`，圆角 `--radius-xs`，内边距 4px 8px
- 垂直线底端标签：当前鼠标对应的时间值，同样样式

### 9.2 Tooltip / 数据面板

鼠标 hover 时，在图表左上角（固定位置，不随鼠标移动）显示当前 bar 的完整数据：

```
┌──────────────────────────────┐
│  2025-04-01 14:35            │
│  开 8.50  高 8.55            │
│  低 8.48  收 8.52            │
│  量 12,345                   │
│  MA5 8.51  MA10 8.49         │
│  MA20 8.47                   │
│  涨跌: +0.02 (+0.24%)       │
└──────────────────────────────┘
```

- 背景：`var(--color-bg-secondary)` + 85% opacity
- 圆角：`--radius-sm`
- 内边距：`--space-3`
- 文字：`--text-caption-1`
- 数值颜色跟随涨跌色

各副图的 Tooltip 同样固定在各自区域的左上角：

```
MACD(12,26,9): DIF 0.012  DEA 0.008  BAR 0.008
```

### 9.3 缩放 (Zoom)

- **鼠标滚轮**：向上滚动放大（减少可见 bar 数量），向下滚动缩小（增加可见 bar 数量）
- 缩放中心：鼠标所在位置
- 可见 bar 范围：最少 20 根，最多 500 根
- 缩放时主图和所有副图同步
- Y 轴自动适应可见范围内的数据极值（留 10% 上下余量）

### 9.4 平移 (Pan)

- **鼠标拖拽**：按住左键拖拽可左右平移查看历史数据
- 拖拽时鼠标变为 `grab` → `grabbing` 光标
- 平移时如果已经到达最新数据的右边界，停止向右平移
- 向左最多可查看到当日 09:30 的数据

### 9.5 双击复位

- 双击图表区域：重置缩放和平移，回到最新数据的默认视图

### 9.6 全屏模式

- 点击全屏按钮后：
  - 图表区域扩展到页面全部可用空间（隐藏交易面板、底部 Tab、资产概览区）
  - 导航栏保持可见
  - 右上角出现「退出全屏」按钮
  - ESC 键退出全屏
- 全屏时图表分辨率更高，可看到更多 K 线数据

## 十一、前端图表组件架构

### 11.1 组件树

```
<StockChart>                         # 图表容器（管理布局、缩放、平移）
  <ChartToolbar />                   # 工具栏
  <ChartMain>                        # 主图区域
    <CandlestickRenderer />          # K线绘制器（6种类型通过 prop 切换）
    <TimeshareRenderer />            # 分时图绘制器
    <OverlayIndicators />            # 主图叠加指标层（MA/EMA/BOLL/SAR/...）
    <DrawingLayer />                 # 画线工具层
    <CrosshairLayer />               # 十字线层
    <LatestPriceLine />              # 最新价标线
    <LimitPriceLines />              # 涨跌停价线
  </ChartMain>
  <ChartSeparator />                 # 可拖拽分隔条
  <SubChart indicator="vol" />       # 副图
  <ChartSeparator />
  <SubChart indicator="macd" />
  <ChartSeparator />
  <SubChart indicator="kdj" />
  <SharedXAxis />                    # 共享 X 轴
  <ChartTooltip />                   # 固定位置 Tooltip
  <IndicatorSettingsPanel />         # 指标参数编辑浮层
</StockChart>
```

### 11.2 数据流

```
SSE 推送 / 周期切换请求
     ↓
  api.ts (fetch + 解析)
     ↓
  useChartData() hook
     ↓
  ┌──────────────────────────┐
  │  chartData 状态:          │
  │    bars: OHLCV[]          │
  │    indicators: {...}      │
  │    visibleRange: [a, b]   │
  │    zoom: number           │
  │    panOffset: number      │
  └──────────────────────────┘
     ↓
  各 Renderer 组件读取对应切片渲染
```

### 11.3 Recharts 实现要点

所有图表使用 Recharts `<ComposedChart>` 渲染。关键技术点：

1. **蜡烛图**：使用 `<Bar>` 组件 + 自定义 `shape` prop 绘制蜡烛
2. **影线**：在 shape 函数中返回 SVG `<g>` 包含 `<rect>` (实体) + `<line>` (影线)
3. **主图叠加指标**：在同一个 `<ComposedChart>` 中添加 `<Line>` 组件
4. **BOLL 填充**：使用 `<Area>` 组件的 `stackId` 实现上下轨间填充
5. **SAR 点**：使用 `<Scatter>` 组件绘制离散点
6. **副图**：每个副图是独立的 `<ComposedChart>`，通过 `syncId` 属性与主图共享 X 轴
7. **缩放/平移**：通过控制传入数据的 slice 范围实现，不使用 Recharts 内置缩放
8. **十字线**：使用 `<ReferenceLine>` 动态更新 + `onMouseMove` 事件

## 十四、验收标准

### 功能验收

1. 工具栏中可切换 6 种 K 线类型，每种画法视觉正确
2. 7 个周期可自由切换（分时/1分/5分/15分/30分/60分/日K），数据正确聚合
3. 可叠加至少 3 种主图指标（MA + BOLL + SAR），线条颜色/样式与本 PRD 规格一致
4. 可同时显示最多 4 个副图，副图之间可拖拽调整高度
5. 至少 MACD / KDJ / RSI / WR / DMI / CCI / OBV 7 个副图指标可选且渲染正确
6. 所有指标参数可通过 ⚙ 面板自定义修改，修改后图表实时更新
7. 十字线跟随鼠标移动，垂直线贯穿所有子图
8. Tooltip 固定在图表左上角，实时显示当前 hover 的 bar 数据和所有指标值
9. 鼠标滚轮可缩放 K 线密度（20~500 根可见范围）
10. 鼠标拖拽可平移查看历史数据
11. 分时图正确显示昨收基准线、均价线、双色面积渐变
12. 画线工具至少支持趋势线和水平线，可绘制、选中、拖拽、删除

### UI 验收

1. 所有图表区域背景使用 Apple 设计系统中的 `--color-bg-secondary`
2. 网格线使用 `var(--color-chart-grid)` 半透明色，不喧宾夺主
3. 指标线条颜色与本 PRD 规格表一致
4. Segmented Control（周期切换）使用 Apple 标准样式
5. 指标参数面板使用毛玻璃效果
6. 图表区域的 Tooltip 不遮挡蜡烛主体（固定在角落）
