# Radius — AInvest Design System

> 圆角规范文档，定义容器类、控件类、强调类三大组件的圆角使用规则，适用于 Web 端与 App 端。

---

## ⚠️ 重要使用注明（必须严格遵守）

**本规范中的全局圆角样式不得覆盖（override）组件内固有的圆角样式。**

具体说明：
- 按钮、标签、Tab 等控件类组件拥有自身固定的圆角规格，以各组件规范文档中的定义为准；
- 本文档定义的全局圆角变量仅适用于**尚未在组件规范中明确圆角值的元素**；
- 在任何实现中，若组件自身已定义圆角，必须优先使用组件内固有样式，全局圆角设置不得对其进行覆盖。

---

## 一、圆角尺寸规格

圆角规范 Web 端与 App 端使用场景一致，共定义五个等级：

| 等级 | 圆角值 | 适用场景 |
|------|--------|----------|
| **大号（Large）** | `24px` | Web 端弹窗、底部弹窗、全屏大卡片、特殊营销类场景的大圆角卡片 |
| **中号（Medium）** | `16px` | 模块卡片、下拉菜单、App 端弹窗；**默认内容卡片均使用此圆角** |
| **小号（Small）** | `6px` | 标签类（Tag）、方形按钮、输入框等高度较小的控件 |
| **极小号（XSmall）** | `4px` | 高密度、小尺寸组件，如小号 Tag、极小选择框、开关、交易场景操作按钮 |
| **全圆角（Full）** | `9999px` | 全圆角按钮、Tab、分段选择器、头像等 |

## 二、应用类型与使用规则

圆角主要应用于以下三类组件：

### 2.1 容器类

**用途**：建立信息层级

适用组件包括：卡片、弹窗、底部弹窗、菜单等。

| 组件 | 推荐圆角 |
|------|----------|
| 弹窗（Modal）、底部弹窗 | `24px`（大号） |
| 全屏大卡片、营销类大圆角卡片 | `24px`（大号） |
| 默认模块卡片、下拉菜单 | `16px`（中号） |
| App 端弹窗 | `16px`（中号） |

### 2.2 控件类

**用途**：表达交互属性

适用组件包括：按钮、输入框、Tab 等。

| 组件 | 推荐圆角 |
|------|----------|
| 全圆角按钮、Tab、分段选择器 | `9999px`（全圆角） |
| 方形按钮、输入框 | `6px`（小号） |
| 交易场景极小操作按钮、极小选择框、开关 | `4px`（极小号） |

> ⚠️ **控件类组件优先使用自身固有的圆角样式**，本规范中的全局圆角样式不得 override 组件内固定样式。详见文档顶部「重要使用注明」。

### 2.3 强调类

**用途**：提升信息识别效率

适用组件包括：Tag、部分文字按钮 / 无边卡片的 Hover 态背景色块。

| 组件 | 推荐圆角 |
|------|----------|
| 标准 Tag | `6px`（小号） |
| 小号 Tag | `4px`（极小号） |
| Hover 态圆角底色 | 根据对应组件尺寸选择 `4px` 或 `6px` |

> ⚠️ **Hover 态使用注明**：强调类组件在 Hover 状态下需要添加圆角底色时，必须在设计稿中**提前注明该场景在 Hover 状态下需要添加圆角底色**，不可隐式处理。

## 三、卡片嵌套的圆角处理

当页面出现**卡片嵌套**结构时，遵循以下原则：

1. **等比缩放原则**：内层卡片的圆角相对外层卡片等比缩小
2. **取整原则**：缩放后的圆角值进行取整，确保视觉协调
3. 嵌套层级建议不超过两层，避免圆角过小失去视觉意义

**示例参考**：

| 外层卡片圆角 | 内层卡片圆角（等比缩放后取整） |
|------------|-------------------------------|
| `24px` | `16px` |
| `16px` | `6px` 或 `8px` |
| `6px` | `4px` |

## 四、快速选择指引

```
需要确定圆角值？
│
├─ 是控件类组件（按钮 / Tab / 输入框等）？
│   └─ 优先查阅该组件自身规范文档，使用组件内固有圆角，本规范不适用
│
├─ 是容器类组件？
│   ├─ 弹窗 / 底部弹窗 / 全屏大卡片 / 营销卡片 → 24px
│   ├─ 默认模块卡片 / 下拉菜单 / App 弹窗 → 16px
│   └─ 存在卡片嵌套 → 等比缩放后取整
│
└─ 是强调类组件？
    ├─ 标准 Tag → 6px
    ├─ 小号 Tag / 极小操作按钮 / 交易场景 → 4px
    └─ Hover 态底色 → 对应组件尺寸取 4px 或 6px，并在设计稿中提前注明
```

## 五、禁止事项（Forbidden）

| ❌ 禁止 | ✅ 正确做法 |
|---------|-----------|
| 用全局圆角变量覆盖按钮、Tab、输入框等组件的固有圆角 | 优先使用组件规范中定义的圆角值 |
| 在 Hover 态添加圆角底色但未在设计稿中注明 | 提前注明 Hover 场景需要添加圆角底色 |
| 卡片嵌套时内外层使用相同圆角值 | 遵循等比缩放原则并取整 |
| 使用规范外的自定义圆角值（如 `12px`、`20px`） | 严格使用 `4px` / `6px` / `16px` / `24px` / `9999px` |
