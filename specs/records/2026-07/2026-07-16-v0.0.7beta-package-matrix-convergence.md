## Evidence and causal chain

1. The previous local head is an ancestor of `myhexin/v0.0.7beta`; the target is 147 commits ahead and zero commits behind. Integration is therefore a branch fast-forward/switch, not a conflict merge.
2. The default npm registry timed out while the configured mirror responded normally. A frozen install through the reachable mirror restored dependencies without changing the lockfile.
3. Rustup's component metadata omitted Clippy while the binaries and component files existed, causing Tauri's `cargo metadata` bootstrap to fail on a duplicate `cargo-clippy`. A clean stable-toolchain reinstall restored consistent Rust, Cargo, and Clippy ownership.
4. Bun canonicalizes macOS temporary paths from `/var/...` to `/private/var/...` before `onLoad`. The plugin compared that canonical callback path with the non-canonical input path, rejected the intended module, and left the tracked empty generated table in the bundle.
5. The compiled overlay-server and generated-payload regressions called `Bun.build` inside `bun test`; the first also relied on `process.chdir` and an absolute `tsconfig` path. These in-process builds retained the test runner's resolver context, then failed to resolve package aliases or workspace dependencies that standalone production builds resolve. Production runs the compiler from a standalone repository/package-root process, so both regressions must exercise that same resolver boundary.
6. The native macOS application and HFS+ image build completed, but Tauri's generated `create-dmg` script then asked Finder to position icons. In the unattended environment Finder timed out the AppleEvent with `-1712`. Tauri's supported automation mode explicitly skips this interactive Finder-only cosmetic step while retaining real DMG creation. The matrix supplied that mode, but `packages/overlay/script/build.ts` replaced the entire child environment with three variables before launching Tauri, dropping `CI`; preserving the caller environment is therefore part of the root fix.
7. The checked-in packaging docs still describe release jobs that the current canonical workflow explicitly removed, creating a second, stale release model.
8. Overlay type checking exposed the same invalid declaration shape already repaired for four Kobalte bundles in `patches/@kobalte%2Fcore@0.13.11.patch`, but the Slider bundle was absent from that single dependency patch. Kobalte 0.13.12 retains the invalid Slider declarations, so upgrading would not remove the error; extending the existing patch is the root toolchain repair.

## Implementation plan

1. Canonicalize both sides of the embedded UI module identity comparison, and strengthen its regression contract.
2. Run the compiled artifact and generated-payload regressions in repository/package-root Bun subprocesses with the production build boundary.
3. Make the GUI matrix invoke Tauri in its deterministic automation mode and cover the exact environment contract.
4. Reconcile deterministic generated payload drift caused by the real SDK/package build and prove the checked-in modules match both generators.
5. Update the packaging/release docs and both spec indexes.
6. Run focused tests, repository guards, both real native package matrices, artifact inspections, and a final diff review.
