## Causal chain

1. **Observable:** the current light rail is a uniform neutral gray, while the reference uses a quiet vertical pastel atmosphere.
2. **Direct trigger:** `--rail-surface` is fixed to `rgb(247, 247, 247)` and both visible shell owners paint that flat color.
3. **Deep cause:** one token currently serves two different CSS value domains: solid color calculations/backing and visible background paint. Replacing it with a gradient would invalidate `color-mix()` consumers and body `background-color` expectations.
4. **Root implementation:** retain `--rail-surface` as the opaque solid foundation and add one symmetric semantic `--rail-background-image` paint token. Light maps it to the reference gradient; dark themes map it to `none`. The titlebar and left shell use the image token over the shared solid foundation with fixed positioning and the canonical Overlay shell dimensions so the gradient does not restart at their DOM boundary.
