# 交付说明（AI 编程工具采购决策网站 · Phase 02）

> 交付日期：2026-08-02 · 交付范围：`specs/artifacts/ai-coding-tool-decision-site/`（仅新增，OpenCorvus 产品源码零改动）

## 一、站点功能

1. **参数面板（S1）**：团队人数 N（10/30/100 预设 + 自由正整数输入）、使用强度 LIGHT/STANDARD/HEAVY、成本/安全/任务效果三权重（各 0-100%）、JetBrains credits / Amazon Q LOC / Tabnine provider 三个官方可换算超额单位的消耗量输入。调整后**即时重算**，权重归一化公式与当前归一化结果实时显示。
2. **工具对比矩阵（S2）**：9 个工具 × 7 维（价格档位/额度/IDE 支持/CLI/Agent 能力/企业管理/安全/数据使用）+ 实测列（claude/codex quality+duration，其余 NOT_TESTED）+ 成本列（当前 N 席位/年）。
3. **年度成本模型（S3）**：席位成本/超额成本/年度总成本三列表格 + ECharts 对比图；每格展示计算式与官方单价原文；ASSUMED 徽标、NO_CONVERSION「不可换算（官方无公开换算依据）」原位展示。
4. **综合评分排序（S4）**：成本/安全/任务效果得分与综合评分表 + ECharts 对比图；降序排序 + TOP 名次高亮 + R1-R6 推荐徽标；NOT_TESTED 工具显示「评分不含任务效果维度」徽标；安全 7 维 checklist 指示值来源可见。
5. **推荐方案/风险/试点计划（S5）**：R1-R6 原文逐条渲染 + limitations L1-L7 风险表 + 10 人 4 周试点计划摘要。
6. **数据来源与新鲜度（S6）**：来源文件 sha256、12 个官方 source_urls、访问日期 2026-08-01 / 复核 2026-08-02、STALE 动态判定、标记位语义表。

## 二、参数与重算逻辑

- 席位成本 = 官方单价 × 12 × N（Windsurf = 480×N+960）；页面同时展示 `unit_price_original` 原文便于人工核对。
- 超额成本仅按官方可换算单位计算（Cursor $0.25/MTok 按强度档 ASSUMED token 区间、JetBrains 1 credit=$1、Amazon Q $0.003/LOC、Tabnine provider+5%）；NO_CONVERSION 项不产生数值。
- 综合评分 = W_cost×成本得分 + W_security×安全得分 + W_task×任务效果得分；成本得分 8 工具 min-max 归一化；安全得分 7 维 checklist 加权（1/0.5/0 指示值）；任务效果 = mean_quality/5×100；NOT_TESTED 工具去掉任务效果维度并对剩余权重在各自和上重归一化。
- N 非正整数时显示校验提示，成本列不展示数值。
