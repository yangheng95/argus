---
title: Keybinds
description: Customize TUI keybinds for OpenCorvus.
---

OpenCorvus's TUI keybinds live in your TUI config and merge with the built-in defaults.

## Configuration file

Place a `keybinds.jsonc` (or the `keybinds` block inside `tui.json`) under one of:

| Location                                           | Use                                  |
| -------------------------------------------------- | ------------------------------------ |
| `~/.config/opencorvus/keybinds.jsonc`              | Global, applies everywhere           |
| `~/.config/opencorvus/tui.json` (`keybinds` block) | Global, alongside other TUI settings |
| Project-level `tui.json`                           | Per-repo overrides                   |

## Schema

```json
{
  "keybinds": {
    "submit": "ctrl+enter",
    "cancel": "ctrl+c",
    "history.up": "ctrl+up",
    "history.down": "ctrl+down"
  }
}
```

The keys are the action IDs from the OpenCorvus TUI; values are key chord strings. Open the in-TUI help (typically `?`) to see the live binding map for your build.

## Resolution

User keybinds are merged on top of the built-in defaults — partial configs are fine. Removing a default requires setting it to `null` (where supported).

## Tips

- Pair with [Themes](/docs/themes/) for a fully personalized TUI.
- The Overlay desktop app has its own keybind layer (Tauri shortcuts) that doesn't read this config.
