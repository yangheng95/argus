## Technical Design Decisions

### Backend Architecture

**File Structure (as specified in PRD):**
```
index.ts                 # Hono entry point, mounts API + SSE + static files
src/
  db.ts                  # SQLite DDL + initialization + seed data
  auth.ts                # Authentication middleware + /api/auth/* routes
  market.ts              # Market routes + SSE endpoint
  trading.ts             # Trading routes (buy/sell/cancel/orders)
  portfolio.ts           # Portfolio and summary routes
  history.ts             # Trade history and daily snapshots
  simulator.ts           # Price simulation engine + order matching
```

**Key Implementation Details:**

1. **Database Connection**: Use `bun:sqlite` with `new Database('data/trading.db')`. Create `data/` directory if not exists.

2. **Authentication Flow**:
   - Token generation: `crypto.randomUUID()` or `Bun.randomUUID()`
   - Password hashing: `await Bun.password.hash(password, 'argon2id')`
   - Middleware extracts Bearer token from `Authorization` header, validates against `sessions` table

3. **SSE Implementation**:
   - Use Hono's `streamSSE()` helper
   - Maintain Set of connected clients
   - Broadcast stock snapshot every 2 seconds via simulator interval
   - Handle client disconnect cleanup

4. **Market Simulator**:
   - `setInterval(2000)` in `simulator.ts`
   - Price calculation: `newPrice = oldPrice * (1 + randomNormal(0, 0.005) + trend)`
   - Enforce ±10% limit from open_price
   - After price update, scan pending orders and execute matches
   - Insert price_history record after each update

5. **Order Matching Logic**:
   - Buy orders: execute if `currentPrice <= order.price`
   - Sell orders: execute if `currentPrice >= order.price`
   - Update user balance, positions, order status in transaction
   - Record filled order timestamp

**Key Implementation Details:**

1. **Tailwind v4 Configuration**: Use CSS-based config in `index.css`:
   ```css
   @import "tailwindcss";
   @theme {
     --color-bg-primary: #0f172a;
     --color-bg-secondary: #1e293b;
     --color-text-primary: #f8fafc;
     --color-up: #ef4444;    /* Red for up (China market) */
     --color-down: #22c55e;  /* Green for down */
   }
   ```

2. **SSE Client in api.ts**:
   ```typescript
   export function subscribeMarket(callback: (data: Stock[]) => void) {
     const es = new EventSource('/api/market/sse');
     es.onmessage = (e) => callback(JSON.parse(e.data));
     return () => es.close();
   }
   ```

3. **Auth Context**: Store token in memory (not localStorage for security), provide login/logout methods

4. **Number Formatting**:
   - Price: `toFixed(2)`
   - Amount: `toLocaleString('zh-CN')`
   - Percent: `toFixed(1) + '%'`

5. **Route Structure**:
   - `/login`, `/register` - Public
   - `/` - Market (protected)
   - `/stock/:code` - Detail (protected)
   - `/portfolio` - Portfolio (protected)
   - `/history` - History (protected)

## Constraints

1. **Bun-only**: All commands use `bun`, no npm/yarn/pnpm
2. **TypeScript strict mode**: All files must pass `tsc --noEmit`
3. **Single entry point**: `index.ts` serves both API and static files
4. **Dark theme only**: No light mode toggle needed
5. **China market conventions**: Red = up/gain, Green = down/loss
6. **Lot size**: All quantities must be multiples of 100
7. **No external auth**: Simple session-based, no OAuth/JWT libraries needed

## API Endpoint Specifications

Reference PRD section "后端 API" for complete list. Key implementation notes:

| Endpoint | Method | Auth | Request Body | Response |
|----------|--------|------|--------------|----------|
| /api/auth/register | POST | No | `{username, password}` | `{id, username, balance}` |
| /api/auth/login | POST | No | `{username, password}` | `{token, user}` |
| /api/market/stocks | GET | Yes | - | `Stock[]` |
| /api/market/stocks/:code | GET | Yes | - | `Stock & {history: PricePoint[]}` |
| /api/market/sse | GET | Yes | - | SSE stream |
| /api/trading/buy | POST | Yes | `{stockCode, quantity, price}` | `Order` |
| /api/trading/sell | POST | Yes | `{stockCode, quantity, price}` | `Order` |
| /api/trading/cancel/:id | POST | Yes | - | `Order` |
| /api/trading/orders | GET | Yes | - | `Order[]` |
| /api/portfolio | GET | Yes | - | `Position[]` |
| /api/portfolio/summary | GET | Yes | - | `{totalAssets, availableBalance, marketValue, totalPnl, pnlPercent}` |
| /api/history/trades | GET | Yes | `?stock=&limit=&offset=` | `Trade[]` |
| /api/history/daily | GET | Yes | - | `DailySnapshot[]` |
