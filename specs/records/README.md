# Spec Records

This directory stores dated implementation records, investigations, benchmark notes, and audit results.

## Layout

| Directory | Contents |
| --- | --- |
| `2026-06/` | June 2026 records retained after the 2026-06-29 spec consolidation. |

## Rules

1. Records are grouped by month as `specs/records/YYYY-MM/`.
2. Each record filename must include the same `YYYY-MM` month as its containing directory.
3. Records are historical evidence unless a file explicitly declares itself as the current source of truth.
4. Files dated before 2026-06-01 are not retained.
