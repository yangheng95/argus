## Causal chain

1. **Observable:** every memory row permanently shows a high-salience red Delete word while its scope badge floats near the same right edge.
2. **Direct trigger:** the row is a two-column flex layout whose main disclosure consumes the available width; inside it, `.knowledge-item-meta` has `flex: 1`, forcing the scope marker to the far end. A separate small text danger Button then adds another right-edge column.
3. **Deep cause:** scope metadata and destructive row chrome are authored as Memory-specific span/text-button treatments instead of composing the existing Badge and icon-action primitives. The information hierarchy therefore treats metadata and a rare destructive action as peers of the title.
4. **Why a color-only patch is insufficient:** muting the red text would retain the detached geometry, oversized action footprint and private badge chrome. The root repair must correct the row composition and move both controls to the existing semantic primitives.
