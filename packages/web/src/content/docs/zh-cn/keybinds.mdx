---
title: 快捷键
description: 自定义 OpenCorvus 的 TUI 快捷键。
---

OpenCorvus 的 TUI 快捷键写在 TUI config 里，与内置默认值合并。

## 配置文件

可放在以下任一位置：

| 位置                                             | 用途                      |
| ------------------------------------------------ | ------------------------- |
| `~/.config/opencorvus/keybinds.jsonc`            | 全局生效                  |
| `~/.config/opencorvus/tui.json`（`keybinds` 块） | 全局，与其他 TUI 设置同处 |
| 项目级 `tui.json`                                | 单仓库覆盖                |

## Schema

```json
{
  "keybinds": {
    "submit": "ctrl+enter",
    "cancel": "ctrl+c",
    "history.up": "ctrl+up",
    "history.down": "ctrl+down"
  }
}
```

key 名对应 OpenCorvus TUI 的 action ID；值为按键 chord 字符串。TUI 内打开帮助（通常是 `?`）可查看当前 build 的实时绑定。

## 合并

用户配置叠加在内置默认上——部分配置即可。要移除默认值需将其设为 `null`（如支持）。

## 提示

- 配合 [主题](/docs/zh-cn/themes/) 完全个性化 TUI。
- Overlay 桌面端有自己的 Tauri 快捷键层，不读取此 config。
