1. 详细功能说明 (Functional Requirements)1.1 核心模块：智能笔记创建 (Feature: AI-QuickNote)功能编号： F-01功能描述： 用户输入一段非结构化文本，点击“智能保存”，系统自动提取标题并保存。详细需求：输入限制： 支持文本输入（Max: 2000 字符）。触发机制： 点击“AI 生成”按钮或快捷键 Ctrl + Enter。处理逻辑：调用 LLM 接口提取前 15 个字作为标题。自动识别内容中的日期、地点等关键词并加粗。保存逻辑： 默认保存至“未分类”文件夹。1.2 核心模块：瀑布流列表 (Feature: Masonry List)功能编号： F-02排序逻辑： 按 updated_at 降序排列。交互细节：左滑： 调出“删除”与“归档”快捷按钮。点击： 进入详情页编辑。2. 接口与数据定义 (Technical Specs)2.1 数据对象定义 (Data Schema)字段名类型说明备注note_idString (UUID)唯一标识符主键contentText笔记正文必须summaryString (100)AI 生成的摘要可为空tagsArray标签数组如 ["工作", "灵感"]statusEnum状态0:草稿, 1:发布, 2:回收站2.2 核心 API 定义POST /api/v1/notesRequest: { "content": "..." }Response: { "code": 200, "data": { "note_id": "...", "summary": "..." } }3. 异常处理逻辑 (Edge Cases)场景系统响应用户感知网络断开开启本地缓存（LocalStorage/IndexedDB）。顶部显示“离线模式，内容将在联网后同步”。输入超限截断第 2000 字之后的内容。输入框下方出现红色警告提示。AI 接口超时设置 10s 超时时间。自动回退到“普通保存”模式，不显示摘要。4. UI/UX 交互细节 (Interaction Design)4.1 加载状态 (Loading States)AI 生成中： 按钮变为 Loading 状态，并伴有流光效果（Skeleton Screen）。空状态： 当列表为空时，显示插画及“开始记录你的第一个想法”引导文案。4.2 反馈机制 (Feedback)删除操作： 需弹出二次确认框（Toast 或 Modal），并提供 5 秒内的“撤销”选项。5. 验收标准 (Acceptance Criteria)[ ] 用户在弱网环境下（3G）完成一次记录，耗时不得超过 5 秒。[ ] AI 提取的标题准确率（人工抽检）需达到 85% 以上。[ ] 连续快速点击“保存”按钮，系统应有防抖处理，不产生重复记录。
