# AimeCode M1-2 · 数据持久化

> **自包含文档**：一个 AI 模型只读这一个文件，就能将 M1-1 的内存存储替换为 SQLite + Drizzle ORM 持久化层。
> **前置条件**：M1-1（API 服务框架）已完成——Hono 路由、中间件栈就绪，内存 MemoryStore 可调用。
> **包含**：Drizzle ORM 配置、SQLite 数据库 schema（会话表/消息表/用量表）、迁移脚本、Repository 层、连接池管理。
> **不包含**：PostgreSQL 支持（M4-5 私有化部署时引入）、用户表（M4-1）、审计表（M4-3）。

---

## 1. 目标与验收标准

### 1.1 里程碑目标

将服务器的会话和消息数据从内存 Map 迁移到 SQLite 文件数据库，使数据在服务器重启后不丢失。使用 Drizzle ORM 提供类型安全的查询。

### 1.2 验收标准

| # | 验收项 | 操作 | 预期结果 |
|---|---|---|---|
| V1 | 数据库创建 | 启动服务器 | 自动创建 `data/aimecode.db`，无报错 |
| V2 | 会话持久化 | 创建会话 → 重启服务器 → 获取会话列表 | 重启后会话仍存在 |
| V3 | 消息持久化 | 发送消息 → 重启服务器 → 获取消息列表 | 消息（含 contentBlocks/toolCalls）完整恢复 |
| V4 | 迁移脚本 | 执行 `bun run db:migrate` | 表结构创建成功，输出 migration applied |
| V5 | Schema 类型安全 | 在 repository 中写错误字段名 | TypeScript 编译报错 |
| V6 | 并发安全 | 同时发送 10 条消息到同一会话 | 全部成功保存，顺序正确 |
| V7 | WAL 模式 | `sqlite3 data/aimecode.db "PRAGMA journal_mode"` | 输出 `wal` |
| V8 | 数据大小 | 1000 条消息后检查 db 文件 | 文件 < 10MB |
| V9 | TypeScript 零错误 | `bun run tsc --noEmit --project server/tsconfig.json` | 0 errors |

## 4. Drizzle Schema

文件路径：`server/db/schema.ts`

```typescript
import { sqliteTable, text, integer, real } from 'drizzle-orm/sqlite-core'

// ── 会话表 ───────────────────────────────────────────────────
export const sessions = sqliteTable('sessions', {
  id:        text('id').primaryKey(),                    // UUID
  title:     text('title').notNull().default('新对话'),
  createdAt: text('created_at').notNull(),               // ISO 8601
  updatedAt: text('updated_at').notNull(),               // ISO 8601
})

// ── 消息表 ───────────────────────────────────────────────────
export const messages = sqliteTable('messages', {
  id:            text('id').primaryKey(),                 // UUID
  sessionId:     text('session_id').notNull().references(() => sessions.id, { onDelete: 'cascade' }),
  role:          text('role', { enum: ['user', 'assistant'] }).notNull(),
  content:       text('content').notNull().default(''),
  contentBlocks: text('content_blocks'),                  // JSON string (ContentBlock[])
  toolCalls:     text('tool_calls'),                      // JSON string (ToolCallRecord[])
  thinkingText:  text('thinking_text'),
  createdAt:     text('created_at').notNull(),
  // 排序用：同一会话内消息按 seq 排序
  seq:           integer('seq').notNull().default(0),
})

// ── Token 用量表 ─────────────────────────────────────────────
// 每次 LLM 调用记录一条，用于统计和预算控制
export const tokenUsage = sqliteTable('token_usage', {
  id:           text('id').primaryKey(),
  sessionId:    text('session_id').notNull().references(() => sessions.id, { onDelete: 'cascade' }),
  messageId:    text('message_id').notNull(),
  inputTokens:  integer('input_tokens').notNull(),
  outputTokens: integer('output_tokens').notNull(),
  model:        text('model').notNull().default('claude-sonnet-4-6'),
  durationMs:   integer('duration_ms'),
  createdAt:    text('created_at').notNull(),
})

// ── 导出所有表（用于 Drizzle 客户端初始化）────────────────────
export type Session = typeof sessions.$inferSelect
export type NewSession = typeof sessions.$inferInsert
export type MessageRow = typeof messages.$inferSelect
export type NewMessage = typeof messages.$inferInsert
export type TokenUsageRow = typeof tokenUsage.$inferSelect
export type NewTokenUsage = typeof tokenUsage.$inferInsert
```

## 5. 数据库连接

文件路径：`server/db/index.ts`

```typescript
import { drizzle } from 'drizzle-orm/bun-sqlite'
import { Database } from 'bun:sqlite'
import * as schema from './schema'
import { existsSync, mkdirSync } from 'fs'

const DB_DIR = 'data'
const DB_PATH = `${DB_DIR}/aimecode.db`

// 确保 data 目录存在
if (!existsSync(DB_DIR)) {
  mkdirSync(DB_DIR, { recursive: true })
}

// 创建 SQLite 连接
const sqlite = new Database(DB_PATH)

// ── SQLite 优化配置 ──────────────────────────────────────────
// WAL 模式：支持并发读写，性能显著提升
sqlite.exec('PRAGMA journal_mode = WAL')
// 同步模式：NORMAL 在 WAL 下安全且更快
sqlite.exec('PRAGMA synchronous = NORMAL')
// 外键约束：默认关闭，必须手动开启
sqlite.exec('PRAGMA foreign_keys = ON')
// 缓存大小：负值表示 KB，64MB
sqlite.exec('PRAGMA cache_size = -65536')
// busy timeout：避免 SQLITE_BUSY
sqlite.exec('PRAGMA busy_timeout = 5000')

// ── Drizzle 实例 ────────────────────────────────────────────
export const db = drizzle(sqlite, { schema })

// ── 初始化表结构（开发模式 push，生产用 migrate）──────────────
export function initDatabase() {
  // 创建表（如果不存在）
  sqlite.exec(`
    CREATE TABLE IF NOT EXISTS sessions (
      id         TEXT PRIMARY KEY,
      title      TEXT NOT NULL DEFAULT '新对话',
      created_at TEXT NOT NULL,
      updated_at TEXT NOT NULL
    );

    CREATE TABLE IF NOT EXISTS messages (
      id              TEXT PRIMARY KEY,
      session_id      TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
      role            TEXT NOT NULL CHECK(role IN ('user', 'assistant')),
      content         TEXT NOT NULL DEFAULT '',
      content_blocks  TEXT,
      tool_calls      TEXT,
      thinking_text   TEXT,
      created_at      TEXT NOT NULL,
      seq             INTEGER NOT NULL DEFAULT 0
    );

    CREATE INDEX IF NOT EXISTS idx_messages_session_id ON messages(session_id);
    CREATE INDEX IF NOT EXISTS idx_messages_session_seq ON messages(session_id, seq);

    CREATE TABLE IF NOT EXISTS token_usage (
      id            TEXT PRIMARY KEY,
      session_id    TEXT NOT NULL REFERENCES sessions(id) ON DELETE CASCADE,
      message_id    TEXT NOT NULL,
      input_tokens  INTEGER NOT NULL,
      output_tokens INTEGER NOT NULL,
      model         TEXT NOT NULL DEFAULT 'claude-sonnet-4-6',
      duration_ms   INTEGER,
      created_at    TEXT NOT NULL
    );

    CREATE INDEX IF NOT EXISTS idx_token_usage_session ON token_usage(session_id);
    CREATE INDEX IF NOT EXISTS idx_token_usage_date ON token_usage(created_at);
  `)

  console.log(`[DB] SQLite initialized: ${DB_PATH} (WAL mode)`)
}

// ── 关闭连接 ────────────────────────────────────────────────
export function closeDatabase() {
  sqlite.close()
  console.log('[DB] Database connection closed')
}
```

## 6. Repository 层

### 6.1 Session Repository

文件路径：`server/repository/session.repo.ts`

```typescript
import { eq, desc } from 'drizzle-orm'
import { db } from '../db'
import { sessions } from '../db/schema'
import type { Session } from '../db/schema'

export const sessionRepo = {
  create(): Session {
    const id = crypto.randomUUID()
    const now = new Date().toISOString()
    const row = {
      id,
      title: '新对话',
      createdAt: now,
      updatedAt: now,
    }
    db.insert(sessions).values(row).run()
    return row
  },

  findById(id: string): Session | undefined {
    return db.select().from(sessions).where(eq(sessions.id, id)).get()
  },

  findAll(): Session[] {
    return db.select().from(sessions).orderBy(desc(sessions.updatedAt)).all()
  },

  updateTitle(id: string, title: string): Session | undefined {
    const now = new Date().toISOString()
    db.update(sessions)
      .set({ title, updatedAt: now })
      .where(eq(sessions.id, id))
      .run()
    return this.findById(id)
  },

  delete(id: string): boolean {
    const result = db.delete(sessions).where(eq(sessions.id, id)).run()
    return result.changes > 0
  },

  /**
   * 获取会话列表（含消息数统计）。
   * 使用子查询避免 N+1。
   */
  findAllWithMessageCount(): Array<Session & { messageCount: number }> {
    const rows = db.all<Session & { messageCount: number }>(`
      SELECT s.*, COUNT(m.id) as messageCount
      FROM sessions s
      LEFT JOIN messages m ON m.session_id = s.id
      GROUP BY s.id
      ORDER BY s.updated_at DESC
    ` as any) as any

    // Drizzle raw query fallback
    const stmt = db.$client.prepare(`
      SELECT s.*, COUNT(m.id) as message_count
      FROM sessions s
      LEFT JOIN messages m ON m.session_id = s.id
      GROUP BY s.id
      ORDER BY s.updated_at DESC
    `)
    return stmt.all().map((row: any) => ({
      id: row.id,
      title: row.title,
      createdAt: row.created_at,
      updatedAt: row.updated_at,
      messageCount: row.message_count,
    }))
  },
}
```

### 6.2 Message Repository

文件路径：`server/repository/message.repo.ts`

```typescript
import { eq, and, max } from 'drizzle-orm'
import { db } from '../db'
import { messages, sessions } from '../db/schema'
import type { MessageRow, NewMessage } from '../db/schema'
import type { ContentBlock, ToolCallRecord } from '@shared/types'

export interface CreateMessageInput {
  sessionId: string
  role: 'user' | 'assistant'
  content: string
  contentBlocks?: ContentBlock[]
  toolCalls?: ToolCallRecord[]
  thinkingText?: string
}

export const messageRepo = {
  create(input: CreateMessageInput): MessageRow {
    const id = crypto.randomUUID()
    const now = new Date().toISOString()

    // 获取当前会话的最大 seq
    const maxSeqResult = db.$client
      .prepare('SELECT MAX(seq) as max_seq FROM messages WHERE session_id = ?')
      .get(input.sessionId) as { max_seq: number | null } | undefined
    const nextSeq = (maxSeqResult?.max_seq ?? -1) + 1

    const row: NewMessage = {
      id,
      sessionId: input.sessionId,
      role: input.role,
      content: input.content,
      contentBlocks: input.contentBlocks ? JSON.stringify(input.contentBlocks) : null,
      toolCalls: input.toolCalls ? JSON.stringify(input.toolCalls) : null,
      thinkingText: input.thinkingText || null,
      createdAt: now,
      seq: nextSeq,
    }

    db.insert(messages).values(row).run()

    // 更新会话的 updatedAt
    db.update(sessions)
      .set({ updatedAt: now })
      .where(eq(sessions.id, input.sessionId))
      .run()

    // 自动标题：首条用户消息
    if (input.role === 'user' && nextSeq === 0) {
      const title = input.content.slice(0, 20) + (input.content.length > 20 ? '...' : '')
      db.update(sessions)
        .set({ title, updatedAt: now })
        .where(eq(sessions.id, input.sessionId))
        .run()
    }

    return {
      ...row,
      contentBlocks: row.contentBlocks,
      toolCalls: row.toolCalls,
      thinkingText: row.thinkingText,
    } as MessageRow
  },

  findBySessionId(sessionId: string): Array<MessageRow & { contentBlocksParsed?: ContentBlock[]; toolCallsParsed?: ToolCallRecord[] }> {
    const rows = db.select()
      .from(messages)
      .where(eq(messages.sessionId, sessionId))
      .orderBy(messages.seq)
      .all()

    return rows.map(row => ({
      ...row,
      contentBlocksParsed: row.contentBlocks ? JSON.parse(row.contentBlocks) : undefined,
      toolCallsParsed: row.toolCalls ? JSON.parse(row.toolCalls) : undefined,
    }))
  },

  deleteBySessionId(sessionId: string): number {
    const result = db.delete(messages).where(eq(messages.sessionId, sessionId)).run()
    return result.changes
  },
}
```

### 6.3 Usage Repository

文件路径：`server/repository/usage.repo.ts`

```typescript
import { eq, gte, and, sql } from 'drizzle-orm'
import { db } from '../db'
import { tokenUsage } from '../db/schema'
import type { NewTokenUsage } from '../db/schema'

export const usageRepo = {
  record(input: {
    sessionId: string
    messageId: string
    inputTokens: number
    outputTokens: number
    model?: string
    durationMs?: number
  }): void {
    const row: NewTokenUsage = {
      id: crypto.randomUUID(),
      sessionId: input.sessionId,
      messageId: input.messageId,
      inputTokens: input.inputTokens,
      outputTokens: input.outputTokens,
      model: input.model || 'claude-sonnet-4-6',
      durationMs: input.durationMs || null,
      createdAt: new Date().toISOString(),
    }
    db.insert(tokenUsage).values(row).run()
  },

  /**
   * 获取指定日期（YYYY-MM-DD）的总用量。
   */
  getDailyUsage(date: string): { inputTokens: number; outputTokens: number } {
    const result = db.$client.prepare(`
      SELECT
        COALESCE(SUM(input_tokens), 0) as input_total,
        COALESCE(SUM(output_tokens), 0) as output_total
      FROM token_usage
      WHERE created_at >= ? AND created_at < ?
    `).get(`${date}T00:00:00`, `${date}T23:59:59.999`) as any

    return {
      inputTokens: result?.input_total ?? 0,
      outputTokens: result?.output_total ?? 0,
    }
  },

  /**
   * 获取会话总用量。
   */
  getSessionUsage(sessionId: string): { inputTokens: number; outputTokens: number } {
    const result = db.$client.prepare(`
      SELECT
        COALESCE(SUM(input_tokens), 0) as input_total,
        COALESCE(SUM(output_tokens), 0) as output_total
      FROM token_usage
      WHERE session_id = ?
    `).get(sessionId) as any

    return {
      inputTokens: result?.input_total ?? 0,
      outputTokens: result?.output_total ?? 0,
    }
  },
}
```

## 7. 路由适配

将 M0-4/M1-1 的路由从 `store` 切换为 `repository`。

### 7.1 sessions 路由适配示例

文件路径：`server/routes/sessions.ts`（修改）

```typescript
import { Hono } from 'hono'
import { sessionRepo } from '../repository/session.repo'
import { AppError } from '../types/errors'

export const sessionRoutes = new Hono()

sessionRoutes.get('/sessions', (c) => {
  const sessions = sessionRepo.findAllWithMessageCount()
  return c.json(sessions)
})

sessionRoutes.post('/sessions', (c) => {
  const session = sessionRepo.create()
  return c.json({ id: session.id, title: session.title, createdAt: session.createdAt }, 201)
})

sessionRoutes.get('/sessions/:id', (c) => {
  const session = sessionRepo.findById(c.req.param('id'))
  if (!session) throw AppError.notFound('Session')
  return c.json(session)
})

sessionRoutes.patch('/sessions/:id', async (c) => {
  const body = await c.req.json<{ title?: string }>()
  if (!body.title) throw AppError.validation('title is required', 'title')
  const session = sessionRepo.updateTitle(c.req.param('id'), body.title)
  if (!session) throw AppError.notFound('Session')
  return c.json({ id: session.id, title: session.title })
})

sessionRoutes.delete('/sessions/:id', (c) => {
  const deleted = sessionRepo.delete(c.req.param('id'))
  if (!deleted) throw AppError.notFound('Session')
  return c.json({ deleted: true })
})
```

## 11. 集成陷阱

| # | 问题 | 解决方案 |
|---|---|---|
| T1 | `bun:sqlite` 与 `better-sqlite3` API 不完全兼容 | Drizzle 有 `drizzle-orm/bun-sqlite` 专用适配器，不要用 `better-sqlite3` 适配器 |
| T2 | SQLite 外键约束默认关闭 | 每次连接后必须执行 `PRAGMA foreign_keys = ON` |
| T3 | WAL 模式下 `.db-wal` 和 `.db-shm` 文件 | 正常现象，不要删除；SQLite 在 checkpoint 时自动清理 |
| T4 | JSON 字段存储为 TEXT | `contentBlocks` 和 `toolCalls` 需要 `JSON.stringify` / `JSON.parse` |
| T5 | 并发写入时 SQLITE_BUSY | `busy_timeout = 5000` 让 SQLite 自动重试，不需要应用层重试 |
| T6 | `db.all()` 返回值类型推断 | Drizzle 对 raw SQL 返回 `any`，需手动断言类型 |
| T7 | 迁移文件目录在 gitignore 中 | 迁移文件应当纳入版本控制，只 gitignore `.db` 文件 |
| T8 | seq 字段并发递增 | 用 `MAX(seq)` 查询后 +1，在 SQLite 串行写入下安全 |
