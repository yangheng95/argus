# opencorvus database guide

## Database

- **Schema**: Drizzle schema lives in `src/**/*.sql.ts`.
- **Naming**: tables and columns use snake*case; join columns are `<entity>_id`; indexes are `<table>*<column>\_idx`.
- **Migrations**: generated by Drizzle Kit using `drizzle.config.ts` (schema: `./src/**/*.sql.ts`, output: `./migration`).
- **Command**: `bun run db generate --name <semantic_slug>`.
- **Output**: creates `migration/<timestamp>_<semantic_slug>/migration.sql` and `snapshot.json`.
- **Metadata**: every new migration directory must include `migration.meta.json` with non-empty `title` and `summary`.
- **Examples**: use slugs like `orchestrator`, `workbench`, `goal_metadata`; do not commit random generator names.
- **Legacy dirs**: older migration folders are grandfathered; do not rename or delete them casually because builds and upgrades read them by directory order.
- **Tests**: migration tests should read the per-folder layout (no `_journal.json`).
