# Frontend Design / Research Adversarial Repair

Date: 2026-06-21

## Goal

Run an unattended repair-review loop for the webpage-replica pipeline after the
world-economy tasks exposed that frontend-design, frontend-research, and
architect could spend large context budgets without producing a usable
production implementation path.

## Recalled Constraints

- `AGENTS.md` requires no fallback logic, no hidden gates, no blind patches, and
  real visual evidence for frontend work.
- Reference-parity tasks cannot replace source evidence with prose or static
  screenshot wrappers.
- Production-mergeable UI tasks that demand design-system components and forbid
  primitives must not be treated as a visual-skeleton-only first workflow.
