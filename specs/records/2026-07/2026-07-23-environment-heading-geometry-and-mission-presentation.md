## Causal chain

1. Environment Information is a custom Button inside a grid header, while Workspace and Tools are Section/Disclosure rows.
2. The custom button uses a 34px height and 6px horizontal padding; peer Sections use a 42px head and 2px padding. Their chevrons also occupy unrelated inline geometry.
3. The result is different title baselines, left edges, trailing-control sizes, and perceived vertical spacing even though all three are peer classifications.
4. The existing transparent category hover rule does not provide one explicit title-row contract, so later primitive defaults can still drift independently.
5. Mission selection correctly writes a canonical Session source, and TaskDirBar already opens once per new visible source identity. The failure occurs earlier: `launcherHomeActive()` misclassifies an empty selected Mission as the launcher home and hides the Popover anchor.
6. Adding active Session identity to the existing empty-home predicate restores the intended Mission path without introducing Mission-only state or timing logic.
