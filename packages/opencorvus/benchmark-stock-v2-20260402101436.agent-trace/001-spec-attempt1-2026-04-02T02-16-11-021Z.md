  name TEXT NOT NULL,
  open_price REAL NOT NULL,
  current_price REAL NOT NULL,
  high_price REAL NOT NULL,
  low_price REAL NOT NULL,
  volume INTEGER NOT NULL DEFAULT 0,
  trend REAL NOT NULL DEFAULT 0,
  updated_at INTEGER NOT NULL DEFAULT (unixepoch())

CREATE TABLE price_history (

  volume INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL DEFAULT (unixepoch())
);

CREATE TABLE orders (
  id INTEGER PRIMARY KEY AUTOINCREMENT,

  quantity INTEGER NOT NULL,
  price REAL NOT NULL,
  status TEXT NOT NULL DEFAULT 'pending' CHECK(status IN ('pending', 'filled', 'cancelled')),

);

CREATE TABLE positions (

  quantity INTEGER NOT NULL DEFAULT 0,
  cost_basis REAL NOT NULL DEFAULT 0,
  UNIQUE(user_id, stock_code)
);

CREATE TABLE daily_snapshots (
  id INTEGER PRIMARY KEY AUTOINCREMENT,

## Backend API Endpoints

### Authentication (`src/auth.ts`)
- `POST /api/auth/register` - Register with username/password, returns user + initial 1,000,000 balance
- `POST /api/auth/login` - Login, returns Bearer token

### Market Data (`src/market.ts`)
- `GET /api/market/stocks` - List all 10 stocks with current prices, change, volume
- `GET /api/market/stocks/:code` - Single stock details + last 60 price points
- `GET /api/market/sse` - SSE stream, pushes full market snapshot every 2 seconds

### Trading (`src/trading.ts`)
- `POST /api/trading/buy` - Place limit buy order (stock_code, quantity, price)
- `POST /api/trading/sell` - Place limit sell order
- `POST /api/trading/cancel/:id` - Cancel pending order
- `GET /api/trading/orders` - List user's orders (all statuses)

### Portfolio (`src/portfolio.ts`)
- `GET /api/portfolio` - Current holdings (stock, qty, cost, current price, P&L)
- `GET /api/portfolio/summary` - Total assets, available cash, market value, total P&L, return %

### History (`src/history.ts`)
- `GET /api/history/trades` - Filled trade history (filterable by stock, paginated)
- `GET /api/history/daily` - Last 30 days asset curve

## Market Simulator (`src/simulator.ts`)

- Runs every 2 seconds
- Generates new prices using normal distribution (σ=0.5%) + trend factor (-0.1% to +0.1%)
- Enforces ±10% price limit from open price
- Auto-matches orders on price update:
  - Buy orders: market price ≤ order price → fill
  - Sell orders: market price ≥ order price → fill
- On startup: generates 60 historical price points per stock

## Security Rules

- Password hashing: `Bun.password.hash()` / `Bun.password.verify()` (Argon2)
- Auth middleware: Verify Bearer token, set user context
- Order ownership: Users can only cancel their own orders
- Buy validation: Available balance ≥ quantity × price
- Sell validation: Position quantity ≥ sell quantity
- Lot size: Quantity must be multiple of 100
- Price limit: Order price within ±10% of current price

## Frontend Styling

- Dark theme (trading software style)
- Chinese market colors: Red = up/profit, Green = down/loss
- Number formatting: Prices 2 decimals, amounts with thousand separators, percentages 1 decimal
- Responsive: Desktop-first, tablet-compatible
