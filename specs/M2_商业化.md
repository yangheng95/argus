### 3.4 tushare API 映射（实现要点）

TushareService 的 `getMacroData` 实现：
1. 将 AimeCode 指标 ID 映射到 tushare API（如 `gdp_yoy` → `cn_gdp` 接口的 `gdp_yoy` 字段）
2. 按 API 分组合并请求（同一接口的多个指标合并为一次调用）
3. 并行请求所有分组（`Promise.all`）
4. 转换 tushare DataFrame 格式为 `MacroIndicator[]`，按 date 升序

### 4.4 Notebook 导出

```typescript
// src/services/export/notebook.ts

function exportToNotebook(session: Session): NotebookDocument {
  const cells: NotebookCell[] = []

  // 标题 cell
  cells.push(markdownCell(`# ${session.title}\n> 导出时间：${new Date().toISOString()}`))

  for (const msg of session.messages) {
    if (msg.role === 'user') {
      cells.push(markdownCell(`## 用户提问\n${msg.content}`))
    } else {
      for (const block of msg.blocks) {
        switch (block.type) {
          case 'text':  cells.push(markdownCell(block.content)); break
          case 'code':  cells.push(codeCell(block.code)); break
          case 'table': cells.push(codeCell(toPandasCode(block.columns, block.rows))); break
          case 'chart': cells.push(codeCell(toPlotlyCode(block.spec))); break
          // disclaimer 不导出
        }
      }
    }
  }

  return { nbformat: 4, nbformat_minor: 5, metadata: PYTHON3_KERNEL, cells }
}
```

关键规则：
- 表格数据内联为 `pd.DataFrame({...})` 代码
- 图表内联为 `plotly.graph_objects.Figure({...})` 代码
- 下载通过 `Blob` + `URL.createObjectURL` 触发

### 5.1 服务端会话鉴权

```typescript
// src/server/middleware/auth.ts

interface AuthConfig {
  enabled: boolean                       // AUTH_ENABLED，默认 false
  jwksUri: string                       // 企业 SSO 的 JWKS 端点
  issuer: string
  audience: string
  algorithms: ('RS256' | 'ES256')[]
}

interface AuthenticatedUser {
  sub: string
  email?: string
  name?: string
  roles: ('admin' | 'analyst' | 'viewer')[]
  iat: number
  exp: number
}
```

验签流程：
1. 从 `Authorization: Bearer <token>` 提取 JWT
2. 从 JWKS 端点获取公钥（缓存 1 小时，验签失败时强制刷新一次）
3. 验证签名 + 过期时间 + issuer + audience
4. 解析 roles → 注入请求上下文
5. Token 无效 → 401；权限不足 → 403

### 5.3 数据脱敏

```typescript
// src/server/sanitize/types.ts

interface SanitizeRule {
  id: string
  name: string
  pattern: RegExp
  replacement: (match: string) => string
  enabled: boolean
}

// 内置规则集
const BUILTIN_RULES: SanitizeRule[] = [
  { id: 'id_card',   name: '身份证号', pattern: /(\d{6})\d{8}(\d{4})/g,
    replacement: (_, p, s) => `${p}********${s}`, enabled: true },
  { id: 'phone',     name: '手机号',   pattern: /(\d{3})\d{4}(\d{4})/g,
    replacement: (_, p, s) => `${p}****${s}`, enabled: true },
  { id: 'bank_card', name: '银行卡',   pattern: /(\d{4})\d{8,12}(\d{4})/g,
    replacement: (_, p, s) => `${p}********${s}`, enabled: true },
]
```

脱敏引擎要点：
- `sanitizeDeep<T>(data: T): T` — 递归遍历对象所有 string 值并应用规则
- 在 response 中间件执行，数据离开服务端前脱敏
- 审计日志的 `toolParams` 写入时即脱敏（不存原文）
- 脱敏不可逆
- 配置：`SANITIZE_ENABLED`、`SANITIZE_RULES_FILE`（自定义规则 JSON）

### 7.4 企业 SSO 集成

支持 OIDC 协议。配置项：`discoveryUrl`、`clientId`、`clientSecret`、`redirectUri`、`roleMapping`。
