The TUI is OpenCorvus's interactive terminal front-end. It is the default behavior when you run `opencorvus` with no subcommand.

## Launching

```bash
opencorvus
```

This starts the TUI bound to the current working directory's project. It autodiscovers your `opencorvus.jsonc`, picks up your active provider credentials, and opens an interactive task pane.

## Features

- **Sessions** — every interactive run is a session. Resume with `--continue` or `--session <id>`.
- **Tasks** — submit a task; watch orchestrator decisions, requirements, architecture, per-goal builds, integrity review, and interactions in real time.
- **Slash commands** — `/init`, `/share`, `/undo`, plus any custom commands you define under `commands/` or in the [config](/docs/config/).
- **Permission prompts** — when an `ask` rule fires, the TUI pauses and surfaces an `allow / deny` choice. See [Permissions](/docs/permissions/).
- **Themes** — built-in palettes plus custom themes. See [Themes](/docs/themes/).
- **Keybinds** — fully customizable. See [Keybinds](/docs/keybinds/).

## Inherited from OpenCorvus

OpenCorvus's TUI extends the upstream Go-based OpenCorvus TUI. Most keybinds, themes, and slash-command primitives carry over; OpenCorvus layers in orchestrator, workflow, goal-run, artifact, review, and interaction events on top.

## Headless alternative

If you want to drive OpenCorvus from a script, browser, or editor instead of the TUI, run [`opencorvus serve`](/docs/cli/) and use the [SDK](/docs/sdk/) or [ACP](/docs/acp/) integration.
